# 五维度评审体系详解（Review Dimensions Deep Dive）

## 维度总览

| # | 维度名称 | 英文标识 | 权重 | 能力映射 | 能力门槛 |
|---|---------|---------|:---:|---------|:---:|
| D1 | 引用真实性 | citation_authenticity | 20% | General Capability | ~40 |
| D2 | 引用准确性 | citation_accuracy | 15% | General Capability | ~45 |
| D3 | 层级组织质量 | hierarchical_organization | 25% | Agents | ~40 |
| D4 | 批判性分析深度 | critical_analysis_depth | 25% | Scientific Reasoning | **~55+** |
| D5 | 学术规范性 | academic_norm_compliance | 15% | Agents+General | ~55 |

---

## D1：引用真实性（Citation Authenticity）

### 定义
验证森林中所有引用的文献是否真实存在，无虚构、无严重歪曲。

### 评分量表

| 分数 | 标准 | 判定依据 |
|------|------|---------|
| **10** | 完美 | 0 虚构，100% 已验证，含 DOI/arXiv 全覆盖 |
| **9** | 优秀 | 0 虚构，≥95% 验证，少量传统期刊未逐条确认 |
| **8** | 良好 | 0 虚构，90-94% 验证，有合理的未验证项 |
| **7** | 良好+ | 0 虚构，85-89% 验证，需补充验证 |
| **6** | 及格 | 0 虚构，80-84% 验证，有明显遗漏但非系统性 |
| **5** | 及格- | 0-1 疑似虚构，75-79% 验证，需全面复审 |
| **4** | 不及格 | 1-2 疑似虚构或 70-74% 验证 |
| **3** | 差 | ≥2 疑似虚构或 60-69% 验证 |
| **2** | 很差 | 多处虚构或 50-59% 验证 |
| **1** | 不可接受 | 系统性虚构或 <50% 验证 |

### 检查清单

- [ ] 所有带 arXiv ID 的引用已在 arxiv-mcp-server 中命中
- [ ] 所有带 DOI 的引用可解析到有效页面
- [ ] 传统期刊引用通过 web_search 找到了匹配结果
- [ ] 无"Unknown Author""et al."等模糊署名
- [ ] 无年份明显异常（如未来日期、过早日期）

### 实测基线数据

DeepSeek V4 Pro（44分）在 bim+frs 共 89 篇引用上的表现：
- **评分：9/10**
- arxiv 确认率：27%（9/35），web 补充后达 93%（33/35）
- 虚构引用数：**0**
- 未验证项：均为传统顶刊（Science/Cell/Neuron/Nature/PNAS/eLife）

### 常见问题模式

| 问题模式 | 典型表现 | 严重度 | 修正难度 |
|---------|---------|--------|---------|
| 编造不存在的论文 | 作者+标题+期刊均无法查实 | 致命 | 高——需删除并替换为真实引用 |
| 混淆论文版本 | 将预印本信息与正式版混淆 | 中 | 低——更新元数据即可 |
| 归属错误 | 将 A 论文的结果归因于 B 论文 | 中 | 中——需重新阅读原文确认 |
| 年份错误 | 引用年份与实际发表年份不符 | 低 | 低——修正数字即可 |

## D2：引用准确性（Citation Accuracy）

### 定义
验证引用的元数据（作者/年份/标题/期刊）和引用语境是否精确无误。

### 评分量表

| 分数 | 标准 | 问题率 |
|------|------|--------|
| **10** | 完美 | 0-2% |
| **9** | 优秀 | 3-5% |
| **8** | 良好 | 6-9% |
| **7** | 良好+ | 10-12% |
| **6** | 及格 | 13-16% |
| **5** | 及格- | 17-20% |
| **4** | 不及格 | 21-25% |
| **3-1** | 差-不可接受 | >25% |

### 5 项子检查清单

| # | 检查项 | 权重 | 方法 |
|---|--------|:---:|------|
| 2.1 | 作者名单完整性 | 25% | 对比原始论文的作者列表 |
| 2.2 | 年份准确性 | 20% | 检查是预印本年份还是正式发表年份 |
| 2.3 | 标题准确性 | 20% | 逐字对比标题（注意特殊字符/大小写）|
| 2.4 | 期刊/会议准确性 | 15% | 确认发表的 venue 是否正确（区分书籍章节和期刊论文）|
| 2.5 | 引用语境恰当性 | 20% | 检查引用是否被归入了正确的方向/话题下 |

### 实测基线数据

DeepSeek V4 Pro（44分）在 89 篇引用上的表现：
- **评分：7/10**
- 问题数：6 个中等问题 + 4 个低等问题 = **11% 问题率**
- 主要问题类型：缺作者列表（4篇）、书籍→期刊误标（1篇）、语境偏差（1篇）

## D3：层级组织质量（Hierarchical Organization Quality）

### 定义
评估 Forest → Tree → Branch → Leaf 四级层级的逻辑清晰度和单一职责执行情况。

### 评分量表

| 分数 | 标准 | 最高相似度* |
|------|------|:----------:|
| **10** | 完美的层级设计，零交叉声明 | < 0.75 |
| **9** | 优秀的层级设计，极微弱的语义重叠 | 0.75-0.78 |
| **8** | 良好的层级设计 | **0.79-0.82** |
| **7** | 合理的设计，有少量 index 关系重叠 | 0.83-0.85 |
| **6** | 可接受但有明显交叉声明 | 0.86-0.88 |
| **5** | 一般，需要重组 | 0.89-0.92 |
| **4** | 较差，多处交叉声明 | 0.93-0.95 |
| **3-1** | 结构混乱 | > 0.95 |

\* 使用 sentence-transformers（paraphrase-multilingual-MiniLM-L12-v2）计算 Leaf 间余弦相似度的最高值

### 5 项子检查清单

| # | 检查项 | 权重 | 方法 |
|---|--------|:---:|------|
| 3.1 | Tree 划分合理性 | 25% | 专家判断：每棵 Tree 是否对应独立子领域 |
| 3.2 | Branch 覆盖完整性 | 20% | 每个 Tree 的 Branch 是否覆盖核心话题 |
| 3.3 | Leaf 单一职责执行 | **30%** | 交叉声明检测（向量嵌入） |
| 3.4 | 命名规范一致性 | 15% | 检查命名约定遵循情况 |
| 3.5 | refs 连通性 | 10% | 检查孤立节点比例 |

### 实测基线数据

MKE 自身 51 文档（手动维护 + DeepSeek V4 Pro 构建）的检测结果：
- **评分推断：8-9/10**（最高相似度 0.817，4对>0.80中2对为index正常关系）
- 平均相似度：0.493
- >0.80 对占比：0.3%
- >0.70 对占比：3.4%

### 相似度分布参考表（中文知识库，多语言模型）

基于 MKE 51 文档实测：

| 相似度区间 | 占比 | 判定 | 行动 |
|-----------|:---:|------|------|
| > 0.90 | 0.1% | 极可能完全重复 | 直接拒绝 |
| 0.80-0.90 | 0.3% | 可能部分重复或 index 关系 | 待审 |
| 0.70-0.80 | 3.1% | 语义相关不同概念 | 记录关注 |
| 0.60-0.70 | 15.1% | 同领域知识关联 | 正常 |
| 0.55-0.60 | 15.0% | 弱关联 | 正常 |
| < 0.55 | 66.6% | 独立主题 | 通过 |

## D4：批判性分析深度（Critical Analysis Depth）

### 定义
评估内容是否超越表面总结，包含横向对比、局限性讨论、张力呈现等深层分析能力。

**这是区分中等能力和强能力模型的核心维度。**

### 评分量表

| 分数 | 标准 | 表现特征 |
|------|------|---------|
| **10** | 权威级别的深度分析 | 有原创洞见；呈现未被广泛讨论的争议点；方法论反思；对未来方向有具体预测 |
| **9** | 优秀的学术批评 | 全面横向对比；深入局限性讨论；识别领域内的张力；提出有见地的综合评价 |
| **8** | 良好的批判性视角 | 有方法间对比；讨论了主要局限；提及了部分争议 |
| **7** | 达标的分析深度 | 有基本对比；有一些局限讨论；超越纯总结 |
| **6** | 分析不足 | 以总结为主，偶有评论但不系统 |
| **5** | 浅层描述 | 几乎全是总结，无独立分析 |
| **4** | 明显不足 | **仅方法简介+性能数据**（DeepSeek V4 Pro 实测水平）|
| **3-1** | 严重不足 | 有事实错误、逻辑矛盾或明显偏颇 |

### 5 项子评估标准

| # | 评估项 | 权重 | 评判要点 |
|---|--------|:---:|---------|
| 4.1 | 论述超越总结 | 30% | 是否只有"A做了X，取得了Y%"？还是有"为什么X有效？Z指出的问题是什么？" |
| 4.2 | 方法间横向对比 | 25% | 是否在相同任务上比较了不同方法的优劣？有无对比表格？ |
| 4.3 | 局限性讨论 | 20% | 是否讨论了已知失败案例、适用条件、假设前提？ |
| 4.4 | 张力与争议呈现 | 15% | 是否呈现了学术界的不一致观点？（如"Group A 认为... 而 Group B 认为..."）|
| 4.5 | 可操作洞见 | 10% | 是否提供了超越文献摘要的新见解或实践指导？|

### 实测基线数据

DeepSeek V4 Pro（44分）在 frs 综评和 bim 代表文档上的表现：
- **评分：4/10**（明显不足）
- 主要缺陷：论述以总结为主、缺乏方法间横向对比、缺乏局限性讨论、结论过于模板化
- 正面案例：bim 键值记忆框架文档准确标注了与 CLS 的张力（"整合仍是活跃研究前沿"），但未深入展开

### 与 Intelligence Index Scientific Reasoning 的相关性

D4 评分与 AAI 中 Scientific Reasoning 维度（HLE 12% + GPQA Diamond 6% + CritPt 6% = 24%）高度正相关：
- HLE（人类最后的考试）：测试模型对困难科学问题的推理深度 → 映射到"论述超越总结"
- GPQA Diamond：测试研究生级科学推理能力 → 映射到"方法间横向对比"+ "局限性讨论"
- CritPt：测试符号表达式和数值推理 → 映射到"可操作洞见"

## D5：学术规范性（Academic Norm Compliance）

### 定义
评估文档是否遵循结构化的写作规范，即使不是严格意义上的学术论文。

### 评分量表

| 分数 | 标准 | 缺陷数 |
|------|------|:-----:|
| **10** | 完全符合规范 | 0 |
| **9** | 极小瑕疵 | 1 |
| **8** | 轻微瑕疵 | 2 |
| **7** | 小问题 | 3-4 |
| **6** | 明显缺陷 | 5 |
| **5** | 较多缺陷 | **6-7**（DeepSeek V4 Pro 实测水平）|
| **4** | 系统性问题 | 8-9 |
| **3-1** | 严重不规范 | ≥10 |

### 6 项子检查清单

| # | 检查项 | 权重 | 满分标准 |
|---|--------|:---:|---------|
| 5.1 | 方法论声明 | 25% | 说明了资料来源/筛选标准/组织方法/抽取工具 |
| 5.2 | 引用格式一致性 | 20% | 所有引用遵循统一格式 `[id] title \| reason` |
| 5.3 | 版本标识完整 | 15% | 每个文件都有 version/created/updated |
| 5.4 | 元数据完整性 | 20% | Frontmatter 包含 title/description/keywords/source/refs |
| 5.5 | 内部标签隔离 | 10% | 项目标签 `[mke]`/`[bim]` 不出现在正文引用中 |
| 5.6 | 图表与可视化 | 10% | 复杂关系有表格辅助理解（不强求但加分）|

### 实测基线数据

DeepSeek V4 Pro（44分）的表现：
- **评分：5/10**（有缺陷）
- 主要缺陷：缺少综述方法论（PRISMA）、缺少作者署名、内部标签混入、引用元数据不完整（4篇缺作者）

### 与指令遵循能力的关系

D5 评分与模型的**指令遵循（Instruction Following）**能力高度相关——能否严格按照给定的格式要求输出内容。这对应 AAI 中：
- **Agents 维度**（34%）：任务完成能力包含"按规格交付"的要求
- **General 维度**（18%）：AA-Omniscience 和 AA-LCR 都涉及对复杂指令的理解和执行
