# 评分标准化与对照实验范式（Scoring Standardization & Controlled Experiment Paradigm）

## 概述

本文档定义如何在对照实验中对多个模型的森林生成质量进行**统计上可靠的评分和比较**。核心目标是确保"同一份基础资料 × 不同模型 × 相同评审方法"产生的对照数据具有统计学意义。

## 对照实验设计

### 实验变量

| 变量类型 | 变量名 | 固定值/取值范围 |
|---------|--------|---------------|
| **控制变量** | 基础资料 | 同一份，锁定版本（如综述论文 v4.0）|
| **控制变量** | 生成方法论 | 同一 SOP（forest-generation-methodology 9 步不变）|
| **控制变量** | 评审方法论 | 同一 SOP（forest-quality-reviewer 6 步不变）|
| **控制变量** | 评审者模型 | 固定为同一个高能力模型（如 Claude Fable 5, II=60）|
| **控制变量** | 评审者偏差声明 | 每次报告均注明 |
| **自变量** | LLM 模型 | Model A / Model B / Model C ... |
| **因变量** | 5维度评分 | D1-D5 各 0-10 分 |
| **因变量** | 综合评分 | 加权平均 |
| **因变量** | 人工修正率 | % |
| **因变量** | 生成效率 | 时间/token 消耗 |

## 评分标准化

### 综合评分计算

采用加权平均：

```
综合评分 = 0.20×D1 + 0.15×D2 + 0.25×D3 + 0.25×D4 + 0.15×D5
```

### 置信区间估计

对于每个维度，如果有多轮重复数据，计算 95% 置信区间。单次实验的标准误差约为 ±0.5-1.0 分。两模型间差异 ≥ 2 分时可认为具有统计显著性。

### 评分一致性检验

使用 Krippendorff's Alpha 评估多轮/多评审者间一致性。alpha >= 0.7 表示可接受。
