# Intelligence Index 能力映射方法论（Intelligence Index Mapping Methodology）

## 概述

本文档定义如何将知识森林质量评审的 5 维度评分映射到 **Artificial Analysis Intelligence Index（AAI）** 的四大能力空间。这一映射是实现"大模型能力 → 知识质量"定量关系的核心。

## AAI 方法论基础

来源：`docs/forest/ai-evaluation-benchmarks/Artificial Analysis Intelligence Index methodology.md`

### AAI v4.1 构成

AAI 通过加权平均 9 项评测计算综合分数（0-100），覆盖四大能力维度：

| 类别 | 权重 | 组成评测 | 评测性质 |
|------|:---:|---------|---------|
| **Agents** | **34%** | GDPval-AA v2 (20%) + τ³-Banking (14%) | Agent 任务完成 |
| **Coding** | **24%** | Terminal-Bench v2.1 (16%) + SciCode (8%) | 代码生成与执行 |
| **Scientific Reasoning** | **24%** | HLE (12%) + GPQA Diamond (6%) + CritPt (6%) | 科学推理 |
| **General** | **18%** | AA-LCR (6%) + AA-Omniscience (12%) | 通用问答 |

### AAI 评测原则

1. **标准化（Standardized）**：相同条件评估
2. **无偏（Unbiased）**：避免不公平惩罚
3. **零样本指令提示（Zero-Shot Instruction Prompted）**：测试指令遵循能力
4. **透明（Transparent）**：完全公开方法论

## 能力门槛效应分析

基于 DeepSeek V4 Pro（Intelligence Index = 44）的实测数据（详见评审报告），我们识别出三种不同的能力响应模式：

### 模式 A：门槛效应（非线性 S 型曲线）

**特征**：低于某个阈值时质量很差，达到阈值后迅速饱和不再提升。

```
质量
 10 │           ╭─────╮
  9 │     ╭─────╯     ╲
  8 │    ╱             ╲____  门槛效应
  7 │   ╱
  6 │  ╱
  5 │ ╱
  4 │╱
  3 │
    └──────────────────────────→ Intelligence Index
       30    40    50    60
            ↑
          门槛 (~40)
```

**适用维度**：
- **D1 引用真实性**：44 分已达 9/10，推测门槛在 ~35-40 分
- **D3 层级组织**：44 分已达 8/10，推测门槛在 ~38-42 分

**解读**：基础事实能力和结构化组织能力不需要顶尖模型就能做好。这些能力更像"开关"——要么能（超过阈值），要么不能（低于阈值编造）。

### 模型 B：近似线性增长

**特征**：随能力提升持续改善，无明显饱和迹象。

```
质量
 10 │                         ╭──
  9 │                    ╭────╯
  8 │               ╭────╯
  7 │          ╭────╯
  6 │     ╭────╯
  5 │╭────╯
  4 │
    └──────────────────────────→ Intelligence Index
       35    40    45    50    55    60
```

**适用维度**：
- **D2 引用准确性**：44 分 = 7/10（11% 问题率），预期 55 分可达 8.5/10
- **D5 学术规范**：44 分 = 5/10（系统性缺陷），预期 55 分可达 7.5/10

**解读**：精确性和规范性需要持续的指令遵循能力改善。这类能力没有明显的"够用就行"的阈值。

### 模式 C：陡峭增长（高能力区差异最大）

**特征**：低能力区几乎无效，高能力区才显著分化。

```
质量
 10 │                                  ╭━━╮
  9 │                             ╭────╯  ╰─╮
  8 │                        ╭─────╯        ╲
  7 │                   ╭─────╯              ╲
  6 │              ╭─────╯
  5 │         ╭─────╯
  4 │    ╭─────╯
  3 │╭───╯
  2 │
    └──────────────────────────────→ Intelligence Index
       35    40    45    50    55    60
                          ↑
                     分水岭 (~55)
```

**适用维度**：
- **D4 批判性分析**：**44 分 = 4/10（明显不足），这是最陡峭的曲线**

**解读**：批判性分析需要深层推理能力，这是当前大模型的核心差异点。**D4 是最能区分"能用"和"优秀"的维度**。

## 局限性与后续研究方向

1. **单点校准**：目前仅有 Intelligence Index = 44 一个实测点，其他区间为外推。需要至少再获取 2 个不同 II 值的实测数据来拟合曲线形状。
2. **领域特异性**：当前数据来自记忆/知识/协作领域（bim+frs），可能不适用于纯工程或自然科学领域。
3. **评审者偏差**：GLM-5.2 作为评审者，其自身能力可能影响对各维度的判定严格程度。
4. **AAI 动态性**：AAI 的权重和组成评测会随版本更新变化，映射关系需要定期重新校准。
