# 输入资料策展策略（Input Curation Strategy）

## 概述

输入资料策展是知识森林生成的 **Step 0**——它决定了森林质量的"原材料"上限。再优秀的 LLM 抽取方法也无法从低质量资料中产出高质量森林。

## 策略矩阵

### 策略一：单源深度（Single-Source Deep Dive）

| 属性 | 说明 |
|------|------|
| **适用场景** | 针对特定领域的系统梳理，需要建立完整的知识体系 |
| **典型输入** | 一篇高质量综述论文 + 其参考文献中的核心文献 |
| **质量要求** | 综述需有明确的方法论声明（如 PRISMA）、同行评审、近 3 年内发表 |
| **优势** | 覆盖完整、主题聚焦、引用链清晰 |
| **风险** | 受限于单一视角（综述作者的偏见） |
| **MKE 项目实例** | bim 森林：源自同一篇综述论文 v4.0 的人脑记忆相关章节 |

### 策略二：多源聚合（Multi-Source Aggregation）

| 属性 | 说明 |
|------|------|
| **适用场景** | 跨领域的知识整合、需要多视角交叉验证 |
| **典型输入** | 多篇综述 + 教材章节 + 技术报告 + 经验论文 |
| **质量要求** | 来源间有可追溯的引用关系；至少有一篇作为"主锚定文献" |
| **优势** | 视角全面、偏见被稀释、覆盖面广 |
| **风险** | 来源间可能有矛盾或重叠，需要额外的一致性处理 |
| **MKE 项目实例** | frs 森林：54 篇论文的系统性综述 |

### 策略三：增量迭代（Incremental Iteration）

| 属性 | 说明 |
|------|------|
| **适用场景** | 已有森林需要扩展、持续跟踪领域新进展 |
| **典型输入** | 现有森林 + 新增文献（会议论文/preprint） |
| **质量要求** | 新增文献的主题边界与现有森林对齐；避免重复覆盖已有内容 |
| **优势** | 成本低、可持续、保持知识库时效性 |
| **风险** | 增量累积可能导致结构失衡（某些 Tree 过于庞大） |
| **使用建议** | 每 N 篇新增后执行一次 Step 1（重新审视层级设计）|

## 资料质量评估清单

### 第一级：来源可信度（必须全部通过）

- [ ] **出版渠道正规**：同行评审期刊 / 顶级会议 / 权威机构报告（优先级递减）
- [ ] **作者可追溯**：有明确的作者署名和机构归属
- [ ] **版本明确**：有 arXiv ID / DOI / ISBN / 发布日期
- [ ] **非生成内容**：不是 LLM 生成的文章（可通过写作风格和引用模式初步判断）

### 第二级：内容质量（至少满足 4/6）

- [ ] **引用规范**：每项主张都有 source 引用，引用格式统一
- [ ] **方法论声明**：说明了数据收集/筛选/分析的具体方法（对综述尤为重要）
- [ ] **覆盖完整性**：不遗漏目标领域的核心子主题
- [ ] **批判性视角**：不仅陈述正面结果，也讨论局限性和失败案例
- [ ] **时效性**：发表于最近 5 年内（历史性领域可放宽）
- [ ] **语言匹配**：为目标语言（中文森林优先选中文资料，英文资料次之）

### 第三级：适用性评估（针对具体项目）

| 评估项 | 问题 | 权重 |
|--------|------|:---:|
| 领域匹配度 | 该资料的领域是否与目标 Forest 的定位一致？ | 高 |
| 粒度适配性 | 内容的详细程度是否适合拆分为知识原子？ | 高 |
| 引用密度 | 是否有足够的引用支撑后续的审计步骤？ | 中 |
| 结构化程度 | 是否已有隐含的结构（章节/小节）可映射为 Tree/Branch？ | 中 |
| 可获取性 | 全文是否可公开获取？ | 低（但影响实操便利性）|

## 资料预处理检查表

在将资料传入 `knowledge-atom-extractor` 之前：

```markdown
## 资料预处理 Checklist

### 元信息收集
- [ ] 记录资料的完整引用信息（标题/作者/年份/来源/URL）
- [ ] 记录资料版本/日期（锁定版本以确保可复现）
- [ ] 标记资料的策展策略类型（单源/多源/增量）

### 格式标准化
- [ ] 转换为 Markdown 或纯文本格式
- [ ] 清除页眉/页脚/页码等噪音
- [ ] 保留原始章节结构（作为 Step 1 的输入参考）
- [ ] 提取并保留所有引用标记（[1], (Author, Year) 等）

### 内容预检
- [ ] 快速扫描是否有明显的内容缺失或乱码
- [ ] 估算大致的内容量（字数/章节数）以预估抽取工作量
- [ ] 识别可能的高价值章节（优先处理）
```

## 与 forest-generation-methodology 其他步骤的关系

```
Step 0 (本步骤) ──→ Step 1 (主题设计)：资料的主题分布决定了 Tree 划分
     │
     └──→ Step 2 (LLM 抽取)：资料的质量决定了原子质量的上限
          │
          └──→ Step 5 (引用审计)：资料的引用密度决定了审计工作量
```
