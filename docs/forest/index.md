# 项目知识森林总索引

**元知识引擎（Meta-Knowledge Engine, MKE）** 是本项目的核心——一个面向大模型的领域知识引擎。`bim`（类脑记忆）、`aic`（人机协作）、`frs`（前沿综述）三个森林的知识最终服务于 MKE 的设计、实现和迭代。

本目录基于"知识领域森林理论"组织项目知识。每个子目录代表一个**森林**（独立知识领域），森林内按**树→枝干→叶**的层级组织文档，文档间通过**引用链接**构成图网络。

| `bim` | 类脑记忆机制 | 生物学启发 | [index.md](brain-inspired-memory/index.md) | 人脑记忆的宏观架构、微观机制、检索算法——为 MKE 存储和遗忘机制提供启发 |

## 引用规范

- 文档间通过 `refs` 元数据字段声明引用关系
- 引用格式：`[森林ID] 文档标题 | 引用关键字`
- 严格遵循**单一职责原则**：每个知识点只有一个权威来源，其他文档通过引用链接而非复制

**bim / aic / frs → mke**：三个支撑森林的知识最终流入 MKE 核心：

- **bim → mke**：类脑记忆机制为 MKE 的分层存储、稀疏编码、模式完成检索、记忆遗忘策略提供生物学启发
- **aic → mke**：AI 人机协作为 MKE 提供消费场景（知识何时被查询）、设计约束（上下文窗口限制）、验证反馈（检索质量评估）
- **frs → mke**：前沿综述为 MKE 各层提供学术对标——GraphRAG→检索策略、MemVerse→记忆融合、知识编辑→知识演化管理
- **mke → aic**：MKE 为 Agent 协作提供知识检索、记忆融合、存储引擎等基础设施
