# 项目知识森林总索引

本目录基于"知识领域森林理论"组织项目知识。每个子目录代表一个**森林**（独立知识领域），森林内按**树→枝干→叶**的层级组织文档，文档间通过**引用链接**构成图网络。

## 森林清单

| 森林 ID | 名称 | 索引文件 | 说明 |
|---------|------|---------|------|
| `mke` | 元知识引擎 | [index.md](meta-knowledge-engine/index.md) | Meta-Knowledge Engine：森林理论、五层架构、渐进式检索、SQLite 存储、LLM 抽取器、Agent Memory 对齐 |
| `aic` | AI 人机协作 | [index.md](ai-collaboration/index.md) | 人类与大模型协作：CEO-子公司模型、注意力瓶颈、交互范式、Agent 角色设计、胶水提示词、反模式清单 |
| `bim` | 类脑记忆机制 | [index.md](brain-inspired-memory/index.md) | 人脑记忆的数据结构与算法：宏观架构、微观机制、检索算法、新兴理论、未解之谜——为 Agent Memory 提供生物学启发 |

## 引用规范

- 文档间通过 `refs` 元数据字段声明引用关系
- 引用格式：`[森林ID] 文档标题 | 引用关键字`
- 严格遵循**单一职责原则**：每个知识点只有一个权威来源，其他文档通过引用链接而非复制
