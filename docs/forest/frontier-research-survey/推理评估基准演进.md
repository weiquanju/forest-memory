# 推理评估基准演进

## 核心问题

评估 LLM Agent 推理能力需要从"单轮正确率"演进到"多轮记忆+决策+推理"的综合评估。静态基准正被碎片化的专用 Agent 基准取代。

## 一、基准演进四阶段

| 阶段 | 代表基准 | 特点 |
|------|---------|------|
| 早期 | GSM8K [48]、MATH [49] | 小学数学应用题、数学竞赛题 |
| 发展 | AIME、AMC | 更高难度数学题集 |
| 扩展 | 多领域专用基准 | 逻辑推理、常识推理、多跳问答 |
| 前沿 | MemBench [50]、MemoryAgentBench [51]、MemoryArena [52] | 多会话任务，记忆与决策交织 |

## 二、静态基准的局限

1. **数据污染（Data Contamination）**：测试数据可能已出现于训练语料，导致虚高表现
2. **静态单轮局限**：无法评估动态环境中的推理和决策能力

## 三、新评估范式

### 趋势一：组合式基准

**Scheherazade [55]**：将多个基准"链式"连接，生成更长更复杂的推理链，评估模型处理长链条件推理的能力。

### 趋势二：过程导向评估

不仅看最终答案正确性，还关注推理过程质量：
- **可重用性（Reusability）**：推理步骤是否可被其他模型理解并复用
- **可验证性（Verifiability）**：推理步骤是否可被独立验证

### 趋势三：Agent 动态评估

| 基准 | 评估维度 | 特点 |
|------|---------|------|
| MemBench [50] | 参与/观察二场景 + 事实/反思二层次 | 首个综合记忆基准 |
| MemoryAgentBench [51] | 准确检索、测试时学习、长程理解、选择性遗忘 | 增量多轮交互评估四能力 |
| MemoryArena [52] | 多会话 Memory-Agent-Environment 循环 | 统一评估场 |
| LifelongAgentBench [19] | Database/OS/KG 三环境终身学习 | 首个系统终身学习评估 |

## 四、评估范式的结构性挑战

1. **评估成本与可复现性**：动态基准多轮 Agent-环境交互，单次 API 成本和时间远高于静态基准，社区复现门槛高
2. **记忆与推理的纠缠**：难以分离"记错了"还是"推理错了"——需要更细粒度的归因分析框架
3. **生态碎片风险**：统一标杆（GSM8K/MATH）正被碎片化专用 Agent 基准取代，跨工作比较日益困难

## 五、开放挑战

- 记忆与推理的分离评估——需要设计能独立测量"检索准确性"和"推理正确性"的基准
- 降低动态评估成本——探索模拟环境替代真实 API 调用的方法
- 统一评估框架——在碎片化和标准化之间找到平衡
