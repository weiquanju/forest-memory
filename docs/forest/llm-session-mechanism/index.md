# LLM 会话机制

## 定位

本森林描述现代大语言模型（LLM）会话机制的工作原理与根本局限。分析基于公开的 Transformer 架构知识，以 DeepSeek V4 Pro 作为典型实例。核心回答三个问题：LLM 如何"记住"当前对话、为什么对话关闭后"忘记"、以及 MKE 在这个拼图中的位置。

## 讨论框架

本次讨论采用多视角联合分析形式——从 Transformer 架构、上下文窗口和无状态本质三个视角审视 LLM 会话机制。分析严格区分"公知原理"（公开学术知识）、"合理推断"（根据原理推演）和"坦诚不知道"（模型内部未公开细节）。

## 知识边界

| 分类 | 内容 | 可信度 |
|------|------|:---:|
| 公知原理 | Transformer 架构、注意力机制、自回归生成、上下文窗口概念 | ✅ 高 |
| 合理推断 | 上下文窗口大小量级、截断策略的通用模式 | ⚠️ 中 |
| 坦诚不知道 | DeepSeek V4 Pro 具体实现细节、精确窗口大小、专有优化 | ❌ 不可用于结论 |

## 核心原则

1. **诚实标注知识边界**——从"公知原理""合理推断"到"坦诚不知道"三级分类
2. **不猜测专有实现**——DeepSeek V4 Pro 的具体工程细节不在本森林讨论范围
3. **聚焦 MKE 的定位**——本森林的最终目的不是描述 LLM，而是明确 MKE 解决了哪部分问题
