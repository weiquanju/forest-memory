# 知识原子规范

## 定义

**知识原子（Knowledge Atom）** 是元知识引擎中不可再分的最小知识单元。一个 .md 文件 = 一个知识原子 = 一片叶子。

## YAML Frontmatter 字段规范

### 必填字段

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `forest` | string | 森林 ID，小写短标识符 | `mke`、`aic` |
| `tree` | string | 所属树的名称 | `元知识引擎` |
| `branch` | string | 所属枝干的名称 | `数据规范` |
| `title` | string | 文档标题（同时也是叶子的主键） | `知识原子规范` |
| `version` | semver | 语义版本号 | `1.0.0` |
| `created` | date | 创建日期 ISO 8601 | `2026-07-12` |
| `updated` | date | 最后更新日期 | `2026-07-12` |
| `description` | string | 一句话说明该知识原子的内容与用途 | 见上方 |

### 可选字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `keywords` | string[] | 检索关键字，帮助向量/关键词匹配 |
| `refs` | string[] | 引用声明，格式 `[森林ID] 文档标题 \| 引用关键字` |
| `status` | enum | `draft` / `reviewed` / `stable` / `deprecated` |
| `depends_on` | string[] | 硬性前置依赖（必须先理解的知识原子） |

### 字段约束

- `forest` + `tree` + `branch` + `title` 四元组在全局唯一
- `version` 采用 semver：主版本.次版本.修订号
- `updated` 必须 ≥ `created`
- `refs` 中引用的文档必须真实存在

## 内容格式规范

### 文档结构
```
YAML Frontmatter
---
# 标题（与 title 字段一致）
## 子标题层级不超过 3 层
```

### 行文约束
- 一个知识原子只阐述**一个**核心概念或操作步骤
- 不超过 200 行（超长内容应拆分为多个知识原子）
- 代码块必须标注语言
- 引用外部文档使用 `refs` 元数据，正文内用 Markdown 链接 `[标题](../path/to/doc.md)`

## 质量门禁

构建时自动检查以下规则：

1. **Frontmatter 完整性** — 8 个必填字段全部存在且非空
2. **ID 唯一性** — `forest:tree:branch:title` 四元组无冲突
3. **引用有效性** — `refs` 引用的 `[森林ID] 文档标题` 在索引中可解析
4. **单一职责** — LLM 抽取时若检测到与已有知识原子内容重复度 > 80%，拒绝写入
5. **版本一致性** — `updated` ≥ `created`，版本号符合 semver
