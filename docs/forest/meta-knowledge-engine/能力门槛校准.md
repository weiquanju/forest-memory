# 能力门槛校准

## 定位

本文档记录基于 DeepSeek V4 Pro（Intelligence Index 44 分）实测的 LLM 知识抽取能力门槛校准结论。

> DeepSeek V4 Pro 知识抽取质量评审报告（`docs/DeepSeek_V4_Pro知识抽取质量评审.md`）提供了首轮基线数据，后续将使用方法论体系中的三个 Skill 进行多模型对照实验以更新本结论。

## 五维度实测结论

基于 forest-quality-reviewer 的 5 维度评审体系，DeepSeek V4 Pro 实测结果：

| 维度 | 评分 | 能力门槛 | 风险等级 |
|------|:---:|:---:|:---:|
| D1 引用真实性 | 9/10 | < 40 分 | 低 |
| D2 引用准确性 | 7/10 | ~45 分 | 中——可人工补充 |
| D3 层级组织 | 8/10 | ~40 分 | 低 |
| D4 批判性分析 | 4/10 | > 55 分 | **高**——需更强模型 |
| D5 学术规范 | 5/10 | ~55 分 | **高**——需更强模型 |
| **综合** | **6.5/10** | — | 建库可行，深化不足 |

**关键发现**：89 篇引用 0 篇虚构——引用真实性在 ~40 分即达门槛。

## 三类响应模式

基于 44 分实测数据，识别出 LLM 知识抽取能力的三类不同响应模式：

### 模式 A：门槛效应（非线性）

- **引用真实性**：~40 分达到门槛后不再显著提升
- **层级组织**：~40 分即饱和，结构化能力在中低水平就达到瓶颈

### 模式 B：近似线性增长

- **引用准确性**：随能力提升持续改善
- **学术规范**：与指令遵循能力正相关，持续改善

### 模式 C：陡峭增长（高能力区差异最大）

- **批判性分析**：~55 分后才开始显著分化，是区分"能用"和"优秀"的分水岭
- 与 Scientific Reasoning 维度高度正相关

## 模型路由策略

基于能力门槛校准，推荐分层模型路由：

| 知识抽取阶段 | 所需能力维度 | 推荐 Intelligence Index | 性价比之选 |
|------------|------------|:---:|----------|
| **建库阶段**（引用真实+层级组织） | General + Agents | ~40-50 | DeepSeek V4 Flash ($0.10/M) |
| **校验阶段**（引用准确+学术规范） | General + Agents | ~45-55 | Claude Sonnet 4.6 ($3/$15 per M) |
| **深化阶段**（批判性分析+横评） | Scientific Reasoning | **> 55** | Claude Opus 4.7 / Claude Fable 5 |

**结论**：知识抽取的"建库阶段"可以用低成本模型完成。只有"深化阶段"需要高能力模型。这大大降低了 MKE 的实际运营成本。
