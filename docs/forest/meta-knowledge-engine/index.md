# AI 知识质量基础设施（MKE）

## 定位

**MKE = AI 知识质量基础设施（AI Knowledge Quality Infrastructure）**

不局限于 RAG 场景，而是面向所有需要"知识组织 + 质量治理 + 精准检索"的 AI 应用场景。RAG 只是 MKE 的消费场景之一，Agent Memory、训练数据治理、知识库迁移等同样是 MKE 的消费场景。

区别于单纯的"数据库"：元知识引擎解决的不只是"怎么存、怎么查"，还包括"怎么建、怎么改、怎么同步、怎么保障质量"。

> 完整定位与边界声明参见 [项目定位与边界声明](项目定位与边界声明.md)

## 核心原则

1. **文档即叶子**：每个 .md 文件是一个"知识原子"，遵循单一职责
2. **引用非复制**：跨文档引用使用 `refs` 元数据，杜绝交叉声明
3. **层级定位**：检索时先定位森林/树，再下钻枝干/叶，避免全局盲目搜索
4. **图网络**：文档间通过引用关系构成有向图，支持多跳推理（multi-hop reasoning）
