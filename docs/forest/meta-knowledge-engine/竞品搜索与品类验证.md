# 竞品搜索与品类验证

## 验证目标

通过系统性 GitHub 搜索，验证"知识质量治理"作为独立品类的市场需求，建立竞品全景图。

## 5 方向搜索统计

| 搜索方向 | 总命中 | 同类专门项目 | 结论 |
|---------|--------|------------|------|
| 质量维度（knowledge consistency, hallucination detection, fact checking） | 1670+ | 0 | 赛道成熟但方向错位——聚焦"LLM 输出质量"而非"知识库存量质量" |
| 治理动作（knowledge validation, deduplication, curation, data lineage） | 867+ | 0 | "知识去重""知识策展"几乎不存在 |
| 去重技术（semantic deduplication, near-duplicate, MinHash LSH） | 303+ | teleMem | 唯一信号：teleMem 将语义去重作为卖点，但非知识原子级 |
| Agent 记忆（agent memory, memory dedup, memory pruning, RAG quality） | 4076+ | 0 | 腾讯/Redis/Neo4j/字节全线入局，**无一家提供存量知识质量治理** |
| 组合搜索（knowledge dedup agent, RAG clean, memory quality） | 1041+ | 0 | 印证核心空白 |

## 核心发现

MKE 瞄准的不是一个拥挤赛道，而是一个**被大量关联赛道环绕但自身几乎空白的区域**：

- Agent Memory 解决"怎么存、怎么查"
- Hallucination Detection 解决"说没说谎"
- Knowledge Conflict 解决"模型内部矛盾"
- **没有人解决"存在知识库里的东西本身对不对、有没有重复、改一处要不要联动更新"**

## 三维对比矩阵

| 维度 | PKA | Khala | MKE |
|------|-----|-------|-----|
| 治理对象 | Agent **工作流质量** | 系统**架构一致性** | **知识内容存量质量** |
| 治理粒度 | 任务级 | 系统组件级 | **知识原子级** |
| SSOT | 不存在 | 部分（Archon Claims 绑定代码常量） | **完全 SSOT** |
| 交叉声明检测 | 不存在 | Design-Observation Diff（架构级） | **三层冲突检测** |
| 去重 | 不存在 | 不存在 | **知识原子级语义去重** |
| 与 MKE 重叠度 | 0% | < 10% | — |

三个项目治理三个完全不同的层级。PKA 和 Khala 的存在不是竞争威胁，而是间接验证了"质量治理"作为方向的正确性。

## 品类成熟度判断

| 信号 | 当前状态 | 趋势 |
|------|---------|------|
| GitHub 项目数量 | 极低（几乎无同类专门项目） | 早期蓝海 |
| 学术论文覆盖 | 中高（知识冲突、幻觉检测等关联方向） | 快速增长 |
| 工业界投入 | 低中（Agent Memory 大厂密集入局但无治理层） | 即将溢出 |
| 术语共识 | 未形成（"知识治理""知识质量"概念混淆） | 需要建立 |

**结论**："知识质量治理"处于品类形成早期，是一个需要自己定义品类的新兴赛道。Agent Memory 赛道 2025-2026 年爆发，预计 2026-2027 年会从"怎么记住"自然过渡到"记住的对不对"——这是 MKE 的最佳切入时机。
