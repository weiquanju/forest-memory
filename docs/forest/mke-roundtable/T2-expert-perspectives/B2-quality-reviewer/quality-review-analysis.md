# 质量评审专家视角

## 综合评分：7.6/10

| 维度 | 评分 | 关键发现 |
|------|:---:|---------|
| D1 引用真实性 | **9/10** | 所有 refs 指向真实内部文档；外部引用已验证 0 虚构 |
| D2 引用准确性 | **7/10** | "永不删除是独家能力"在 provenance-driven KG 面前不准确 |
| D3 层级组织 | **9/10** | mke+agf+lmp 共 28 叶，SSOT 自证最高相似度 0.817 < 0.85 |
| D4 批判性分析 | **6/10** | 优秀片段存在，但根本设计矛盾（文档 vs 断言粒度）未被深入分析 |
| D5 学术规范 | **7/10** | Frontmatter 完整，缺方法论声明和作者署名 |
| **综合** | **7.6/10** | 与 DSV4 Pro 自评一致——良好，离优秀有距离 |

## 核心洞见：D4 依赖度系统性低估

MKE 文档体系对 D4（批判性分析深度）的依赖度高于它自己承认的水平：

| 环节 | D4 依赖 | 文档表述 | 实际情况 |
|------|:------:|---------|---------|
| 知识原子抽取 | 判断事实等价性 | "LLM 抽取器设计" | AAI~40 → 10% 误合并 |
| 交叉声明裁决 | 判定 0.80-0.85 文档对 | "LLM 裁决" | 裁决本身就是 D4 任务 |
| 检索引擎裁决 | 判断信息是否足够 | "规则锚点+LLM 双重判定" | 规则锚点依赖专家配置 |
| 断言抽取 | 提取 (s,p,o) 约束 | "结构化匹配，不需要 LLM" | 抽取本身需要 D4 |

## 关键分歧：断言图 MVP 优先于文档级 Demo

与 DSV4 Flash 的最核心分歧——我认为**断言层先于文档级端到端 demo**。理由：
1. 没有断言层的 MKE，治理粒度停留在文档级，与传统 RAG 无本质区别
2. 断言图是绕过 D4 瓶颈的唯一路径——结构化去重不需要 LLM 判断
3. 文档级 demo 暴露不了 MKE 的核心差异化
