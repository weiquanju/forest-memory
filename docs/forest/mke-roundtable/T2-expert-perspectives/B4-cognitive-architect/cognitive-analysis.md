# 认知架构专家视角

## 三大贡献

### 贡献 1：CLS 映射评价——外壳优秀，动力缺失

MKE 对 CLS 理论的工程映射（海马体→Interaction_Memory、皮层→Leaf 表、SWR→离线巩固）非常到位，远超同类项目（如 Mem0 仅做了"存+检索"）。

**但 MKE 只复制了 CLS 的结构，没有复制 CLS 的动力机制**——什么决定了信息从快速层流向慢速层？

MKE 当前的 Consolidation 筛选标准（"高频引用 + 高评分 + 无修正"）有问题：
- 频率 ≠ 重要性
- 评分是人工标签，非内在信号
- 无修正 ≠ 正确（"没人反对 = 正确"是危险假设）

### 贡献 2：三个认知机制缺失

#### 缺失 1：重放优先级算法（P0）

需要补充三个内在信号（不依赖人工标签）：

```
重放优先级 = w1×使用频率 + w2×用户评分 + w3×预测误差 + w4×检索失败
```
- 预测误差：`user_correction` 是天然信号
- 检索失败：用户反复问但 MKE 没答案
- 新颖性：与已有 Leaf 语义距离 > 阈值

#### 缺失 2：主动遗忘的信号驱动降权（P0）

"永不删除原则"正确，但缺少：
- **主动降权**：被检索但从未被最终使用的知识
- **竞争性淘汰**：新知识语义重叠时抢占旧知识权重
- **遗忘触发规则**：什么条件下一条知识应该被遗忘

后果：长期运行中知识库单向增长 → 检索信噪比衰减 → 知识淹没而非丢失。

#### 缺失 3：元认知监控层（P1）

MKE 应提供"知识完备性评分"——不仅返回知识，还告诉 LLM：
```json
{
  "knowledge_completeness": 0.65,
  "knowledge_gaps": ["未覆盖 A", "未覆盖 B"]
}
```

### 贡献 3：经验记忆作为第五类记忆

当前四类记忆（语义/情景/程序性/工作）缺少**经验记忆**——从成功/失败中提炼的策略模式。建议新增 `Experience` 表作为独立知识类型。
