# 开放生态与模型路由

## OpenAI 的开放生态战略

OpenAI 明确表态：**"Codex 绝不能成为一个只有 OpenAI 才能持续改进的封闭产品"**

### 核心原则

- 整个技术栈每一层，OpenAI 自己使用的，就是提供给开发者的同一套能力
- **不搞双轨制**：不做"自己一套、开发者一套"
- Codex Harness 已开源，允许开发者 Fork、修改、替换模型
- 插件接口、Apps Server 等全部开放，可查看源码、获得灵感并自定义

### 对开发者的启示

没有"唯一的 AI 大神"。未来没有单一模型能统治一切，能力体现在为不同任务匹配合适的模型。

## 模型路由策略

建立**模型路由层（Model Router）**：

| 任务类型 | 推荐模型 | 选择理由 |
|---------|---------|---------|
| 简单 CRUD / 代码补全 | GPT-5.6 Sol | 极快（750 Token/s）、极便宜，10 秒完成 PR |
| 复杂系统重构 / 遗留代码解读 | GPT-5.5 / Claude | 更强推理能力，虽然稍慢但质量更高 |

### 核心能力

人类的"工程能力"体现在：
1. 为不同难度的任务匹配合适的模型
2. 编写让各个 Agent 无缝衔接的**"胶水提示词（Glue Prompts）"**

## "可插拔"的 Agent 技术栈

```
┌─────────────────────────────┐
│    模型路由层               │
│  GPT-5.6 Sol ←→ GPT-5.5    │
├─────────────────────────────┤
│    Codex Harness（开源）    │
│    可 Fork、可替换模型       │
├─────────────────────────────┤
│    插件接口 + Apps Server   │
│    开放源码、可自定义        │
└─────────────────────────────┘
```

## 关键结论

远离单一供应商锁定，利用开放生态构建可组合、可演进的 Agent 工具链。真正的核心竞争力不在于绑定某个最强模型，而在于灵活编排多模型、多 Agent 协同工作的能力。
