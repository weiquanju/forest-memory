# 知识原子重定义与层级模型

## 当前定义的设计矛盾

`知识原子规范.md` 中的定义：

> 一个 .md 文件 = 一个知识原子 = 一片叶子
> 一个知识原子只阐述**一个**核心概念或操作步骤

这个定义在没有断言层时成立。但引入断言层后：

```
一篇 Leaf "A18 芯片性能分析"（一个核心概念 ✅）
  ├── {iPhone16, uses_chip, A18}       ← 可被提取为独立事实
  ├── {A18, manufactured_by, TSMC}      ← 可被提取为独立事实
  ├── {A18, perf_gain, 30%}             ← 可被提取为独立事实
  └── ...更多独立事实

"知识原子"的标签该给 Leaf 还是给 (s,p,o)？
→ 显然应该给 (s,p,o)——它才是真正不可再分的最小知识单元
→ Leaf 是知识原子 → Leaf 包含多个知识原子 → 概念崩塌
```

## 修正后的层级模型

```
Forest → Tree → Branch → Leaf → Fact Cluster → Assertion
 领域     主题    子模块    细胞      分子           原子
```

| 层级 | 生物学类比 | MKE 实体 | 定义 |
|------|----------|---------|------|
| Forest | 森林 | 知识领域 | 如 "芯片知识" |
| Tree | 树木 | 知识主题 | 如 "Apple Silicon" |
| Branch | 枝干 | 知识子模块 | 如 "A18 芯片" |
| **Leaf** | **叶子/细胞** | **知识细胞** | 一个完整、自包含的论述（一个 .md 文件） |
| **Fact Cluster** | **分子** | **知识分子** | 一组语义内聚的断言（同一话题下的关联事实） |
| **Assertion** | **原子** | **知识原子** | 单个不可再分的事实 (s, p, o) |

## 为什么 Leaf 不叫 Cell

"叶子"是 MKE 项目的核心隐喻，改变了用户认知成本太高。内部逻辑：

```
对外：Leaf = 叶子（仍是 MKE 的最小可见单元）
内部：Leaf 包含 Fact Cluster → 包含 Assertion
     概念上 Leaf 是"知识细胞"，Assertion 才是"知识原子"
```

`知识原子规范.md` 无需重命名 Leaf，但需要增加扩展预留声明：
- "原子"一词在 MKE 中有两层含义——文档级（v1.0）和事实级（v2.0）
- 这是有意为之的版本演化路径

## 为什么不需要 Tissue（组织）

Tissue 的假设：Branch 下的 Leaf 太多时需要一个中间分组层。但这个问题**已经被 Branch 本身解决**：

```
不需要 Tissue：                   加 Tissue 的问题：
Branch: "A18 芯片"                Branch: "A18 芯片"
  ├── 性能指标.md                   ├── Tissue: "性能指标"
  ├── 制造工艺.md                   │     ├── 跑分.md
  ├── 市场定位.md                   │     └── 能效.md
  ├── 跑分.md                      ├── Tissue: "制造工艺"
  ├── 能效.md                      │     ├── 制程.md
  └── ...                          │     └── 封装.md
                                   └── Tissue: "市场定位"
  Branch 设计合理时                        ├── 竞品.md
  自然聚合                             └── 定价.md

                                   每个 Tissue 仅 1-2 Leaf
                                   → 层级膨胀，信息密度不变
```

**核心原则：每一层都必须引入新的治理能力。**

| 层级 | 新增的治理能力 |
|------|--------------|
| Forest | 领域隔离 |
| Tree | 大粒度检索定位 |
| Branch | 中粒度下钻 |
| Leaf | 文档级 SSOT + 完整论述语境 |
| Fact Cluster | 检索完整性 + 簇内一致性校验 |
| Assertion | 结构化冲突检测 + 可计算性 + source_count |
| Tissue（假设） | **无**——纯分组，Branch 已覆盖 |

Tissue 不带来任何新能力，只增加复杂度。不加。
