# 断言图框架（AGF）

## 定位

断言图框架是 MKE 治理粒度从**文档级**下沉到**事实级**的架构演进方案。它不替代 MKE 的知识原子（Leaf），而是在 Leaf 之下增加两层子结构——Fact Cluster（分子）和 Assertion（原子）——使 MKE 能够在 (s,p,o) 三元组级别进行结构化冲突检测、精确检索和知识溯源。

**这不是 MKE 之外的独立系统，而是 MKE 的内部能力扩展。**

## 动机

MKE v1.0 的"知识原子"定义（一个 .md 文件 = 一个知识原子）在设计之初成立——当 MKE 只处理精心编写的知识文档时，文档是最小粒度。但当治理需要下沉到事实级别时，矛盾出现：

> 一篇 Leaf 包含多个独立事实，但 MKE 只能以整篇 Leaf 为单位做质量治理。
> 一个错误事实会拖累整篇文档；两个文档中相同的事实无法被自动识别为重复。

断言图解决的就是这个矛盾——让 MKE 的治理粒度从"这篇文章对吗"下沉到"这个事实对吗"。

## 核心原则

1. **断言是 Leaf 的索引，不是替代**——MKE 保留完整论述语境，断言帮助定位和去重
2. **每一层都引入新的治理能力**——不加无实质能力的中间层（因此不加 Tissue）
3. **结构化匹配替代语义判断**——(s,p,o) 字符串比较不需要 D4 级别的 LLM 能力
4. **永不删除原则延伸到断言级**——过时断言标记 deprecated，保留知识演化史
