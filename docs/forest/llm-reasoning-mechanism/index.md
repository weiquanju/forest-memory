# LLM 推理机制

## 定位

本森林描述大语言模型（LLM）从收到用户提问到生成响应输出前的工作原理——不是架构概述（那是 lcm 森林的职责），而是**"为什么会输出这些文字"的内部机制**。核心回答四个问题：问题如何进入模型、模型如何"环顾"上下文、文字如何逐 token 生成、以及什么是 LLM "推理"的诚实真相。

## 拟人化修辞说明

本森林在讨论中以拟人化修辞框架（"环顾""目光""视野"）描述注意力机制的数学过程。这些比喻旨在帮助理解，不代表 LLM 具有意识或人类式的思维过程。每个比喻在正文中均有对应的诚实机制说明。
