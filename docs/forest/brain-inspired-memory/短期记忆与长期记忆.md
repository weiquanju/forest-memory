# 短期记忆与长期记忆

## 定义

| 类型 | 持续时间 | 容量 | 实现机制 | 关键脑区 |
|------|---------|------|---------|---------|
| 短期记忆 | 几秒到几分钟 | 极其有限 | 神经元持续放电 | 前额叶皮层 |
| 长期记忆 | 数小时到终生 | 理论无限 | 突触结构持久改变 | 海马体 + 新皮层 |

## 短期记忆的机制

### 持续神经活动模型

- 前额叶皮层神经元在无外部刺激时**保持持续兴奋状态**，以"在线"方式维持信息
- 实现方式：局部回路循环兴奋、突触前馈与反馈、单细胞双稳态
- **容量限制**：受限于能同时兴奋的细胞群数量
- **易失性**：需要持续神经活动支持（神经活动一旦停止，信息立即丢失）

> *Goldman-Rakic, 1995, Neuron; Constantinidis et al., 2018*

## 长期记忆的机制

### 突触可塑性

- **LTP（长期增强）**：突触连接强度持续增加 → 记忆形成
- **LTD（长期抑制）**：突触连接强度持续减弱 → 记忆消退或选择性弱化
- 涉及新突触的形成和旧突触的消除

> *Bliss & Lømo, 1973, J. Physiol.; Malenka & Bear, 2004, Neuron*

### 容量基础

- 大脑有数十亿神经元 + 更庞大的突触连接数 → 可编码海量信息
- 但形成需要时间和重复来**巩固**（consolidation）
- 非所有短期记忆都能转化为长期记忆

## 容量-持久性权衡

```
短期记忆 ←────────时间────────→ 长期记忆
高精度瞬时编码              持久稳定存储
极易被干扰/覆盖             需要反复巩固
容量极小                    容量极巨大
────────────────────────────────────────
          并非线性转化，有选择性过滤
```

这一权衡在 Agent Memory 设计中直接对应"滑动窗口缓存 + 交互记忆持久化"的双层架构。
