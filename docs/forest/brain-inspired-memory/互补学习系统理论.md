# 互补学习系统理论

## 来源

**McClelland, McNaughton & O'Reilly (1995)**  
*Psychological Review*

## 核心模型

```
海马体（Fast Learning）          新皮层（Slow Learning）
─────────────────────          ─────────────────────
    学习速率：快                      学习速率：慢
    存储：事件细节                    存储：事件规律
    功能：特化（specificity）         功能：泛化（generalization）
    类比：快速缓存                    类比：长期硬盘
```

## 最新计算实现：Jun et al. (2025)

**VAE + MHN 架构**（arXiv: `2507.11393v1`）

| 组件 | 模拟 | 功能 |
|------|------|------|
| **VAE**（变分自编码器） | 新皮层 | 模式完成——泛化与重建 |
| **MHN**（现代 Hopfield 网络） | 海马体 | 模式分离——快速编码与区分 |

### 基准测试结果

- Split-MNIST 持续学习基准：**~90% 准确率**（接近 SOTA）
- 显著减少灾难性遗忘
- 表征分析验证了 VAE 与 MHN 的功能分离

## 设计启示

CLS 的"快慢互补"直接启发元知识引擎的双层设计：
- **快速层**：Interaction_Memory 表——实时记录对话（对应海马体）
- **慢速层**：Leaf 表——持久领域知识（对应新皮层）
- **巩固过程**：高频引用 + 无修正的 Interaction → 提升 Leaf 权重（个性化 PageRank）
