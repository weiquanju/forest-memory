# STDP 脉冲时序依赖可塑性

## 规则定义

```
突触前 → 突触后（前 几毫秒） → LTP（增强）
突触前 ← 突触后（滞后几毫秒） → LTD（抑制）
```

```
        LTP
         ↑
    ─────●─────→  Δt (突触后 - 突触前, ms)
         │
         ↓
        LTD
```

## 与 Hebbian 的区别

| 维度 | Hebbian | STDP |
|------|---------|------|
| 时间精度 | 定性"同时" | 毫秒级精确时序 |
| 方向性 | 相关即增强 | 前→后增强 / 后→前抑制 |
| 重复次数 | 未指定 | 需多次重复 |

## 算法功能

1. **序列学习**：根据输入信号的时间相关性调整连接
2. **因果推理**：前→后增强对应于"原因→结果"的时间顺序
3. **脉冲神经网络（SNN）训练**：STDP 是 SNN 最常用的无监督学习规则

## 局限

- 需要毫秒级精确时序匹配
- 需要**多次重复**才能产生稳定的突触变化
- 无法解释大脑如何在**单次经历**中就完成持久学习
  → 这一局限由 BTSP 弥补（参见 [BTSP](BTSP行为时间尺度可塑性.md)）
