# 预测性世界模型

## 来源

- **Ohmae & Ohmae (2024)**：arXiv: `2411.16075v2`, q-bio.NC
- **Ohmae & Ohmae (2025)**：arXiv: `2512.02419v1`, q-bio.NC

## 核心主张

新皮层和小脑尽管回路结构迥异，但共享**同一套核心计算原则**：

1. 从过去输入中**预测未来事件**
2. 通过**预测误差学习**持续更新内部的生成式世界模型
3. 世界模型（"这是什么"）被重新部署于生成运动输出（"如何行动"）

## 对记忆的激进重构

```
传统观点：记忆 = 静态存储的"数据记录"
新观点：  记忆 = 动态的生成式内部模型
         回忆 = 对该模型的"查询与重建"
```

大脑本质上在持续构建、更新和使用一个**内部模拟器**来指导行为与决策。

## 对 Agent 的启发

Agent 的理想形态不应是"查询知识库 + 执行指令"，而是维护一个**内部任务模型**：
- 知道"当前项目处于什么状态"
- 预测"下一步最需要什么知识"
- 在内部模拟决策 → 再对外执行

这与元知识引擎的"渐进式检索+裁决迭代"的闭环设计方向一致。
