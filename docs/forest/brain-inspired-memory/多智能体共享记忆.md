# 多智能体共享记忆

## 来源

**Yi et al. (2026)**  
*Social Hippocampus Memory Learning* (SoHip)  
arXiv: `2603.25614v1`

## 核心创新

传统联邦学习共享**模型参数**或**中间表示** → 通信开销大、隐私风险高。

SoHip 借鉴海马体记忆机制，改为共享**轻量级"记忆"**：

```
智能体 A                      智能体 B
────────                      ────────
本地表征                      本地表征
  ↓                             ↓
提取短期记忆                  提取短期记忆
  ↓                             ↓
海马体式巩固 → 个体长期记忆    海马体式巩固 → 个体长期记忆
  ↓                             ↓
  └──── 集体聚合 ────┘
           ↓
     融合后的集体长期记忆 → 增强每个智能体的本地预测
```

## 实验结果

相比传统方法**最高提升 8.78% 准确率**（摘要中明确记载）。

## 对 Agent 生态的启示

在"CEO-子公司"协作模型中（参见 [aic/CEO-子公司协作模型](../../ai-collaboration/CEO-子公司协作模型.md)），多个 Worker Agent 之间应有共享记忆层：
- 每个 Worker 有独立的 Interaction_Memory（个体经验）
- 共享 Leaf 表（集体知识）
- 通过个性化 PageRank 区分"通用知识"和"个体经验"
