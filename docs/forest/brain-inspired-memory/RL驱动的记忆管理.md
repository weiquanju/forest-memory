# RL 驱动的记忆管理

## 来源

**Wang et al. (2025)**  
*Mem-α: Learning Memory Construction via Reinforcement Learning*  
arXiv: `2509.25911v1`, cs.CL

## 核心思路

传统 AI 记忆系统依赖人工设定策略（固定时间衰减、遗忘阈值等）。Mem-α 提出让智能体通过 **RL 自主学习**存储、更新和检索策略。

## 三组件架构

```
┌─────────────────────────────────────┐
│           Mem-α Agent               │
├──────────┬──────────┬───────────────┤
│ 核心记忆  │ 情景记忆  │  语义记忆       │
│ 长期事实  │ 对话历史  │  知识概念       │
└──────────┴──────────┴───────────────┘
         ↑ RL 策略决定何时写入/读取 ↑
```

## 学科归类限制

> Mem-α 归类于 **cs.CL**，针对 LLM agent 的**长对话任务**记忆管理，非通用 RL 智能体框架。

## 与大脑的结构性类比

| 脑机制 | Mem-α 工程对应 |
|--------|---------------|
| 多巴胺强化有用记忆 | RL 奖励信号驱动自适应存储 |
| Rac1 主动遗忘无用记忆 | RL 策略决定不存储低价值信息 |
| 海马体-皮层分工 | 核心/情景/语义记忆的三组件分离 |

注意：类比是**结构性**的，非机制上的严格对应。

## 对元知识引擎的启发

- Interaction_Memory 的 `rating` 字段可作为 RL 奖励信号
- 高频引用 + 高评分 → 提升 Leaf 权重
- 长期未引用 → 自然衰减（对应主动遗忘）
