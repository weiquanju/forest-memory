# 模式分离与模式完成

## 两大互补算法

```
编码阶段                    检索阶段
──────────              ──────────────
模式分离                  模式完成
Pattern Separation        Pattern Completion
     ↓                        ↓
将相似输入映射为             从部分线索恢复
差异极大的输出               完整记忆
     ↓                        ↓
防止记忆混淆                内容寻址存储
(DG 齿状回)                 (CA3 区域)
```

## 模式分离（编码时）

- 执行区域：**齿状回（DG）**
- 功能：将相似输入 → 差异极大的神经活动模式
- 算法对应：**哈希函数**——相近输入 → 差异输出
- 作用时机：记忆编码阶段

参见 [稀疏编码与模式分离](稀疏编码与模式分离.md) 了解 DG 的具体机制。

## 模式完成（检索时）

- 执行区域：**海马体 CA3**
- 结构：**自联想网络**（auto-associative network）
- 机制：recurrent collateral 突触连接形成**吸引子网络**（Hopfield, 1982; Rolls, 2013）
- 过程：部分线索输入 → 循环连接收敛到存储的完整模式
- 算法对应：**内容寻址存储（CAM）** 的读取过程

## 协同示例

回忆一个人的名字：

```
1. 模式分离（DG）：将"John"和"Joan"两个相似名字区分开
2. 模式完成（CA3）：根据部分线索（看到了脸）→ 收敛到 "John"
```

## 对元知识引擎的启发

| 脑机制 | 工程对应 |
|--------|---------|
| DG 模式分离 | 知识原子单一职责（防止语义重叠） |
| CA3 模式完成 | 渐进式检索的图扩散（从部分原子恢复完整知识链） |
