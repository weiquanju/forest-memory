# 多模态记忆整合

## 挑战

记忆通常是多模态的——同时包含视觉、听觉、触觉信息。大脑必须在编码时**绑定**不同感官通道，在检索时**保持一致性**。

## 编码阶段

- 多模态信息汇聚到**内侧颞叶**（含海马体）和前额叶皮层
- 海马体将不同感官线索绑定到一个记忆中
- 形成**跨模态记忆印迹（cross-modal engram）**
- 例：学习时同时看到图片 + 听到声音 → 日后只需一种线索即可回忆另一部分

## 检索阶段

- CA3 的模式完成机制可处理**不完整的多模态线索**
- 例：只闻到咖啡香 → 海马体仍能通过模式完成找到完整记忆（包括视觉和味觉）
- 算法上：不同模态特征向量拼接后存入同一记忆，部分输入通过部分匹配找到完整记忆

## 对 Agent 的启发

Agent 的上下文也应支持多模态：
- 代码 AST（结构化） + 文档 Markdown（半结构化） + 对话历史（非结构化）
- 统一存入元知识引擎时，使用相同的知识原子 Schema
- 检索时通过向量匹配跨模态召回相关知识原子
