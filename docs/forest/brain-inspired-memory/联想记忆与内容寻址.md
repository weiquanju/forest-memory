# 联想记忆与内容寻址

## 定义

**内容寻址存储（Content-Addressable Memory, CAM）**：

> 通过内容的一部分来定位完整数据，而非通过预先分配的地址。

## 生物实现：CA3 网络

```
部分线索（比如闻到咖啡香）
        ↓
   激活 CA3 中与该线索相关的部分神经元
        ↓
   CA3 的循环连接（recurrent collaterals）将活动扩散
        ↓
   网络收敛到存储的完整记忆模式（喝咖啡的情景）
        ↓
   "我想起来了！" ← 视觉+味觉+场景 全部恢复
```

能量景观类比：CA3 的每个存储记忆是能量函数的局部极小值，输入线索后网络沿能量梯度下降，收敛到最近的存储模式。

## 算法抽象：键值记忆模型

```
海马体（CA3）         新皮层
─────────────       ──────────
   键（Key）    →      值（Value）
 检索线索/索引         记忆内容

检索过程：
  查询 → 在海马体中匹配键 → 从新皮层提取对应的值
```

这与 Transformer 的 Q-K-V 机制同构——查询（Q）与键（K）点积定位信息 → 从值（V）读取内容。

> Gershman et al., 2025, arXiv: `2501.02950v2`

## 三种寻址方式对比

| 寻址方式 | 生物对应 | AI 对应 |
|---------|---------|--------|
| 地址寻址 | — | RAM 按内存地址读取 |
| **内容寻址** | CA3 吸引子网络 | CAM、Hopfield 网络 |
| **键值寻址** | 海马体索引+皮层存储 | Transformer KV 机制 |

## 对元知识引擎的启发

元知识引擎的检索策略正是"内容寻址"的工程实现：
- `retrieve(query)` = Q（查询）
- 向量余弦相似度 = 在海马体中匹配键
- 1-hop 图扩散 = 激活关联记忆
- 返回完整知识原子 = 从新皮层提取值
