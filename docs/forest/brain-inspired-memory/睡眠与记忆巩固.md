# 睡眠与记忆巩固

## SWR：海马-皮层对话

### 机制

在 **NREM 睡眠**期间：

1. 海马体产生**尖波涟漪（Sharp-Wave Ripple, SWR）**
2. 以**压缩时间尺度**"重放"清醒时的神经活动序列
3. 位置细胞按照探索顺序再次依次放电
4. 同时驱动新皮层相关区域的同步激活
5. 海马体通过反复重放将记忆痕迹"教给"新皮层

> *Buzsáki, 2015; Girardeau & Zugaro, 2011, Nat. Neurosci.*

### 与 CLS 的关系

SWR 的"海马→皮层重放"正是 CLS 系统巩固的细胞层面实现——海马体快速学习 → 睡眠中重放 → 新皮层逐渐形成稳定表征。

## 开放问题

1. **SWR 的选择性**：为何某些记忆被优先重放？选择标准是什么？
2. **REM vs NREM 分工**：NREM（慢波睡眠）的 SWR 重放 vs REM 睡眠在记忆巩固中的具体角色

## 对 Agent 的启发

Agent 应有"离线巩固阶段"：
- 每日定时任务：扫描 Interaction_Memory，将高频引用的交互模式固化为知识原子
- 对应 SWR 的"选择性重放"——不是所有交互都被巩固，而是按频率/评分筛选
- 元知识引擎第五层（治理校验层）的"每日死链检测"就是这一机制的工程实现
