# 情感对记忆的调控

## 核心现象

情感唤起事件被**更生动、更持久**地记住——如大多数人能清晰回忆"9·11"事件发生时自己在哪里。

## 神经基础

```
情绪刺激
    ↓
激活杏仁核（amygdala）
    ↓
释放去甲肾上腺素（norepinephrine）
    ↓
直接增强海马体中相关记忆痕迹的编码和巩固
```

> *McGaugh, 2000, Science*

## 算法解读

从算法角度看，这相当于大脑为**高情感显著性的经历**赋予更高的**"存储优先级"**——一种由价值信号驱动的自适应记忆管理策略。

## 与 RL 驱动的记忆管理的联系

| 生物机制 | AI 对应 |
|---------|--------|
| 杏仁核去甲肾上腺素 | RL 高奖励信号 → 增加存储概率 |
| 多巴胺驱动的主动遗忘 | RL 低奖励信号 → 不存储/衰减 |
| 情感显著性 | Interaction_Memory 的 `rating` 字段 |

## 对 Agent 的启发

用户提供的显式反馈（"正确"/"错误"）可被视为"情感标记"：
- `rating: 5` → 高显著性 → 优先写入知识原子
- `rating: 1` → 低显著性 → 标记为待修正/遗忘
