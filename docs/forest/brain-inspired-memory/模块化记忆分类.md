# 模块化记忆分类

## 四类记忆对照

| 类型 | 内容 | 关键脑区 | 意识参与 | 持久性 |
|------|------|---------|---------|--------|
| **情景记忆** | 特定事件（时间、地点、细节） | 海马体 + 内侧颞叶 | 需要 | 可衰退 |
| **语义记忆** | 一般知识和事实 | 新皮层（颞叶、额叶联合皮层） | 需要 | 较稳定 |
| **程序性记忆** | 技能和习惯 | 基底神经节 + 小脑 | 不需要 | 终身保留 |
| **工作记忆** | 当前任务在线信息 | 前额叶皮层 | 需要 | 秒级 |

## 情景记忆（Episodic）

- 海马体在编码阶段**绑定**情景各要素
- 检索阶段通过**模式完成**激活分布于新皮层的记忆内容
- "海马体索引、新皮层存储"的分工最早由 Teyler & DiScenna（1986）提出——**海马记忆索引理论**
- 在 KV 框架中被抽象为：海马体编码"键"（索引），新皮层存储"值"（内容）

## 语义记忆（Semantic）

- 抽象的、去情境化的知识
- 在新皮层中通过与感觉、运动等区域的广泛联系形成稳定表征
- 海马体在早期形成中起作用，但随巩固逐渐独立于海马体
- **Agent 映射**：元知识引擎的 Leaf 节点存储的正是"语义记忆"

## 程序性记忆（Procedural）

- 运动学习和模式自动化
- 不需要意识参与，一旦习得往往终身保留
- 与情景/语义记忆的皮层机制完全不同
- **Agent 映射**：Agent 的 prompt 模板、调度规则、胶水提示词——可以理解为"程序性记忆"

## 工作记忆（Working Memory）

- 临时缓存系统，非持久存储
- 前额叶皮层对信息的主动维持和操作
- 容量受前额叶网络动态调控
- **Agent 映射**：对话中的滑动窗口缓存——保留最近 N 轮交互上下文

## 对 Agent Memory 设计的启示

大脑通过模块化将不同类型信息分配给不同脑区 → Agent Memory 也应区分情景记忆（Interaction_Memory 表）、语义记忆（Leaf 表）、程序性记忆（Prompt 模板/规则）。
