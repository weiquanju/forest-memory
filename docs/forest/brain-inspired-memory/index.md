## 核心原则（来自原文）

1. **分层存储**：大脑采用类似计算机的多级存储架构（感觉记忆→短期记忆→长期记忆）
2. **模块化分工**：不同类型的记忆由不同脑区专业处理
3. **稀疏编码**：只用约 9% 的神经元编码单个记忆，最大化容量
4. **模式完成**：从部分线索恢复完整记忆——内容寻址存储
5. **键值分离**：海马体索引 + 新皮层内容 = 生物 KV 存储
6. **动态更新**：记忆提取时进入不稳定窗口，可被修改后再巩固
