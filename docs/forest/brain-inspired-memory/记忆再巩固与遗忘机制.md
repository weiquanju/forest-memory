# 记忆再巩固与遗忘机制

## 再巩固（Reconsolidation）

### 机制

```
记忆被提取 → 进入不稳定窗口 → 可被修改 → 重新稳定
```

### 算法对应：在线学习

每次查询记忆时，系统对相关记忆进行一次"微调"以适应当前环境。

**对 Agent Memory 的启示**：`Interaction_Memory` 表中用户修正的答案应覆盖原始知识——这正是"再巩固"的工程实现。

## 被动遗忘：突触资源竞争

### 机制

- 突触可塑性依赖有限分子资源（PRPs、代谢能量）
- 诱导 LTP 时，邻近未激活突触经历**异突触 LTD**
- Karbowski（2019）代谢模型：突触可塑性仅消耗总能量预算的 **4-11%**

### 算法对应：写入即覆盖

资源受限系统中，新学习挤压旧记忆的维持——确保系统不会无限积累过载。

## 主动遗忘：分子通路

### 通路 1：Rac1-Cofilin

- 多巴胺 → 激活 Rac1 → 促使相关记忆痕迹的突触连接减弱
- Shuai et al., 2010, *Cell*（首次发现）
- Davis & Zhong, 2017, *Neuron*（完整通路阐明）

### 通路 2：成年神经发生

- 齿状回持续产生新神经元
- 新神经元整合入回路 → 旧记忆痕迹被"稀释"
- Akers et al., 2014, *Science*

### 算法对应：权重衰减 / 剪枝

系统主动降低不常用连接的权重，优化整体资源分配。

## 对 Agent Memory 的设计启示

| 脑机制 | 工程对应 |
|--------|---------|
| 再巩固 | 用户修正覆盖原始知识 |
| 资源竞争 | Token 预算约束 + 旧记忆摘要压缩 |
| 主动遗忘 | 个性化 PageRank 中权重自然衰减 |
| 检索失败（而非擦除） | 沉默印迹——知识还在，只是检索路径被遮蔽 |

注意：KV 框架（Gershman et al., 2025）的核心观点——**检索失败而非记忆擦除是遗忘的主要原因**——提示我们在 Agent Memory 中应该保留所有交互记录，仅通过权重/索引来管理可访问性，而非真正删除数据。
