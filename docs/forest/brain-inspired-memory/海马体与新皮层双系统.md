# 海马体与新皮层双系统

## 核心类比

```
海马体  ≈  计算机的快速缓存
新皮层  ≈  计算机的硬盘存储
```

## 海马体：快速学习系统

| 属性 | 特征 |
|------|------|
| 学习速率 | **快**——能迅速编码新经历 |
| 存储内容 | 情景记忆的细节（时间、地点、关联） |
| 容量 | 有限，记忆痕迹随时间衰退 |
| 角色 | 记忆形成的早期阶段——短期记忆最初在此形成 |

### 关键证据：患者 H.M.

- 切除海马体后 → **丧失了形成新长期记忆的能力**
- 但保留了手术前的童年记忆
- 证明：海马体是记忆编码和转移的关键"中转站"

## 新皮层：慢速学习系统

| 属性 | 特征 |
|------|------|
| 学习速率 | **慢**——需要数周到数年 |
| 存储内容 | 去情境化的泛化知识 |
| 容量 | 巨大且持久 |
| 角色 | 通过系统巩固逐步接收海马体传递的记忆 |

### 泛化能力

新皮层从多次经历中提取共性，形成稳定认知模型：
- 重复性日常经历 → 整合为一般知识进入新皮层
- 独特事件细节 → 长期保留在海马体作为特定情景记忆

## 系统巩固过程

```
编码阶段              巩固阶段              检索阶段
──────────        ──────────────        ──────────
海马体快速编码  →  反复重放激活新皮层  →  旧记忆可能不依赖海马体
  (秒-分)          (周-年)              (直接皮层检索)
```

这一过程在睡眠中通过 **SWR 尖波涟漪** 的"海马-皮层对话"完成（参见 [睡眠与记忆巩固](睡眠与记忆巩固.md)）。

## 与 CLS 理论的关系

海马体（快速学习）+ 新皮层（慢速学习）构成了**互补学习系统（CLS）** 的核心。这一双系统架构启发我们为 Agent Memory 设计"快速索引缓存 + 持久知识库"的分层架构——元知识引擎的第四层（记忆融合层）即借鉴了这一设计。
