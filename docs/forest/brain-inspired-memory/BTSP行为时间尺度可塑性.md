# BTSP 行为时间尺度可塑性

## 发现

**Bittner et al., 2017, *Science***  
DOI: `10.1126/science.aan3846`

海马体 CA1 区位置细胞在探索新环境时，位置场的形成并非依赖 Hebbian 或 STDP，而是由 BTSP 驱动。

## 核心机制

### 树突钙离子平台电位

1. CA1 锥体细胞远端树突产生大幅持久的 **Ca²⁺ 平台电位**
2. 该信号在**秒级时间窗口**内，将窗口内所有活跃的突触输入**一次性增强**

### 时间窗口（原文 Fig. 2G）

```
上升时间 ≈ 4 秒
衰减时间 ≈ 3 秒
总窗口  ≈ 7 秒（非对称）
```

> "risetime = ~4 s, decay time = ~3 s; Fig. 2G"  
> 后续计算模型为简化分析常近似为对称窗口（Wu & Maass, 2025）

## 与 STDP 的本质区别

| 维度 | STDP | BTSP |
|------|------|------|
| 时间尺度 | 毫秒级 | 秒级 |
| 重复需求 | 多次重复 | **单次经历**即可 |
| 增强范围 | 特定突触 | 窗口内**全部活跃突触** |
| 信号依赖 | 精确的突触前后放电时序 | 树突平台电位 |
| 功能场景 | 精细时序调谐 | 一次性创建宏观记忆痕迹 |

## 后续研究

- **Wu & Maass (2025, *Nature Communications*)**：BTSP 计算模型，证明其能解释 CA1 位置场的一次性快速形成——传统模型无法重现
- **Magee (2026, *Nature Neuroscience*)**：综述 BTSP 广泛存在于海马体 CA1 及其他脑区

## 多时间尺度分工

```
STDP (毫秒)     →  序列学习、因果推理
BTSP (秒)       →  关键时刻一次性创建记忆痕迹
Hebbian (基础)  →  联想记忆的基本原则
```

**关键启示**：对 Agent Memory 而言，重要的"关键时刻"信息（如用户明确修正、架构决策）应以类似 BTSP 的"一次写入"高优先级存储，而非等多次交互累积。
