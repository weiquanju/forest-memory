# 稀疏编码与模式分离

## 稀疏分布式编码

在每个记忆事件中，只有**一小部分**神经元被激活，大部分保持静默。

### 两大优势

1. **大容量**：不同记忆的神经表征重叠度极低
2. **抗干扰**：即使部分神经元受损，整体记忆仍可被检索

## 齿状回（DG）的关键角色

### 实验数据

| 来源 | 发现 | 脑区对比 |
|------|------|---------|
| GoodSmith et al., 2017, *Neuron* | DG 颗粒细胞仅 ~**9%** 活跃 | 苔藓细胞 88%、CA3 29% |
| Diamantaki et al., 2016, *eLife* | 颗粒细胞稀疏发放的定性验证 | — |

### 计算模型假设

为突出模式分离效应，网络模型通常假设更极端的稀疏水平：约 **2-5%** 激活率（Hainmueller & Bartos, 2020, *Nat. Rev. Neurosci.*）

### 模式分离机制

```
相似输入 A、B
      ↓
齿状回去相关处理（正交编码）
      ↓
输出 A' 和 B' —— 神经活动模式差异极大
      ↓
防止记忆混淆
```

在算法上类似于**哈希函数**或**正交编码**——将相近输入映射为差异巨大的输出。

## 对元知识引擎的启发

- 知识原子的**单一职责原则** = 文档级的稀疏编码
- 每个知识原子独立存储一个概念 → 不同原子间重叠度低 → 检索时抗干扰
- 引用机制避免了"知识混淆"（交叉声明）
