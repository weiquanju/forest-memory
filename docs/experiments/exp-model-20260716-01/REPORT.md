# 实验报告：exp-model-20260716-01

## 不同模型对知识森林生成质量的影响——维度1对照实验

> **实验日期**: 2026-07-16
> **实验维度**: 维度1（不同模型对照）
> **被测模型**: DeepSeek V4 Flash (AAI 40) / DeepSeek V4 Pro (AAI 44) / GLM-5.2 (AAI 51)
> **固定变量**: CodeBuddy v4.10.2 / bim_source + frs_source + arXiv:2404.13501 / forest-generation-methodology v1.0.0
> **评审方法**: forest-quality-reviewer v1.0.0（5维度评审体系，交叉评审矩阵）

---

## 1. 执行摘要

本实验验证了 **Artificial Analysis Intelligence Index (AAI) 与知识森林生成质量之间的定量关系**。在固定工具、输入资料和方法论的条件下，三个不同能力等级的 LLM（AAI 40/44/51）对同一份多源资料执行知识森林生成，产出经交叉评审矩阵（6 组评审）量化评估。

**核心结论**：

1. **综合评分随 AAI 线性增长**：5.8 → 6.9 → 8.2（AAI 40→44→51），每提升 1 分 AAI 约对应 0.17 分质量提升
2. **D4 批判性分析是区分度最高的维度**：3→5→7，增幅最大（+2/+2），印证"Scientific Reasoning 需 >55 分才显著分化"的推断
3. **D1 引用真实性存在门槛效应**：AAI 40 即达 8/10（0 虚构引用），后续提升幅度很小
4. **评审者间信度极高**：18 个评分点中 17 个完全一致（94.4%），验证了评审方法论的有效性
5. **GLM-5.2 (AAI 51) 在所有维度全面领先**，D4 达 7/10 表明其 Scientific Reasoning 已接近"深度批判性分析"门槛

- 新会话上下文干净清洁，不继承历史
- 森林结构由各模型独立设计（同 Forest ID: memory-systems-ai，但 Branch/Leaf 组织不同）

### 2.3 交叉评审矩阵

```

dsv4flash        ✗ 跳过      ✓         ✓
```

## 4. 关键发现

### 4.1 发现一：D4 批判性分析是区分模型能力的核心维度

D4 是三个模型间区分度最高的维度：

```
D4 评分变化:  3.0 ──→ 5.0 ──→ 7.0
AAI:          40      44      51
增幅:           +2.0    +2.0   ← 各段增幅最大
```

**对应 AAI 能力维度**：Scientific Reasoning（HLE + GPQA Diamond + CritPt，权重 24%）

**解读**：
- AAI 40 的 dsv4flash 几乎无批判性分析——70% 叶子正文不足 200 字，无方法对比、无局限讨论、无学术张力
- AAI 44 的 dsv4pro 有所改善——引入对比表格和部分局限讨论，但深度仍有限
- AAI 51 的 glm52 显著跃升——呈现 CLS vs KV 学术张力、讨论"毒性累积"深层矛盾、提出可操作开放问题

**门槛推断**：D4 在 AAI <55 区间为缓慢增长，>55 分后预期显著分化。glm52 (51) 的 7/10 可能仍处于增长斜坡上，尚未到达平台期。

### 4.2 发现二：引用真实性存在能力门槛效应

```
D1 评分:  8.0 ──→ 8.5 ──→ 9.0
AAI:      40      44      51
增幅:       +0.5    +0.5   ← 增幅最小，趋于饱和
```

**关键事实**：三个模型均实现 0 虚构引用。AAI 40 即达到 8/10（可用水平），后续提升仅体现在引用标识符的完整性上（arXiv ID/DOI 标注率从 ~60% → ~80% → ~95%）。

**实践意义**：引用真实性验证（"论文是否存在"）的能力门槛较低，~40 分即满足。模型路由时可将此任务分配给低成本模型。

### 4.3 发现三：层级组织能力在低能力段即接近饱和

```
D3 评分:  7.0 ──→ 8.0 ──→ 9.0
AAI:      40      44      51
```

三个模型在 Forest → Tree → Branch → Leaf 的结构化组织上差异不大。AAI 40 的 dsv4flash 虽然内容深度严重不足，但其三棵树的顶层划分逻辑清晰。主要差异体现在：
- 跨树引用是否下沉到叶子级（dsv4flash ❌ / dsv4pro ✅ / glm52 ✅）
- 树级 index.md 是否完整（dsv4flash 缺 / dsv4pro ✅ / glm52 ✅）
- 叶子粒度是否均匀

### 4.4 发现四：评审者间信度验证了方法论有效性

18 个评分点中 17 个完全一致（94.4%），仅 dsv4pro 的 D1 存在 1 分差异。这一极高的一致性表明：

1. `forest-quality-reviewer` skill 的评分标准设计有效——不同能力等级的评审者（AAI 40/44/51）能达成高度一致的判断
2. 评审能力门槛可能低于生成能力门槛——AAI 40 的评审者能可靠地评价 AAI 51 的产出
3. "评价他人"作为元任务，其能力要求可能低于"生成高质量内容"

### 4.5 发现五：内容深度与 AAI 的非线性关系

| 指标 | dsv4flash (40) | dsv4pro (44) | glm52 (51) |
|------|:---:|:---:|:---:|
| 平均每叶子行数 | ~27 | ~42 | ~52 |
| 平均每叶子字数 | ~100-200 | ~300-500 | ~500-800 |
| 对比表格数 | 0 | 多个 | 多个 |
| 开放问题讨论 | 0 | 少量 | 多个 |
| 学术张力呈现 | 0 | 1处(CLS vs KV) | 多处 |

内容深度（行数/字数/结构化程度）随 AAI 增长，但**单位 AAI 的内容深度增幅在 44→51 段显著大于 40→44 段**——这与 D4 的陡峭增长模式一致。

## 6. 各模型详细评价

### 6.1 DeepSeek V4 Flash (AAI 40) — 综合 5.8/10

**定位**：快速建库级模型——覆盖广度尚可但深度严重不足

**优势**：
- 引用真实性达标（D1=8.0，0 虚构引用）
- 顶层结构清晰（D3=7.0，三棵树递进逻辑正确）
- 生成效率最高（45 min，每叶子 1.73 min）

**劣势**：
- D4 批判性分析仅 3.0——70% 叶子正文 <200 字，无方法对比/局限/张力
- D2 引用准确性 6.0——方法名错误（PoG）、元数据不完整
- D5 学术规范 5.0——refs 格式不统一、跨树引用未下沉
- 关键性能数据大量丢失（PoG +18.9%、EWC -45.7% 等均未纳入）

**适用场景**：快速生成知识森林骨架，后续需高能力模型深度补充

### 6.2 DeepSeek V4 Pro (AAI 44) — 综合 6.9/10

**定位**：校验级模型——结构化组织良好但批判深度有限

**优势**：
- 跨树引用下沉到叶子级 ✅
- 树级 index.md 完整 ✅
- 方法对比表格丰富（Mem0/MemVerse/DYNA、WilKE/PRUNE/STABLE 等）
- 方法名全部正确（无 dsv4flash 的 PoG 命名错误）
- 引用标识符较完整（~80% 标注 arXiv ID）

**劣势**：
- **2 个空文件**（graphrag-multi-hop-reasoning.md, sparse-coding-pattern-separation.md）——严重影响完整性
- D4 批判性分析 5.0——有对比表但缺深层学术张力和反例讨论
- 部分叶子缺 version 字段
- .experiment_metadata.yaml 不完整（缺 comparison_dimension 等字段）

**适用场景**：中等质量知识森林生成，需修复空文件后可用于生产

### 6.3 GLM-5.2 (AAI 51) — 综合 8.2/10

**定位**：深化级模型——全面领先，接近深度批判性分析门槛

**优势**：
- D4 批判性分析 7.0——显著优于前两者
  - CLS vs KV 学术张力明确呈现
  - "毒性累积"深层矛盾讨论
  - 可操作开放问题（"推理深度边际收益递减——更多步骤何时变成有害的冗长？"）
  - 科学诚实（标注"推测性假说""非主流解释"）
- D3 层级组织 9.0——T3 四分支覆盖最全，叶子粒度均匀
- D5 学术规范 8.0——元数据质量最高，forest/index.md 含 model/experiment 字段
- 跨树引用格式标准化（`[tree_id-branch_id] 文档名 | 引用原因`）
- 0 空文件，29 个 .md 文件全部有内容

**劣势**：
- 部分叶子缺少 version 字段
- forest/index.md 的 refs 为空列表
- T1 将"检索算法"和"理论框架"合并为一个 Branch（语义跨度偏大）
- 部分叶子仍以描述为主（如 l1-multi-timescale-plasticity）

**适用场景**：高质量知识森林生成，可直接用于生产环境

## 7. 评审者偏差分析

### 7.1 偏差风险矩阵

| 评审配对 | AAI差值 | 偏差风险 | 实际影响 |
|---------|:---:|:---:|---------|
| dsv4pro(44) → dsv4flash(40) | +4 | 中 | 同族模型，评测风格相似，可能偏宽松 → 实际评分与 glm52 完全一致，无偏差 |
| glm52(51) → dsv4flash(40) | +11 | 低 | 不同家族，能力差距大 → 评分与 dsv4pro 完全一致 |
| dsv4flash(40) → dsv4pro(44) | -4 | 低 | 同族但能力略低 → D1 评 8 分，glm52 评 9 分，差 1 分 |
| glm52(51) → dsv4pro(44) | +7 | 低 | 不同家族 → D2-D5 完全一致 |
| dsv4flash(40) → glm52(51) | -11 | 高 | 能力显著低于被评审者 → 实际评分与 dsv4pro 完全一致，偏差未 materialize |
| dsv4pro(44) → glm52(51) | -7 | 中 | 能力低于被评审者 → 评分与 dsv4flash 完全一致 |

### 7.2 偏差分析结论

**关键发现**：尽管 6 组评审中有 4 组存在"评审者能力低于被评审者"的情况（偏差风险中-高），但实际评分表现出极高的一致性。这可能表明：

1. `forest-quality-reviewer` skill 的评分标准足够明确，降低了评审者主观偏差
2. "评价他人产出"的能力门槛可能低于"生成高质量产出"的能力门槛
3. 5 维度评分体系（0-10 分制）提供了足够的分辨率，使不同能力的评审者能达成共识

**唯一差异**：dsv4pro 的 D1 评分存在 1 分差异（dsv4flash 评 8，glm52 评 9）。glm52 更充分地验证了引用标识符完整性后给予更高分——这反映了更高能力评审者对"可验证性"的更细致评估。

## 8. 局限性声明

### 8.1 实验设计局限

1. **样本量有限**：仅 3 个模型，每个模型单次生成，无法进行统计显著性检验
2. **AAI 覆盖范围**：40-51 分区间，缺少 >55 分的高能力模型数据点，无法验证"55 分后显著分化"的推断
3. **单一森林主题**：所有模型生成同一主题（memory-systems-ai）的森林，可能存在主题特异性
4. **同族模型偏差**：dsv4flash 和 dsv4pro 来自同一模型家族（DeepSeek），可能共享某些系统性偏好

### 8.2 评审局限

1. **抽样评审**：每位评审者仅抽样阅读 6-8 个叶子（24-38%），可能遗漏未发现的问题
2. **引用审计不完整**：未使用 arxiv-mcp-server 逐条验证所有引用，部分传统期刊引用仅通过来源材料交叉验证
3. **D4/D5 主观性**：批判性分析和学术规范的评分包含评审者主观判断
4. **交叉声明检测未量化**：D3 的单一职责评估基于人工判断，未运行 sentence-transformers 量化检测

### 8.3 已知数据质量问题

1. **dsv4pro 的 2 个空文件**：`graphrag-multi-hop-reasoning.md` 和 `sparse-coding-pattern-separation.md` 为 0 字节，导致 dsv4pro 的 D1-D5 评分可能偏低（若补充内容后评分可能上升）
2. **dsv4flash 的内容深度**：大量叶子仅 3-5 行正文，D4 评分 3/10 可能已触底——无法区分"差"和"极差"

## 9. 结论与建议

### 9.1 核心结论

1. **AAI 与知识森林质量呈正相关**：综合评分 5.8 → 6.9 → 8.2，验证了模型能力对知识抽取质量的正向影响

2. **五维度呈现三种不同的能力响应模式**：
   - 门槛效应（D1）：~40 分即达可用水平
   - 近似线性（D2/D3/D5）：持续改善
   - 陡峭增长（D4）：**区分"能用"和"优秀"的分水岭**，>55 分预期显著分化

3. **交叉评审方法论有效**：94.4% 的评分点完全一致，验证了 `forest-quality-reviewer` skill 的评分标准化设计

4. **GLM-5.2 (AAI 51) 是本实验中最优的知识抽取模型**：在所有 5 个维度上均不低于其他模型，D4 达 7/10 表明其 Scientific Reasoning 已接近深度批判性分析门槛

### 9.2 对后续实验的建议

| 优先级 | 建议 | 理由 |
|:---:|------|------|
| **P0** | 补充 AAI >55 的模型数据点（如 Claude Sonnet 4.6 / Opus 4.7） | 验证"55 分后 D4 显著分化"的推断 |
| **P0** | 修复 dsv4pro 的 2 个空文件后重新评审 | 消除空文件对评分的负面影响 |
| **P1** | 使用 arxiv-mcp-server 逐条验证所有引用 | 将 D1 置信度从 Medium 提升到 High |
| **P1** | 运行 sentence-transformers 量化交叉声明检测 | 将 D3 的单一职责评估从主观转为客观 |
| **P2** | 扩展到不同主题的森林（验证主题无关性） | 排除 memory-systems-ai 主题的特异性 |
| **P2** | 增加维度2（不同工具）和维度3（不同资料）实验 | 验证方法论对不同变量的普适性 |

### 9.3 对模型路由的实践指导

基于本实验数据，推荐以下分层模型路由策略：

```
知识森林生成 pipeline:

Stage 1: 建库（引用真实 + 层级组织）
  → 推荐 AAI ~40-44 (DeepSeek V4 Flash/Pro)
  → 成本最低，质量骨架可用
  → 本实验验证: D1=8, D3=7 (AAI 40)

Stage 2: 校验（引用准确 + 学术规范）
  → 推荐 AAI ~44-51 (DeepSeek V4 Pro / GLM-5.2)
  → 修正引用元数据，统一格式，补充跨树引用
  → 本实验验证: D2=7-8, D5=6-8

Stage 3: 深化（批判性分析 + 横向对比）
  → 推荐 AAI >51 (GLM-5.2 / 更高模型)
  → 补充方法对比、局限讨论、学术张力
  → 本实验验证: D4=7 (AAI 51)，但 >55 预期更好
```
