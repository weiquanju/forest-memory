## 不同模型对知识森林生成质量的影响——维度1对照实验

> **实验日期**: 2026-07-16
> **实验维度**: 维度1（不同模型对照）
> **被测模型**: DeepSeek V4 Flash (AAI 40) / DeepSeek V4 Pro (AAI 44) / GLM-5.2 (AAI 51)
> **固定变量**: CodeBuddy v4.10.2 / bim_source + frs_source + arXiv:2404.13501 / forest-generation-methodology v1.0.0
> **评审方法**: forest-quality-reviewer v1.0.0（5维度评审体系，交叉评审矩阵）

## 1. 执行摘要

本实验验证了 **Artificial Analysis Intelligence Index (AAI) 与知识森林生成质量之间的定量关系**。在固定工具、输入资料和方法论的条件下，三个不同能力等级的 LLM（AAI 40/44/51）对同一份多源资料执行知识森林生成，产出经交叉评审矩阵（9 份评审报告）量化评估。dsv4pro 在首轮评审后发现 2 个空文件，经修复后重新评审。

**核心结论**：

1. **综合评分随 AAI 增长**：5.8 → 7.7 → 8.2（AAI 40→44→51），每提升 1 分 AAI 约对应 0.19 分质量提升
2. **D4 批判性分析是区分度最高的维度**：3→6→7，AAI 40→44 增幅最大（+3），44→51 增幅放缓（+1），印证"Scientific Reasoning 需 >55 分才再次显著分化"
3. **D1/D3 存在门槛效应**：AAI 40 即达 D1=8/D3=7，AAI 44 即达 D1=9/D3=9，后续提升幅度趋于零
4. **评审者间信度极高**：24 个评分点中 22 个完全一致（91.7%），验证了评审方法论的有效性
5. **dsv4pro 修复验证了"质量损失 vs 能力不足"的区分**：修复 2 个空文件使综合分从 6.9→7.7（+0.8），这 0.8 分来自工程缺陷而非模型能力不足
6. **GLM-5.2 (AAI 51) 在所有维度全面领先**，D4 达 7/10 表明其 Scientific Reasoning 已接近"深度批判性分析"门槛

- 每个 subject 在独立 git worktree 中工作，物理隔离

```

                dsv4flash   dsv4pro   glm52
```

## 4. 关键发现

### 4.1 发现一：D4 批判性分析是区分模型能力的核心维度

D4 是三个模型间区分度最高的维度：

```
D4 评分变化:  3.0 ──────→ 6.0 ──→ 7.0
AAI:          40          44      51
增幅:           +3.0        +1.0
              ↑               ↑
         最大增幅         增幅放缓
```

**对应 AAI 能力维度**：Scientific Reasoning（HLE + GPQA Diamond + CritPt，权重 24%）

**解读**：
- AAI 40→44 的 +3 增幅远大于其他维度的增幅（+1~2），表明 Scientific Reasoning 在 40-44 区间有显著跃升
- 但 AAI 44→51 的增幅放缓至 +1，暗示 44-55 区间为"增长平台期"
- 推断 **>55 分后 D4 将再次显著分化**——这需要 AAI>55 的模型数据验证

**门槛推断**：D4 呈"双阶梯"增长模式——40→44 为第一阶梯（+3），44→55 为平台期（+1/7分AAI），>55 为第二阶梯（预期+2+）。

### 4.2 发现二：引用真实性和层级组织存在能力门槛效应

```
D1 评分:  8.0 ──→ 9.0 ──→ 9.0   （AAI 40→44→51）
D3 评分:  7.0 ──→ 9.0 ──→ 9.0   （AAI 40→44→51）
```

**关键事实**：
- D1 在 AAI 40 即达 8/10（0 虚构引用），AAI 44 即达 9/10，之后不再提升
- D3 在 AAI 44 即达 9/10，之后不再提升
- 门槛效应意味着这些维度的能力饱和点较低，~40-44 分即满足

**实践意义**：引用真实性验证和结构化组织可分配给 AAI 40-44 的低成本模型。

### 4.3 发现三：dsv4pro 修复揭示了"质量损失 vs 能力不足"的区分

dsv4pro 修复 2 个空文件后综合分从 6.9→7.7（+0.8），这 0.8 分的提升完全来自工程修复，而非模型能力变化：

| 维度 | 修复前 | 修复后 | 提升来源 |
|------|:---:|:---:|---------|
| D3 +1.0 | 结构不完整 | 结构完整 | 工程修复（非能力） |
| D4 +1.0 | 2文件无内容 | 2文件有对比表 | 工程修复（非能力） |
| D5 +1.0 | 空文件违规 | 规范达标 | 工程修复（非能力） |

**校准结论**：修复前 dsv4pro 的 6.9 分中有约 0.8 分的"质量损失"来自工程缺陷（空文件），真实的 AAI 44 能力水平应为 ~7.7 分。这一发现对能力-质量映射的校准具有重要意义——**评审分数可能同时反映模型能力和工程质量，两者需要区分**。

### 4.4 发现四：评审者间信度验证了方法论有效性

24 个评分点中 22 个完全一致（91.7%），仅 dsv4pro 存在 2 个 1 分差异。这一极高的一致性表明：

1. `forest-quality-reviewer` skill 的评分标准设计有效——不同能力等级的评审者能达成高度一致
2. 评审能力门槛可能低于生成能力门槛——AAI 40 的评审者能可靠地评价 AAI 51 的产出
3. "评价他人"作为元任务，其能力要求可能低于"生成高质量内容"

### 4.5 发现五：内容深度与 AAI 的非线性关系

| 指标 | dsv4flash (40) | dsv4pro (44, 修复后) | glm52 (51) |
|------|:---:|:---:|:---:|
| 平均每叶子行数 | ~27 | ~42 | ~52 |
| 对比表格数 | 0 | 12 | 多个 |
| 开放问题讨论 | 0 | 8 | 多个 |
| 学术张力呈现 | 0 | 4 (19%) | 多处 |

内容深度（行数/字数/结构化程度）随 AAI 增长，但**单位 AAI 的内容深度增幅在 44→51 段显著小于 40→44 段**——这与 D4 的增长放缓一致。

## 6. 各模型详细评价

### 6.1 DeepSeek V4 Flash (AAI 40) — 综合 5.8/10

**定位**：快速建库级模型——覆盖广度尚可但深度严重不足

**优势**：引用真实性达标（D1=8.0）、顶层结构清晰（D3=7.0）、生成效率最高（45 min）

**劣势**：D4 批判性分析仅 3.0（70% 叶子正文 <200 字）、PoG 方法名错误、关键性能数据大量丢失

### 6.2 DeepSeek V4 Pro (AAI 44, 修复后) — 综合 7.7/10

**定位**：校验级模型——结构化组织优秀，批判深度中等

**优势**：跨树引用下沉到叶子级、方法对比表格丰富（57% 叶子）、方法名全部正确、修复后结构完整

**劣势**：学术张力呈现率仅 19%、部分叶子缺 version 字段、.experiment_metadata.yaml 不完整

**修复影响**：2 个空文件的修复使 D3/D4/D5 各 +1 分，综合分 +0.8，消除了工程质量损失

### 6.3 GLM-5.2 (AAI 51) — 综合 8.2/10

**定位**：深化级模型——全面领先，接近深度批判性分析门槛

**优势**：D4=7.0（CLS vs KV 张力、毒性累积深层矛盾、可操作开放问题）、元数据质量最高、跨树引用格式标准化、0 空文件

**劣势**：部分叶子缺 version 字段、forest/index.md refs 为空、T1 检索与理论合并为同一 Branch

## 8. 局限性声明

### 8.1 实验设计局限

1. **样本量有限**：仅 3 个模型，每个模型单次生成
2. **AAI 覆盖范围**：40-51 分区间，缺少 >55 分的高能力模型数据点
3. **单一森林主题**：所有模型生成同一主题（memory-systems-ai），可能存在主题特异性
4. **同族模型偏差**：dsv4flash 和 dsv4pro 来自同一模型家族

### 8.2 评审局限

1. **抽样评审**：dsv4flash 和 glm52 评审抽样 30-38%，dsv4pro 修复后达到 100% 全量覆盖
2. **引用审计不完整**：未使用 arxiv-mcp-server 逐条验证
3. **D4/D5 主观性**：包含评审者主观判断
4. **dsv4pro 修复溯源**：2 个修复文件的内容来源未能确认是由 dsv4pro 重新生成还是人工补充

### 8.3 已知数据质量问题

1. **dsv4pro 修复前空文件**：已修复，修复后数据为最终采用值
2. **dsv4pro 自评偏差**：自评分数（7.8）与外部评审均值（7.7）高度一致，但自评不计入最终均值

## 9. 结论与建议

### 9.1 核心结论

1. **AAI 与知识森林质量呈正相关**：5.8 → 7.7 → 8.2，每 +1 AAI 约对应 +0.19 综合分

2. **五维度呈现三种能力响应模式**：门槛效应（D1/D3）、近似线性（D2/D5）、陡峭增长（D4）

3. **D4 批判性分析呈"双阶梯"增长**：40→44 为第一阶梯（+3），44→55 为平台期，>55 预期第二阶梯

4. **工程修复可区分"质量损失"与"能力不足"**：dsv4pro 修复后 +0.8 分来自工程修复而非能力提升

5. **交叉评审方法论有效**：91.7% 评分点完全一致，评审能力门槛低于生成能力门槛

6. **GLM-5.2 (AAI 51) 是本实验中最优的知识抽取模型**：5 维度全面领先，D4=7 接近深度批判门槛

### 9.2 对后续实验的建议

| 优先级 | 建议 | 理由 |
|:---:|------|------|
| **P0** | 补充 AAI >55 的模型数据点 | 验证"55 分后 D4 再次显著分化"的双阶梯推断 |
| **P0** | 使用 arxiv-mcp-server 逐条验证引用 | 将 D1 置信度提升到 High |
| **P1** | 运行 sentence-transformers 量化交叉声明检测 | 将 D3 单一职责评估从主观转为客观 |
| **P1** | 扩展到不同主题的森林 | 验证主题无关性 |
| **P2** | 增加维度2（不同工具）和维度3（不同资料）实验 | 验证方法论普适性 |

### 9.3 对模型路由的实践指导

```
  → 推荐 AAI >51 (GLM-5.2 / 更高模型)
  → 补充方法对比、局限讨论、学术张力
  → 验证: D4=7（AAI 51），>55 预期 D4=8+
```
