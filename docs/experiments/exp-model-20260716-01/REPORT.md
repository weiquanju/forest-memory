## 1. 执行摘要

本实验验证了 **Artificial Analysis Intelligence Index (AAI) 与知识森林生成质量之间的定量关系**。在固定工具、输入资料和方法论的条件下，三个不同能力等级的 LLM（AAI 40/44/51）对同一份多源资料执行知识森林生成，产出经两轮交叉评审（首轮 9 份 + 自评质量门禁后重评 6 份 = 共 15 份评审报告）量化评估。

**核心结论**：

1. **综合评分随 AAI 增长**：6.0 → 7.6 → 8.5（AAI 40→44→51），每提升 1 分 AAI 约对应 0.22 分质量提升
2. **D4 批判性分析是区分度最高的维度**：3→6→7.5，AAI 40→44 增幅最大（+3），44→51 增幅放缓（+1.5），印证"Scientific Reasoning 需 >55 分才再次显著分化"
3. **D1/D3 存在门槛效应**：AAI 40 即达 D1=8/D3=7，AAI 44 即达 D1=9/D3=9，后续提升幅度趋于零
4. **自评质量门禁作用域有限**：三个森林均印证"技术检查仅影响 D5（frontmatter 完整性），D1-D4 内容维度完全不变"——这是对 forest-generation-methodology Step 3 设计的重要反馈
5. **评审者间信度首轮极高、重评轮分化**：首轮 91.7% → 重评轮 78%（glm52 的 D2/D4/D5 出现"弱评强"偏差方向分化）
6. **dsv4pro 修复验证了"质量损失 vs 能力不足"的区分**：首轮修复 2 个空文件使综合分从 6.9→7.7（+0.8），这 0.8 分来自工程缺陷而非模型能力不足
7. **GLM-5.2 (AAI 51) 在所有维度全面领先**，D4 达 7.5/10 表明其 Scientific Reasoning 已接近"深度批判性分析"门槛

## 2. 实验设计

### 2.1 对照实验框架

```
固定变量:
  ├── 工具: CodeBuddy v4.10.2 (VS Code 1.106.1)
  ├── 输入资料: bim_source (197行) + frs_source (725行) + arXiv:2404.13501 (2121行)
  ├── 方法论: forest-generation-methodology v1.0.0 (9步SOP)
  └── 评审方法: forest-quality-reviewer v1.0.0 (6步SOP, 5维度体系)

自变量:
  └── LLM 模型: DeepSeek V4 Flash (AAI 40) / DeepSeek V4 Pro (AAI 44) / GLM-5.2 (AAI 51)

因变量:
  ├── D1: 引用真实性 (0-10)
  ├── D2: 引用准确性 (0-10)
  ├── D3: 层级组织 (0-10)
  ├── D4: 批判性分析 (0-10)
  ├── D5: 学术规范 (0-10)
  └── 综合评分 (5维度均值)
```

### 2.2 防抄袭与隔离机制

- 每个 subject 在独立 git worktree 中工作，物理隔离
- worktree 间互不可见，无法读取其他 subject 的 forest/ 输出
- 新会话上下文干净清洁，不继承历史
- 森林结构由各模型独立设计（同 Forest ID: memory-systems-ai，但 Branch/Leaf 组织不同）

### 2.3 交叉评审矩阵

```
被测模型          评审者
                dsv4flash   dsv4pro   glm52
dsv4flash        ✗ 跳过      ✓ (R1+R2)  ✓ (v1+v2)
dsv4pro          ✓ (v1+v2)   ✗ 跳过    ✓ (v2+v3)
glm52            ✓ (R1+R2)   ✓ (R1+R2)  ✗ 跳过
```

每个模型被 2 位外部评审者评审，经历两轮：
- **首轮（R1）**：森林生成完成后，dsv4pro 因修复空文件执行 2 轮（v1 修复前 + v2 修复后），另含 1 份自评。共 9 份。
- **重评轮（R2/v2/v3）**：三个森林均执行自评质量门禁（Step 3）后触发，每森林 2 份外部重评。共 6 份。

合计 **15 份评审报告**。

## 4. 关键发现

### 4.1 发现一：D4 批判性分析是区分模型能力的核心维度

D4 是三个模型间区分度最高的维度：

```
D4 评分变化:  3.0 ──────→ 6.0 ───→ 7.5
AAI:          40          44        51
增幅:           +3.0        +1.5
              ↑               ↑
         最大增幅         增幅放缓
```

**对应 AAI 能力维度**：Scientific Reasoning（HLE + GPQA Diamond + CritPt，权重 24%）

**解读**：
- AAI 40→44 的 +3 增幅远大于其他维度的增幅（+1~2），表明 Scientific Reasoning 在 40-44 区间有显著跃升
- AAI 44→51 的增幅放缓至 +1.5，暗示 44-55 区间为"增长平台期"
- 推断 **>55 分后 D4 将再次显著分化**——这需要 AAI>55 的模型数据验证

**门槛推断**：D4 呈"双阶梯"增长模式——40→44 为第一阶梯（+3），44→55 为平台期（+1.5/7分AAI），>55 为第二阶梯（预期+2+）。

### 4.2 发现二：引用真实性和层级组织存在能力门槛效应

```
D1 评分:  8.0 ──→ 9.0 ──→ 9.0   （AAI 40→44→51）
D3 评分:  7.0 ──→ 9.0 ──→ 9.0   （AAI 40→44→51）
```

**关键事实**：
- D1 在 AAI 40 即达 8/10（0 虚构引用），AAI 44 即达 9/10，之后不再提升
- D3 在 AAI 44 即达 9/10，之后不再提升
- 门槛效应意味着这些维度的能力饱和点较低，~40-44 分即满足

**实践意义**：引用真实性验证和结构化组织可分配给 AAI 40-44 的低成本模型。

### 4.3 发现三：自评质量门禁的作用域边界（重评轮新发现）

三个森林执行自评质量门禁（Step 3）后重评，揭示了一个重要的方法论边界：

| 森林 | 自评修复内容 | D5 变化 | D1-D4 变化 | 结论 |
|------|------------|:---:|:---:|------|
| dsv4flash | 补 updated 字段 + index sources | 5→6 (+1) | 全部不变 | 仅 D5 受影响 |
| dsv4pro | 无（version/updated 推迟） | 0 | 全部不变 | 推迟无增益 |
| glm52 | 补 version 字段 | 8→8.5 (+0.5) | 全部不变 | 仅 D5 受影响 |

**核心结论**：自评质量门禁作为"技术检查（非内容评分）"，其作用域**严格限于 D5 的 frontmatter 完整性**。三个森林的核心内容短板（dsv4flash 的 D4=3、dsv4pro 的 D4 张力呈现率 19%）均未因自评门禁而改善——**内容级问题需要交叉评审（D1-D4）或内容深化阶段才能解决**。

**对方法论设计的反馈**：forest-generation-methodology 的 Step 3 自评质量门禁在捕获技术缺陷（空文件、YAML 重复键、缺失字段）方面有效，但无法替代内容质量评审。建议在方法论中明确区分"技术门禁"与"内容评审"的职责边界。

### 4.4 发现四：dsv4pro 修复揭示了"质量损失 vs 能力不足"的区分

dsv4pro 首轮修复 2 个空文件后综合分从 6.9→7.7（+0.8），这 0.8 分的提升完全来自工程修复，而非模型能力变化：

| 维度 | 修复前 | 修复后 | 提升来源 |
|------|:---:|:---:|---------|
| D3 +1.0 | 结构不完整 | 结构完整 | 工程修复（非能力） |
| D4 +1.0 | 2文件无内容 | 2文件有对比表 | 工程修复（非能力） |
| D5 +1.0 | 空文件违规 | 规范达标 | 工程修复（非能力） |

**校准结论**：修复前 dsv4pro 的 6.9 分中有约 0.8 分的"质量损失"来自工程缺陷（空文件），真实的 AAI 44 能力水平应为 ~7.7 分。重评轮进一步校准至 7.6（发现 Wu2024 引用语境偏差）。**评审分数可能同时反映模型能力和工程质量，两者需要区分**。

### 4.5 发现五：评审者间信度的两轮分化

首轮 91.7% 的极高信度在重评轮降至 78%，分歧集中在 glm52（AAI 51）的 D2/D4/D5：

| 分歧维度 | dsv4flash(40) 评分 | dsv4pro(44) 评分 | 偏差方向 |
|---------|:---:|:---:|------|
| D2 引用准确性 | 8 | 9 | 弱评者偏严 |
| D4 批判性分析 | 8 | 7 | 弱评者偏高（主观维度高估） |
| D5 学术规范 | 8 | 9 | 弱评者偏严 |

**偏差模式**：dsv4flash（AAI 40）评审 glm52（AAI 51）时，在主观维度（D4）倾向于高估（可能因无法充分识别自身未达到的深度），在客观维度（D2/D5）倾向于偏严。这一"弱评强"偏差方向分化在首轮未出现（首轮 glm52 两评审者 100% 一致），可能因重评轮抽样更深、暴露了更多分歧点。

> **P1-1 仲裁更新**（2026-07-16）：经实证阅读 6 个焦点叶子，分歧根因被细化为——D2/D5 分歧源于**方法论分类差异**（dsv4flash 将"引用完整性"误计入 D2 并自定义 D5 评分项），D4 分歧源于**抽样代表性差异**（dsv4flash 6 叶中 5 叶来自最深的 T3，dsv4pro 10 叶分布更均衡）。非纯能力偏差。维持均值（综合 8.5），详见 `reviews/arbitration-glm52-d2d4d5.md`。

### 4.6 发现六：内容深度与 AAI 的非线性关系

| 指标 | dsv4flash (40) | dsv4pro (44) | glm52 (51) |
|------|:---:|:---:|:---:|
| 平均每叶子行数 | ~27 | ~42 | ~52 |
| 对比表格数 | 0 | 12 | 多个 |
| 开放问题讨论 | 0 | 8 | 多个 |
| 学术张力呈现 | 0 | 4 (19%) | 多处 |

内容深度（行数/字数/结构化程度）随 AAI 增长，但**单位 AAI 的内容深度增幅在 44→51 段显著小于 40→44 段**——这与 D4 的增长放缓一致。

## 6. 各模型详细评价

### 6.1 DeepSeek V4 Flash (AAI 40) — 综合 6.0/10

**定位**：快速建库级模型——覆盖广度尚可但深度严重不足

**优势**：引用真实性达标（D1=8.0，arxiv-mcp 验证 0 虚构）、顶层结构清晰（D3=7.0）、生成效率最高（45 min）、自评门禁即时修复 frontmatter

**劣势**：D4 批判性分析仅 3.0（75% 叶子正文 <200 字）、PoG 方法名错误（arXiv:2410.14211 确认，仍未修复）、关键性能数据大量丢失

### 6.2 DeepSeek V4 Pro (AAI 44) — 综合 7.6/10

**定位**：校验级模型——结构化组织优秀，批判深度中等

**优势**：跨树引用下沉到叶子级、方法对比表格丰富（57% 叶子）、方法名全部正确（PoG="Paths-over-Graph"）

**劣势**：学术张力呈现率仅 19%、version/updated 字段仍缺失（自评门禁识别但推迟修复）、重评发现 Wu2024 引用语境偏差

### 6.3 GLM-5.2 (AAI 51) — 综合 8.5/10

**定位**：深化级模型——全面领先，接近深度批判性分析门槛

**优势**：D4=7.5（CLS vs KV 张力、毒性累积深层矛盾、可操作开放问题）、frontmatter 完整度 100%、跨树引用格式标准化（100% 叶子覆盖，38 条跨树引用）、0 空文件

**劣势**：D2/D4/D5 存在评审者分歧（±1分）、forest/index.md 纯文本图未改 Mermaid、非标准缩写 CIL 未展开（cosmetic）

## 7. 评审者偏差分析

### 7.1 偏差风险矩阵（重评轮）

| 评审配对 | AAI差值 | 偏差风险 | 重评轮实际影响 |
|---------|:---:|:---:|---------|
| dsv4pro(44) → dsv4flash(40) | +4 | 中 | 与 glm52 100% 一致，无偏差 |
| glm52(51) → dsv4flash(40) | +11 | 低 | 与 dsv4pro 100% 一致，无偏差 |
| dsv4flash(40) → dsv4pro(44) | -4 | 低 | 与 glm52 100% 一致，无偏差 |
| glm52(51) → dsv4pro(44) | +7 | 低 | 与 dsv4flash 100% 一致，无偏差 |
| dsv4flash(40) → glm52(51) | -11 | 高 | D2/D4/D5 各差 1 分，"弱评强"偏差方向分化 |
| dsv4pro(44) → glm52(51) | -7 | 中 | D2/D4/D5 各差 1 分（与 dsv4flash 反向） |

### 7.2 偏差分析结论

- **弱评强场景（AAI 差 -11）**：dsv4flash 评 glm52 时出现偏差方向分化——主观维度（D4）高估，客观维度（D2/D5）偏严
- **中等能力评审（AAI 40-44 互评）**：100% 一致，无偏差
- **强评弱场景（AAI 差 +7~+11）**：100% 一致，无偏差

**结论**：`forest-quality-reviewer` skill 的评分标准在"评审者能力 ≥ 被评审者"或"能力接近"时表现可靠；当"评审者能力显著低于被评审者"（差 ≥11）时，主观维度可能出现高估偏差。建议对 AAI 差距 >10 的评审配对采用三评审者机制。

## 8. 局限性声明

### 8.1 实验设计局限

1. **样本量有限**：仅 3 个模型，每个模型单次生成
2. **AAI 覆盖范围**：40-51 分区间，缺少 >55 分的高能力模型数据点
3. **单一森林主题**：所有模型生成同一主题（memory-systems-ai），可能存在主题特异性
4. **同族模型偏差**：dsv4flash 和 dsv4pro 来自同一模型家族

### 8.2 评审局限

1. **抽样评审**：dsv4flash 重评 46%、dsv4pro 100% 全量、glm52 40% 覆盖率
2. **引用审计**：glm52 的 D1 重评使用了 arxiv-mcp-server 验证 3 篇核心论文；dsv4flash/dsv4pro 部分使用 web 搜索，未全量 arxiv-mcp 验证
3. **D4/D5 主观性**：包含评审者主观判断，重评轮在 glm52 上暴露 ±1 分分歧
4. **dsv4pro 修复溯源**：2 个修复文件的内容来源未能确认是由 dsv4pro 重新生成还是人工补充

### 8.3 已知数据质量问题

1. **glm52 评审者分歧**：D2(8vs9)、D4(8vs7)、D5(8vs9) 各差 1 分，均值为最终采用值。经 P1-1 仲裁，根因为方法论分类差异（D2/D5）+抽样代表性差异（D4），非纯能力偏差，维持均值
2. **dsv4pro version/updated 推迟修复**：自评门禁识别但未修复，影响 D5 上限
3. **自评门禁的边界**：技术检查无法覆盖内容质量（D1-D4），需交叉评审补充

## 9. 结论与建议

### 9.1 核心结论

1. **AAI 与知识森林质量呈正相关**：6.0 → 7.6 → 8.5，每 +1 AAI 约对应 +0.22 综合分

2. **五维度呈现三种能力响应模式**：门槛效应（D1/D3）、近似线性（D2/D5）、陡峭增长（D4）

3. **D4 批判性分析呈"双阶梯"增长**：40→44 为第一阶梯（+3），44→55 为平台期（+1.5），>55 预期第二阶梯

4. **自评质量门禁作用域有限**：三个森林均印证"技术检查仅影响 D5，D1-D4 内容维度不变"——内容级问题需交叉评审解决

5. **工程修复可区分"质量损失"与"能力不足"**：dsv4pro 首轮修复 +0.8 分来自工程修复而非能力提升

6. **交叉评审方法论在能力接近时有效**：首轮 91.7% 信度；重评轮在"弱评强"场景（AAI 差≥11）暴露主观维度偏差

7. **GLM-5.2 (AAI 51) 是本实验中最优的知识抽取模型**：5 维度全面领先，D4=7.5 接近深度批判门槛

### 9.2 对后续实验的建议

| 优先级 | 建议 | 理由 |
|:---:|------|------|
| **P0** | 补充 AAI >55 的模型数据点 | 验证"55 分后 D4 再次显著分化"的双阶梯推断 |
| **P0** | 对"弱评强"场景（AAI差≥10）采用三评审者机制 | 消除 D4 主观维度高估偏差 |
| **P1** | 全量使用 arxiv-mcp-server 验证引用 | 将 D1 置信度统一提升到 High |
| **P1** | 运行 sentence-transformers 量化交叉声明检测 | 将 D3 单一职责评估从主观转为客观 |
| **P1** | 在 forest-generation-methodology 中明确"技术门禁"与"内容评审"职责边界 | 自评门禁无法替代内容质量评审 |
| **P2** | 扩展到不同主题的森林 | 验证主题无关性 |
| **P2** | 增加维度2（不同工具）和维度3（不同资料）实验 | 验证方法论普适性 |

### 9.3 对模型路由的实践指导

```
知识森林生成 pipeline:

Stage 1: 建库（引用真实 + 层级组织）
  → 推荐 AAI ~40-44 (DeepSeek V4 Flash/Pro)
  → 成本最低，质量骨架可用
  → 验证: D1=8-9, D3=7-9

Stage 2: 校验（引用准确 + 学术规范）
  → 推荐 AAI ~44-51 (DeepSeek V4 Pro / GLM-5.2)
  → 修正引用元数据，统一格式，补充跨树引用
  → 验证: D2=7-8.5, D5=7-8.5

Stage 3: 深化（批判性分析 + 横向对比）
  → 推荐 AAI >51 (GLM-5.2 / 更高模型)
  → 补充方法对比、局限讨论、学术张力
  → 验证: D4=7.5（AAI 51），>55 预期 D4=8+
```
