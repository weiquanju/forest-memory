# 键值记忆框架

## 核心主张

键值记忆（Key-Value Memory）框架由 Gershman et al.（2025, arXiv:2501.02950v2）系统阐述，提出统一人脑与 AI 记忆机制的理论：记忆系统本质上采用键值分离架构实现高效存储和检索。

**脑-AI 对应**：
| 组件 | 大脑实现 | AI 实现 |
|------|---------|--------|
| 键（索引） | 海马体 | Transformer KV 缓存中的 Key |
| 值（内容） | 新皮层 | Transformer KV 缓存中的 Value |
| 查询 | 当前感知/思维 | Query 向量 |

## 检索失败主导遗忘

框架的核心论点：**检索失败而非记忆擦除是遗忘的主要原因**。

**支持证据**：
- **舌尖现象**：能感知记忆存在但暂时无法提取
- **"知道感"**：受试者能准确判断信息是否存储在记忆中，即使无法回忆（Hart, 1965; Reder & Ritter, 1992）
- **实验性遗忘可恢复**：通过蛋白质合成抑制诱导的遗忘可在特定条件下恢复（Ryan et al., 2015, *Science*）
- **模拟验证**：Gershman 等人通过"扩增"旧任务记忆条目的键权重，训练后网络无需重新训练即可恢复旧任务分类能力

## 对灾难性遗忘的补充视角

从 KV 框架看，灾难性遗忘可理解为旧任务对应键值对被新任务检索路径"遮蔽"——信息仍在但无法通过正确路径访问。通过人工"扩增"旧任务记忆条目的键权重，模型可无需重新训练恢复旧任务分类性能，与神经科学中"沉默印迹"（silent engram）再激活一致。

## 与 CLS 的关系与张力

- **CLS**：核心叙事是时间梯度转移——新记忆依赖海马体，随时间推移通过系统巩固逐步转移至新皮层
- **KV 框架**：核心叙事是功能并行分工——无论记忆新旧，海马体始终作为索引存在

两个框架回答的是不同问题：CLS 聚焦"记忆如何逐步稳定存储"，KV 聚焦"稳定存储后如何高效检索"。Gershman 等人明确声明框架的生物学解释当前仍属于推测性假说。
