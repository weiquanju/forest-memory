# 海马体-新皮层互补学习系统

## 核心机制

互补学习系统（Complementary Learning Systems, CLS）理论由 McClelland 等人于 1995 年提出，描述海马体和新皮层在记忆中的互补分工。这一理论将大脑记忆系统类比为计算机的多级存储架构——缓存（海马体）与硬盘（新皮层）的协同。

## 双系统分工

| 系统 | 学习速率 | 功能定位 | 计算类比 |
|------|---------|---------|---------|
| 海马体 | 快速学习 | 编码事件细节、快速捕获新经历 | 快速缓存（容量有限、高带宽） |
| 新皮层 | 慢速学习 | 逐步整合、泛化提取共性知识 | 长期存储（容量巨大、慢写入） |

- **海马体**：负责快速编码和暂时存储新信息的细节，尤其对情景记忆至关重要。能够迅速将新经历编码为记忆，但存储容量有限且记忆痕迹会随时间衰退。经典证据来自患者 H.M.——切除海马体后无法形成新长期记忆，但保留了手术前的童年记忆。
- **新皮层**：通过反复的系统巩固（systems consolidation）过程，将海马体中的记忆痕迹逐步转移到皮层网络。这一过程可能需要数周、数月甚至数年。新皮层特别擅长泛化和抽象，能从多次经历中提取共性。

## 系统巩固机制

在 NREM 睡眠期间，海马体中的尖波涟漪（sharp-wave ripple, SWR）以压缩时间尺度"重放"清醒时的神经活动序列，驱动新皮层同步激活。这一"海马-皮层对话"是系统巩固的核心机制——海马体通过反复重放将记忆痕迹"教给"新皮层（Buzsáki, 2015）。

## 与 KV 框架的关系

CLS 的核心叙事是时间梯度转移——新记忆依赖海马体，随时间推移通过系统巩固逐渐转移到新皮层。而 KV 框架（Gershman et al., 2025）认为海马体始终作为索引（键）存在，任何精确的情景检索都需要海马体的键匹配。两个框架回答的是不同问题：CLS 聚焦"记忆如何逐步稳定存储"，KV 聚焦"稳定存储后如何高效检索"。

## CLS 在 AI 中的工程验证

Jun 等人（2025）将 VAE 与现代 Hopfield 网络（MHN）结合：VAE 负责模式完成（模拟新皮层泛化），MHN 负责模式分离（模拟海马体快速编码），在 Split-MNIST 持续学习基准上达到接近 SOTA 的 ~90% 准确率，显著减少了灾难性遗忘。
