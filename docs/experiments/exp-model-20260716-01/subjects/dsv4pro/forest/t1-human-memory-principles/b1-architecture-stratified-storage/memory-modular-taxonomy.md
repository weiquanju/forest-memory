# 人脑记忆的模块化分类体系

## 分类维度

人脑记忆系统在内容类型上呈现模块化特征，不同类型记忆由不同脑区负责。

## 记忆类型与神经基础

| 记忆类型 | 内容 | 核心脑区 | 特点 |
|---------|------|---------|------|
| **情景记忆** | 特定事件（时间、地点、细节） | 海马体 + 内侧颞叶 | "海马体索引、新皮层存储"架构 |
| **语义记忆** | 一般知识、事实、概念属性 | 新皮层（颞叶、额叶联合皮层） | 抽象、去情境化 |
| **程序性记忆** | 技能与习惯 | 基底神经节、小脑 | 无需意识参与、终身保留 |
| **工作记忆** | 当前任务的即时信息 | 前额叶皮层 | 临时缓存系统、容量有限 |

## 海马记忆索引理论

Teyler 和 DiScenna（1986）提出的海马记忆索引理论（hippocampal memory indexing theory）最早阐述了"海马体绑定情景要素作为索引、新皮层存储记忆内容"的分工思想。在 Gershman et al.（2025）的键值记忆框架中被进一步抽象为海马体编码"键"（索引）、新皮层存储"值"（内容）的架构。

## 短期记忆与长期记忆的分层

- **短期记忆（工作记忆）**：依赖前额叶皮层的持续神经活动，通过局部回路循环兴奋、突触前馈与反馈以及单细胞双稳态维持。容量有限（受限于同时兴奋的细胞群数量），持续时间几秒到几分钟。
- **长期记忆**：依赖突触结构和功能的持久改变（LTP/LTD），主要在发生海马体及新皮层。理论容量巨大（数十亿神经元及更庞大的突触连接数），但形成需要时间和重复巩固。

## 工程启示

大脑模块化架构类似于计算机的分层存储（缓存-主存-辅存）以及为不同任务分配专用处理单元。这启示 AI 记忆系统也应区分情景记忆、语义记忆、程序性记忆和工作记忆等不同类型，并分配给不同的存储和检索机制。
