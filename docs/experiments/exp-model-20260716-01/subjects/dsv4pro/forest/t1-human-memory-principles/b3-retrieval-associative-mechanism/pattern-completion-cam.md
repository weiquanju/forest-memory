# 模式完成与内容寻址存储

## 模式完成机制

模式完成（pattern completion）主要发生在记忆检索阶段，由海马体 CA3 区域执行。CA3 是一个自联想网络，其 recurrent collateral 突触连接形成了吸引子网络（Hopfield, 1982; Rolls, 2013）。

**工作原理**：当部分记忆线索输入 CA3 时，循环连接将活动模式收敛到存储的完整记忆模式上。在算法上，这对应于内容寻址存储（Content-Addressable Memory, CAM）的读取过程——通过部分内容直接定位并恢复完整内容。

## 内容寻址存储（CAM）

在大脑中，海马体-皮层系统是一种生物实现的内容寻址存储器。在计算机科学中，CAM 是一种特殊存储器，通过内容本身来定位数据。

**海马体 CAM 的神经实现**：
- CA3 网络的循环连接形成能量景观
- 部分输入激活网络后，通过能量函数下降收敛到最近的存储模式
- 等价于 CAM 的匹配和读取操作

## 键值记忆抽象

海马体的键值记忆模型将 CAM 进一步抽象为"键"和"值"的分离架构：
- **键**：海马体存储的检索线索/索引
- **值**：新皮层存储的记忆内容

检索时，海马体通过匹配"键"定位记忆，然后从新皮层提取相应"值"。这与 Transformer 模型的键值对（KV）记忆机制有深层同构性——查询（Q）与键（K）点积定位，从值（V）读取内容。

## 模式分离与模式完成的协同

二者共同保证记忆系统高效检索且抗干扰。实例：回忆人名时，大脑先通过模式分离区分相似名字，再通过模式完成根据部分线索（如面孔）收敛到正确名字的记忆。
