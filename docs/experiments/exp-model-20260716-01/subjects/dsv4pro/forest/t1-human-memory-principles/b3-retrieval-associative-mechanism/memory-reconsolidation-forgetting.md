# 记忆再巩固与遗忘机制

## 再巩固机制

记忆并非一成不变，而是处于动态更新状态。当记忆被提取时，进入不稳定窗口，此期间记忆痕迹可被修改，随后重新稳定——这一过程称为**再巩固**（reconsolidation）。

**算法类比**：在线学习机制——每次查询记忆时，系统对相关记忆进行一次"微调"以适应环境。

## 被动遗忘：突触资源竞争

突触可塑性依赖有限的分子资源（如可塑性相关蛋白 PRPs）。当某些突触被诱导 LTP 时，邻近未激活突触可能因资源被"抢占"而经历异突触 LTD，导致原有记忆痕迹削弱。

- Karbowski（2019）的代谢约束模型：突触可塑性仅消耗总能量预算的 4-11%
- 新学习虽只占小部分代谢成本，在资源紧张时仍可能挤压旧记忆维持

## 主动遗忘机制

大脑具备主动遗忘机制——通过特定分子和细胞通路主动降低记忆痕迹强度：

1. **多巴胺-Rac1 通路**：果蝇中多巴胺信号激活 Rac1 促使突触连接减弱（Shuai et al., 2010, *Cell*）；后续研究阐明了 Rac1/Cofilin 级联反应驱动主动遗忘的完整通路（Davis & Zhong, 2017, *Neuron*），哺乳动物中存在功能同源物
2. **成年神经发生**：海马体齿状回持续产生新神经元并整合入现有回路，导致旧记忆突触痕迹被"稀释"或覆盖（Akers et al., 2014, *Science*）

## 算法映射

- **被动遗忘** → 资源受限系统中的"写入即覆盖"
- **主动遗忘** → 神经网络中的权重衰减或剪枝（系统主动降低低价值连接权重以优化整体资源分配）
- **检索失败** → KV 框架观点：遗忘主要因检索路径失效而非记忆擦除（Ryan et al., 2015, *Science* 中实验性遗忘被证实可恢复）
