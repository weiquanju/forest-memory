# Mem0/MemVerse/DYNA前沿记忆架构

## 三大记忆框架对比

| 维度 | Mem0 | MemVerse | DYNA |
|------|------|----------|------|
| 记忆组织方式 | 图结构 | 层次化 KG | 时态 KG |
| 多模态支持 | 否 | 是 | 否 |
| 遗忘机制 | 隐式（图更新） | 显式（自适应+周期蒸馏） | 隐式（随机游走权重衰减） |
| 训练依赖 | 否 | 否（即插即用） | 否 |
| 主要局限 | 图复杂度随对话增长 | 多模态记忆开销大 | 时态排序仅~5%改善 |

## Mem0（Chhikara et al., 2025, arXiv:2504.19413）

可扩展长期记忆架构，通过动态提取、整合和检索对话关键信息，解决多轮对话中固定上下文窗口的局限。利用图结构组织记忆以捕获对话元素之间的复杂关系。相较 OpenAI 基线在 LLM-as-Judge 指标上相对提升 26%，p95 延迟降低 91%，Token 成本节省超 90%。

## MemVerse（Liu et al., 2025, arXiv:2512.03627）

模型无关、即插即用的记忆框架，将快速参数化回忆与层次化检索记忆桥接。维护短期记忆（近期上下文）的同时，将原始多模态经验转换为以层次化知识图谱组织的结构化长期记忆。关键创新：**周期蒸馏机制**——将长期记忆中的关键知识压缩到参数化模型中实现快速可微回忆。是唯一同时覆盖多模态+显式遗忘+知识蒸馏的框架。

## DYNA（Sarabadani & Tajvidiyan, 2026, arXiv:2606.15778）

将情景记忆建模为时态知识图谱：事件为节点，时态关系为带时间戳的有向边。查询时通过随机游走和中心度度量检索相关节点。相较微调减少约 7% 灾难性遗忘，相较标准 RAG 改善约 5% 时态排序能力。

## 趋势观察

三类框架均以 KG 为核心组织方式——图结构正在成为 Agent 持久记忆的事实标准。"经验跟随属性"带来的错误累积风险尚未被任何框架系统性解决。
