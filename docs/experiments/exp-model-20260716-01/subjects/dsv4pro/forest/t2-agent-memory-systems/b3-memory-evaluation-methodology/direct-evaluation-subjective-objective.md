# Agent记忆直接评估：主观与客观方法

## 评估范式分类

Zhang et al.（2024, arXiv:2404.13501）提出两大评估策略：直接评估（独立衡量记忆模块能力）和间接评估（通过端到端 Agent 任务表现评估）。

## 主观评估

### 评估维度

| 维度 | 定义 | 示例 |
|------|------|------|
| **连贯性（Coherence）** | 调用的记忆是否自然且适合当前上下文 | 旅行计划应调用旅行偏好而非工作偏好 |
| **合理性（Rationality）** | 调用的记忆内容是否合理正确 | "颐和园在北京"而非"颐和园在月球" |

### 实施关键
- **评估者选择**：熟悉任务、背景多样化以消除主观偏差
- **标注方式**：直接打分（绝对量化）vs 成对比较（消除标注噪声）
- **评分粒度**：过粗无法有效区分能力差异，过细增加标注负担

## 客观评估

### 三项核心指标

| 指标 | 定义 | 计算方式 |
|------|------|---------|
| **结果正确性** | 基于记忆模块正确回答预定义问题的能力 | Accuracy = Σ I[a_i = â_i] / N |
| **引用准确率** | 是否能发现相关记忆内容来支持回答 | F1 = 2·Precision·Recall / (Precision+Recall) |
| **时间与硬件成本** | 记忆适应时间和推理时间 | 平均时间消耗 + 峰值 GPU 内存 |

### 使用场景

结果正确性关注最终答案正确性；引用准确率关注中间信息的恰当性——后者对评估检索式记忆模块尤为重要，因检索质量直接影响推理质量。

## 直接评估的优势与局限

- **优势**：独立评估记忆模块，结果更可靠可比较
- **局限**：目前缺少专门针对 LLM Agent 记忆模块的开源基准
