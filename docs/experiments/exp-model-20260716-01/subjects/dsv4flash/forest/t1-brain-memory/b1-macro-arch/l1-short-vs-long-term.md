# 短期记忆与长期记忆的分层架构

人脑记忆系统最基础的分层是短期记忆（工作记忆）与长期记忆的划分。短期记忆依赖前额叶皮层的持续神经活动维持信息，容量有限且易失；长期记忆则通过突触结构和功能的持久改变（LTP/LTD）实现海量信息的持久存储。二者构成容量与持久性的权衡：短期记忆提供快速、有限的在线处理能力，长期记忆提供大容量、持久的存储能力。
