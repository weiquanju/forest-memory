# 模块化记忆分类

人脑按内容类型对记忆进行模块化分类存储：**情景记忆**（episodic memory）记录特定事件及其时间、地点，核心依赖于海马体及内侧颞叶；**语义记忆**（semantic memory）存储一般知识和事实，主要位于新皮层联合皮层；**程序性记忆**（procedural memory）存储技能和习惯，依赖基底神经节和小脑。此外工作记忆作为临时缓存系统涉及前额叶皮层。这种模块化分工类似于计算机中为不同任务分配专用处理单元的设计，提高了记忆系统的整体效率和可靠性。
