# 海马体与新皮层的互补分工

海马体和新皮层构成互补学习系统（CLS）的核心双系统架构。海马体是"快速学习"系统，负责快速编码新信息的细节（尤其情景记忆），容量有限且痕迹会随时间衰退。新皮层是"慢速学习"系统，通过系统巩固过程逐步整合海马体传递的信息，形成持久的长期记忆表征，擅长泛化和抽象。这种分层架构类似于计算机的缓存-硬盘存储：海马体相当于快速缓存（高带宽、低容量），新皮层相当于硬盘存储（低速、大容量、持久）。
