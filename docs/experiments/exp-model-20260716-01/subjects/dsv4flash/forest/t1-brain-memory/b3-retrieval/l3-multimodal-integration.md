# 多模态记忆的跨感官整合

日常记忆往往是多模态的——同时包含视觉、听觉、触觉等信息。大脑通过**多感官整合**机制将不同模态信息绑定为统一的记忆表征。在编码阶段，多模态信息汇聚到内侧颞叶和前额叶皮层，海马体绑定不同感官线索到一个记忆中。在检索阶段，模式完成机制可处理不完整的多模态线索：即使只有部分感官线索（如只闻到咖啡香），海马体仍能通过模式完成找到对应的完整多模态记忆。这类似于将不同模态的特征向量融合存储在同一个记忆模型中，检索时通过部分匹配找到完整记忆。
