# 互补学习系统（CLS）理论

互补学习系统（CLS）理论由McClelland等人于1995年提出，解释海马体和新皮层在记忆中的互补作用。海马体快速学习并记住事件细节（特化），新皮层慢速学习并记住事件规律（泛化），在特化和泛化之间取得平衡。CLS与键值记忆（KV）框架的张力在于：CLS强调时间梯度转移（新记忆依赖海马体，随巩固逐渐转移到新皮层），KV强调永久索引依赖性（海马体始终作为索引存在）。目前两个框架的整合仍是活跃的研究前沿。
