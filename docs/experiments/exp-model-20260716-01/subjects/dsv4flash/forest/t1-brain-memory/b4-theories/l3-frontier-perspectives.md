# 记忆研究前沿视角

记忆研究的前沿涌现出多个值得关注的视角：**预测性世界模型**认为记忆不只是静态数据记录，而是一个动态的内部模拟器；**强化学习驱动的记忆管理**（如Mem-α）让智能体自适应地决定何时存储、更新和检索信息；**多智能体共享记忆**（如SoHip）借鉴海马体机制让异构智能体通过共享轻量级记忆进行协作。此外，睡眠中尖波涟漪（SWR）重放被认为是系统巩固的核心机制，情感通过杏仁核调控记忆优先级——这些问题构成了连接计算神经科学与认知哲学的前沿。
