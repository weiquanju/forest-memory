# 键值记忆框架

键值记忆（Key-Value Memory）框架是近年来统一人脑与AI记忆机制的重要理论。该框架认为记忆系统本质上采用键值分离架构：海马体编码"键"（检索索引），新皮层存储"值"（记忆内容）。这一框架统一了认知心理学、神经科学和机器学习视角，提出**检索失败而非记忆擦除是遗忘的主要原因**，得到舌尖现象和实验性遗忘恢复等证据支持。在AI中，Transformer的KV机制与大脑键值框架高度呼应。该框架为灾难性遗忘提供了补充性解释——旧任务键值对被新任务检索路径"遮蔽"，信息仍在但无法访问。
