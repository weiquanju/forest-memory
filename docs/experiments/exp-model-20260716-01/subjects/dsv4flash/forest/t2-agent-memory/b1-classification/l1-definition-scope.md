# LLM代理记忆的定义与分类框架

LLM-based Agent 记忆分为狭义和广义两个层次。狭义定义指 Agent 在交互过程中积累的知识和经验（对话历史、观察记录等），支撑 Agent 的自进化能力。广义定义还包括模型参数中隐含的预训练知识。记忆模块是区分 Agent 与原始 LLM 的核心组件，它决定了 Agent 如何积累知识、处理历史经验以及检索信息来支持行动。认知心理学视角将记忆分为感觉记忆、短期记忆和长期记忆三个层级。
