# 知识质量治理—事实一致性检测

知识质量治理确保AI系统使用的知识是准确、一致和可溯源的。**事实一致性检测**（如KG-CRAFT、GraphCheck）自动检查知识图谱或模型输出中的事实错误和逻辑矛盾。**知识溯源**追踪LLM生成内容的来源，评估每条信息的可靠性——这对于降低大模型"幻觉"（hallucination）风险至关重要。知识治理是构建可信AI系统的基础设施，直接影响下游应用的输出质量。
