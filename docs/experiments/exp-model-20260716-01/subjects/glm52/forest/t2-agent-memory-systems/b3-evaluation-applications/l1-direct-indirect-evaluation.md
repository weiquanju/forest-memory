# 直接与间接评估方法

## 两大评估策略

| 策略 | 原理 | 优势 | 局限 |
|------|------|------|------|
| 直接评估 | 独立测量记忆模块能力 | 可靠性高，可独立评估 | 缺乏开源基准 |
| 间接评估 | 通过端到端任务完成度评估 | 易于实施，有公开基准 | 性能归因不明确 |

## 直接评估

### 主观评估

从两个维度评估记忆模块：

**评估方面**：
- **连贯性（Coherence）**：召回的记忆是否自然且适合当前上下文
- **合理性（Rationality）**：召回的记忆是否合理（如"颐和园在北京"而非"在月球上"）

**评估过程**：
- 评估者选择：需熟悉评估任务，背景多样化以消除偏见
- 标注方式：直接评分（绝对定量）或候选比较（消除独立标注噪声）

局限：成本高（需雇佣人工评估者），不同评估者群体偏见导致结果难复现。

### 客观评估

| 指标 | 测量内容 | 计算方式 |
|------|---------|---------|
| 结果正确性 | Agent 能否基于记忆正确回答预定义问题 | Accuracy = (1/N) Σ I[aᵢ = âᵢ] |
| 引用准确性 | 能否发现相关记忆内容支持回答 | F1 = 2·(Precision·Recall)/(P+R) |
| 时间与硬件成本 | 记忆操作的效率 | Δtime = (1/M) Σ(t_end - t_start)；峰值 GPU 内存 |

## 间接评估

通过依赖记忆的任务完成度反映记忆模块有效性：

1. **对话**：一致性（Consistency）和参与度（Engagement）——如 MemoChat 的 GPT-4 评分、MemGPT 的 CSIM 分数
2. **多源问答**：综合评估试内/跨试/外部知识的记忆整合——如 ReAct、Reflexion
3. **长上下文应用**：长上下文段落检索、长上下文摘要（ROUGE 等指标）
4. **其他任务**：成功率（AlfWorld/Minecraft）、探索程度（Minecraft 不同物品数）

## 评估讨论

间接评估更易实施（有公开基准），但任务性能可归因于多种因素，记忆只是其中之一，可能导致评估结果偏差。直接评估可独立评估记忆模块有效性，提高可靠性，但目前缺乏专为 LLM Agent 记忆模块定制的开源基准。
