# 前沿记忆架构

## 统一三维分类框架

Hu et al.（2025, arXiv:2512.13564）提出 Agent 记忆的统一三维分类：

| 维度 | 类别 |
|------|------|
| 载体形式（Forms） | 令牌级（Token-level）/ 参数级（Parametric）/ 潜在级（Latent） |
| 功能（Functions） | 事实性记忆 / 经验性记忆 / 工作记忆 |
| 动态过程（Dynamics） | 形成 / 演化 / 检索 |

## Mem0：可扩展长期记忆

Mem0 框架（arXiv:2504.19413）通过动态提取、整合和检索对话中的关键信息，解决固定上下文窗口在多轮对话中的局限。

- **图结构组织**：捕获对话元素之间的复杂关系
- **性能**：相较 OpenAI 基线在 LLM-as-Judge 指标上相对提升 26%，p95 延迟降低 91%，Token 成本节省超过 90%
- **局限**：仅支持文本，图结构管理复杂度随对话长度增长

## MemVerse：终身多模态记忆

MemVerse（arXiv:2512.03627）是模型无关、即插即用的记忆框架：

- **短期记忆**：维护近期上下文
- **长期记忆**：将原始多模态经验转换为以**层次化知识图谱**组织的结构化记忆
- **关键创新**：周期蒸馏机制——将长期记忆中的关键知识压缩到参数化模型中，实现快速可微回忆
- **特性**：支持持续巩固、自适应遗忘、有界记忆增长
- **局限**：多模态记忆体组织和检索开销大

## DYNA：时态情景记忆

DYNA 框架（arXiv:2606.15778）将情景记忆建模为时态知识图谱：

- 事件为节点，时态关系为带时间戳的有向边
- 查询时通过随机游走和中心度度量检索相关节点
- **性能**：相较微调减少约 7% 的灾难性遗忘，相较标准 RAG 改善约 5% 的时态排序能力
- **局限**：仅支持文本，时态排序仅比 RAG 基线改善 ~5%

## 三框架对比

| 框架 | 记忆组织 | 多模态 | 遗忘机制 | 训练依赖 | 核心局限 |
|------|---------|:---:|:---:|:---:|---------|
| Mem0 | 图结构（动态提取） | 否 | 隐式 | 否 | 图管理复杂度增长 |
| MemVerse | 层次化 KG（短期+长期） | 是 | 显式（自适应+蒸馏） | 否 | 工程复杂度最高 |
| DYNA | 时态 KG（事件-时间边） | 否 | 隐式（权重衰减） | 否 | 时态改善有限 |

**关键观察**：三种框架均以 KG 为核心组织方式——图结构正在成为 Agent 持久记忆的事实标准。MemVerse 是唯一同时覆盖多模态+显式遗忘+知识蒸馏的框架，概念上最完整但工程复杂度也最高。
