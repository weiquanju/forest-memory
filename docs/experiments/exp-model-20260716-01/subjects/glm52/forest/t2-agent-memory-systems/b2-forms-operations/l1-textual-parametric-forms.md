# 文本记忆与参数化记忆

## 两种记忆形式

| 形式 | 表示方式 | 主流程度 | 子类型 |
|------|---------|---------|--------|
| 文本记忆（Textual） | 自然语言，显式离散 | 当前主流 | 完整交互/近期交互/检索交互/外部知识 |
| 参数化记忆（Parametric） | 模型参数，隐式连续 | 仍欠研究 | 微调方法/记忆编辑方法 |

## 文本记忆的四种子类型

1. **完整交互**（Complete Interactions）：存储所有 Agent-环境交互历史（长上下文策略）。局限：计算成本高、推理延迟大、长上下文位置偏差
2. **近期交互**（Recent Interactions）：维护最近获取的记忆（局部性原理）。如 SCM 的 flash memory、MemGPT 的工作上下文。局限：无法访问远期关键信息
3. **检索交互**（Retrieved Interactions）：基于相关性、重要性和主题选择记忆内容。如 Generative Agents 的余弦相似度+重要性+时间性、MemoryBank 的 FAISS 索引
4. **外部知识**（External Knowledge）：通过工具调用获取外部知识转化为记忆

## 参数化记忆

### 微调方法
通过监督微调将领域知识注入 LLM 参数。如 Character-LLM（角色扮演）、Huatuo（生物医学）、InvestLM（金融投资）。

局限：过拟合风险、灾难性遗忘、计算成本高、需要大量数据，主要适用于离线场景。

### 记忆编辑方法
知识编辑专门针对需要改变的事实进行调整，确保无关知识不受影响。如 MAC（元学习在线适应）、MEND（轻量级参数修改生成）、KnowledgeEditor（超网络预测参数修改）。

记忆编辑更适合小规模在线记忆调整，计算成本更低。

## 两种形式的优劣权衡

| 维度 | 文本记忆 | 参数化记忆 |
|------|---------|-----------|
| 有效性 | 信息全面详细，但受 token 限制 | 不受 prompt 长度限制，但存在信息损失 |
| 效率 | 写入高效，读取成本高 | 写入成本高，读取高效 |
| 可解释性 | 强（自然语言直观） | 弱（潜在空间表示） |
| 信息密度 | 低（离散 token 空间） | 高（连续实数向量空间） |
| 适用场景 | 近期交互回忆、上下文特定任务 | 大量记忆、成熟知识存储 |
