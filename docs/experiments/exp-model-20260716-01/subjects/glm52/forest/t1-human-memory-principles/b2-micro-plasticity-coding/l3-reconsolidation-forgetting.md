# 再巩固与主动遗忘

## 记忆再巩固：动态更新机制

记忆并非一旦存储就一成不变。当记忆被提取时，它会进入一个不稳定窗口，此时记忆痕迹可以被修改，随后重新稳定——这一过程称为再巩固（reconsolidation）。

**算法理解**：一种在线学习机制——每当查询记忆时，系统对相关记忆进行"微调"以适应当前环境和需求。如果在提取记忆时提供新信息，旧记忆可能被整合新信息而改变。

## 遗忘的多重机制

遗忘并非简单的"擦除"，而是多种机制的结果：

### 突触资源竞争

突触可塑性依赖有限的分子资源（如可塑性相关蛋白 PRPs、代谢能量）。当某些突触被诱导产生 LTP 时，邻近未激活的突触可能因资源被"抢占"而经历异突触长时程抑制（heterosynaptic LTD）。

Karbowski（2019）的代谢约束模型表明，突触可塑性仅消耗突触总能量预算的 4-11%，但在资源紧张时仍可能挤压旧记忆的维持。这在计算上类似于资源受限系统中的"写入即覆盖"。

### 主动遗忘机制

大脑具备主动遗忘机制——通过特定分子和细胞通路主动降低记忆痕迹强度：

1. **多巴胺-Rac1 通路**（果蝇）：多巴胺信号通过激活小 G 蛋白 Rac1 促使突触连接减弱。Rac1 的遗忘功能由 Shuai 等人（2010, *Cell*）首次发现，后续阐明多巴胺经由 Rac1/Cofilin 级联反应驱动主动遗忘的完整分子通路（Davis & Zhong, 2017, *Neuron*）
2. **成年神经发生**（海马体）：齿状回持续产生的新神经元整合入现有回路，重塑海马体网络连接，导致旧记忆的突触痕迹被"稀释"或覆盖（Akers et al., 2014, *Science*）
3. **抑制性中间神经元**（含 PV 细胞）：通过调控兴奋/抑制平衡和可塑性时间窗口，间接参与记忆的选择性维持与消退

## 算法类比

主动遗忘机制类似于神经网络中的**权重衰减**（weight decay）或**剪枝**（pruning）——系统主动降低不常用或低价值连接的权重，以优化整体资源分配和模型容量。
