# 多时间尺度突触可塑性

## 三种可塑性规则的算法对应

大脑使用多时间尺度的可塑性规则分工，实现从精细调谐到快速捕获的完整学习光谱。

### Hebbian 学习律（1949）

- **原则**："一起放电的神经元会加强彼此连接"
- **算法对应**：相关学习——时间上相关的神经元活动导致突触连接增强
- **应用**：自联想记忆网络（如 Hopfield 网络）的权重初始化

### STDP（脉冲时序依赖可塑性）

- **规则**：突触前神经元在突触后神经元之前几毫秒放电 → 突触增强（LTP）；反之 → 突触减弱（LTD）
- **特征**：毫秒级精确时序匹配，需要多次重复才能产生稳定突触变化
- **算法对应**：时序差分学习算法，可用于训练脉冲神经网络（SNN）
- **功能**：序列学习、因果推理的精细调谐

### BTSP（行为时间尺度可塑性）

- **发现**：Bittner 等人（2017, *Science*, DOI: 10.1126/science.aan3846）发现海马体 CA1 区位置场的形成由 BTSP 驱动，而非传统 Hebbian/STDP
- **核心机制**：树突钙离子平台电位（dendritic Ca²⁺ plateau potential）——当 CA1 锥体细胞远端树突产生大幅持久的钙信号时，在秒级时间窗口内将所有活跃突触输入一次性增强
- **时间窗口**：离体实验中呈非对称时间进程——上升时间约 4 秒、衰减时间约 3 秒（原文 Fig. 2G）；后续计算模型常近似为对称窗口（Wu & Maass, 2025）
- **关键区别**：BTSP 可在**单次经历**中完成突触强度的持久改变，而 STDP 需要多次重复

## 后续研究

- Wu 和 Maass（2025, *Nature Communications*）构建 BTSP 计算模型，证明其独特窗口机制能解释 CA1 位置场的一次性快速形成
- Magee（2026, *Nature Neuroscience*）综述指出 BTSP 广泛存在于海马体 CA1 及其他脑区，是实现快速经验学习的基础机制

## 时间尺度分工

| 规则 | 时间尺度 | 功能 | 重复需求 |
|------|---------|------|---------|
| STDP | 毫秒级 | 时序信息精细调谐 | 多次重复 |
| BTSP | 秒级 | 行为关键时刻宏观记忆痕迹创建 | 单次经历 |
