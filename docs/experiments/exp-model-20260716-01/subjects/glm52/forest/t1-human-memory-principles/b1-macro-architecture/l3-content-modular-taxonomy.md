# 记忆的内容模块化分类存储

## 模块化组织原则

人脑记忆系统在内容类型上呈现模块化特征——不同类型的记忆由不同脑区负责，类似于计算机中为不同任务分配专用处理单元的存储管理。

## 四类记忆

### 情景记忆（Episodic Memory）
- **内容**：特定事件和情景，包括时间、地点和相关细节
- **脑区**：海马体及内侧颞叶结构
- **机制**：海马体在编码阶段绑定情景各要素，检索阶段通过模式完成激活新皮层的记忆内容
- **理论演进**：Teyler 和 DiScenna（1986）的海马记忆索引理论 → Gershman et al.（2025）的键值分离架构（海马体编码"键"、新皮层存储"值"）

### 语义记忆（Semantic Memory）
- **内容**：一般知识和事实，如词汇含义、概念属性
- **脑区**：新皮层，尤其是颞叶和额叶联合皮层
- **特征**：抽象的、去情境化的；随记忆巩固逐渐独立于海马体

### 程序性记忆（Procedural Memory）
- **内容**：技能和习惯，如骑自行车、弹钢琴
- **脑区**：基底神经节和小脑等皮层下结构
- **特征**：不需要意识参与，一旦习得往往终身保留

### 工作记忆（Working Memory）
- **内容**：当前任务的即时记忆
- **脑区**：前额叶皮层
- **特征**：临时缓存系统，非持久存储；容量和持续时间受前额叶网络动态调控

## 模块化的计算意义

不同脑区各司其职：海马体擅长快速编码事件细节但不善于长期保存，新皮层善于长期保存和泛化但不善于处理新奇细节。这种专业化分工提高了记忆系统的整体效率和可靠性，类似于计算机系统中缓存-主存-辅存的分层存储设计。
