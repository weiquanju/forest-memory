# 世界模型与RL驱动记忆

## 预测性世界模型

Ohmae 和 Ohmae（2024, arXiv:2411.16075）提出，大脑新皮层和小脑尽管回路结构迥异，却共享核心计算原则：都从过去输入中**预测未来事件**，并通过**预测误差学习**持续更新内部的生成式世界模型。

- 这些世界模型不仅用于理解感知输入（"这是什么"），还被重新部署于生成运动输出（"如何行动"）
- 从记忆角度看，记忆不只是静态存储的"数据记录"，而是**动态的生成式内部模型**——回忆是对模型的"查询与重建"，而非对固定痕迹的"读取"
- 这一视角与 AI 中的世界模型思路呼应：Ha 和 Schmidhuber（2018）已展示智能体能在压缩的内部世界模型中学习决策

Ohmae 和 Ohmae（2025）进一步将这一框架拓展为脑-AI 计算范式趋同的视角，指出基于世界模型的计算范式可能是生物智能与人工智能走向通用智能的核心基础。

## RL 驱动的记忆管理

传统 AI 记忆系统依赖人工设定策略（固定时间衰减、遗忘阈值等）管理记忆。最新研究提出让智能体通过强化学习自主学习记忆策略。

**Mem-α 系统**（Wang et al., 2025, arXiv:2509.25911）：
- 通过 RL 训练 LLM 智能体自主决定何时在核心记忆、情景记忆和语义记忆组件之间存储、更新和检索信息
- 在长对话任务中优化记忆使用
- 注意：Mem-α 的 RL 训练本质上是优化 LLM agent 的对话记忆管理策略（归类于 cs.CL），而非面向通用 RL 智能体的记忆框架

这种"利用奖励信号自适应管理记忆"的设计思路与大脑通过多巴胺等神经调质强化有用记忆、削弱无用记忆的机制有结构上的可类比性——两者都体现由价值信号驱动的自适应记忆管理。

## 多智能体共享记忆

Yi 等人（2026）提出 **SoHip**（Social Hippocampus Memory Learning）框架，借鉴海马体记忆机制让异构智能体通过共享轻量级"记忆"而非原始数据或模型参数协作：

- 每个智能体从本地表征中提取短期记忆
- 经"海马体式"巩固机制转化为个体长期记忆
- 再与集体聚合的长期记忆融合以增强本地预测
- 实验表明在保护隐私的同时，相比传统方法最高提升 8.78% 准确率

这一思路呼应了大脑中"个体学习-社会共享"的认知模式。

## 睡眠与情感调控的开放问题

- **睡眠**：NREM 期间海马体尖波涟漪（SWR）重放清醒时的神经活动序列，驱动系统巩固；开放问题包括 SWR 重放内容的选择机制
- **情感**：杏仁核通过释放去甲肾上腺素等神经调质增强海马体记忆编码和巩固（McGaugh, 2000），相当于为高情感显著性经历赋予更高"存储优先级"
