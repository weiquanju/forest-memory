# 键值记忆框架

## 核心主张

键值记忆（Key-Value Memory）框架由 Gershman et al.（2025, arXiv:2501.02950v2）系统阐述，提出统一人脑与 AI 记忆机制的理论：记忆系统本质上采用键值分离架构实现高效存储和检索。

## 脑-AI 对应

| 组件 | 大脑实现 | AI 实现 |
|------|---------|--------|
| 键（索引） | 海马体 | Transformer KV 缓存中的 Key |
| 值（内容） | 新皮层 | Transformer KV 缓存中的 Value |
| 查询 | 当前感知/思维 | Query 向量 |

## 检索失败主导遗忘

框架的核心论点：**检索失败而非记忆擦除是遗忘的主要原因**。

**支持证据**：
- **舌尖现象**：能感知记忆存在但暂时无法提取
- **"知道感"研究**：受试者能准确判断信息是否存储在记忆中，即使无法回忆（Hart, 1965; Reder & Ritter, 1992）
- **实验性遗忘可恢复**：通过蛋白质合成抑制诱导的遗忘可在特定条件下自发恢复或重新暴露于遗忘诱导剂后恢复（Ryan et al., 2015, *Science*）——记忆痕迹未被抹除，只是暂时无法访问
- **模拟验证**：Gershman 等人通过"扩增"旧任务记忆条目的键权重（模拟"再激活"），训练后网络无需重新训练即可恢复旧任务分类能力

## 对灾难性遗忘的补充视角

灾难性遗忘（McCloskey & Cohen, 1989）的核心机制是权重干扰——新任务梯度更新覆盖旧任务权重。KV 框架提出互补解释：旧任务键值对被新任务检索路径"遮蔽"——信息仍在但无法通过正确路径访问。

这与神经科学中"沉默印迹"（silent engram）的再激活实验思路一致。但需指出，这一视角目前仍是键值框架下的理论推演，尚未成为 AI 社区对灾难性遗忘的主流解释。

## 与 CLS 理论的关系与张力

| 框架 | 核心叙事 | 聚焦问题 |
|------|---------|---------|
| CLS | 时间梯度转移——新记忆依赖海马体，随时间推移转移到新皮层 | 记忆如何逐步稳定存储 |
| KV 框架 | 功能并行分工——无论记忆新旧，海马体始终作为索引存在 | 稳定存储后如何高效检索 |

Gershman 等人明确声明框架的生物学解释当前仍属于推测性假说（"the connections we have highlighted are speculative"），其核心论点在正常遗忘和实验性健忘症场景有较好证据支持，但推广到神经退行性疾病需更加审慎。
