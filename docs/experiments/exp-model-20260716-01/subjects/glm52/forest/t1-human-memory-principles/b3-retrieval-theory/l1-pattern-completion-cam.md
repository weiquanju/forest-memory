# 模式完成与内容寻址存储

## 两大互补计算原理

海马体记忆系统的两大核心计算原理——模式分离和模式完成——共同确保记忆的精确检索和抗干扰。

| 原理 | 阶段 | 执行区域 | 功能 |
|------|------|---------|------|
| 模式分离 | 编码 | 齿状回 | 相似输入→差异输出，防止混淆 |
| 模式完成 | 检索 | CA3 | 部分线索→完整记忆，重建丢失信息 |

## CA3 自联想网络与吸引子动力学

CA3 是一个自联想网络（auto-associative network），其 recurrent collateral 突触连接形成吸引子网络（attractor network）（Hopfield, 1982; Rolls, 2013）。

当部分记忆线索输入 CA3 时，循环连接会将活动模式收敛到存储的完整记忆模式上。这一过程类似于 Hopfield 网络中输入损坏模式后通过能量函数下降收敛到最近的存储模式。

## 内容寻址存储（CAM）

CA3 的模式完成对应于内容寻址存储（Content-Addressable Memory, CAM）的读取过程：通过部分内容（线索）直接定位并恢复完整内容。

- **计算机科学中的 CAM**：给定模式的一部分，CAM 返回存储的完整模式
- **海马体的 CAM 实现**：部分输入激活 CA3 时，网络通过循环连接的能量景观收敛到存储的记忆

## 多模态记忆整合

大脑通过多感官整合（multisensory integration）机制将不同模态信息绑定为统一记忆表征。

- **编码阶段**：多模态信息汇聚到内侧颞叶（含海马体）和前额叶皮层，海马体绑定不同感官线索
- **检索阶段**：模式完成可处理不完整的多模态线索——仅有部分感官线索（如咖啡香）仍能通过模式完成找到完整记忆

这种能力表明大脑的联想记忆网络对不同模态信息具有统一的表示和联合检索能力，类似于将不同模态特征向量融合后存储在同一记忆模型中。
