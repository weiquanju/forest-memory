# LLM知识编辑

## 知识编辑定位

知识编辑（Knowledge Editing）旨在精确修改 LLM 中的特定知识，而不影响无关知识或模型整体性能。Wu 等人（arXiv:2402.01364）将 LLM 持续学习技术编排为多阶段方案，将知识编辑作为与 RAG 互补的增强策略。

## 代表性方法

### WilKE：终身知识编辑器
Hu 等人（arXiv:2402.10987）揭示终身编辑场景的性能退化现象：
- **毒性累积**（toxicity buildup）和**毒性爆发**（toxicity flash），根本原因是模式不匹配（pattern unmatch）
- 基于编辑知识在 LLM 不同层的模式匹配程度选择编辑层
- 在 GPT2-XL 和 GPT-J 上相较 SOTA 分别提升 46.2% 和 67.8%

### PRUNE：顺序编辑的扰动约束
Ma 等人（arXiv:2405.16821）从理论分析顺序编辑中影响通用能力的因素：
- 核心因素是被编辑矩阵的条件数（condition number）——随编辑次数增加而增大
- 对条件数施加约束，降低对编辑模型的扰动上界
- 提供理论保证（扰动上界）

### STABLE：门控持续自编辑
Hoy 和 Celik（arXiv:2510.16089）通过门控机制限制遗忘：
- 利用 LoRA 进行参数高效微调
- 通过精确匹配下降、bits 增加或 KL 散度三种指标评估每次编辑对稳定性预算的影响
- 超过阈值时对 LoRA 更新裁剪或拒绝

## 事件级与逻辑规则编辑

- **事件级知识编辑**（arXiv:2402.13093）：通过编辑单个事件更新多个蕴含的知识三元组。ELKEN 基准包含 1,515 个事件编辑和 6,449 个事实性问题，发现现有方法在事件级编辑上表现显著不足
- **逻辑规则感知编辑**（arXiv:2606.10554）：评估知识编辑如何处理单事实编辑的逻辑后果。即使 ROME 和 FT 能准确插入直接断言，在蕴含知识上经常失败——直接编辑与蕴含知识评估的性能差距高达 24%

## 方法对比

| 方法 | 遗忘缓解机制 | 理论保证 | 核心瓶颈 |
|------|------------|:---:|---------|
| WilKE | 基于模式匹配的层选择 | 否 | 顺序编辑毒性累积 |
| PRUNE | 条件数约束 | 是（扰动上界） | 约束可能限制编辑灵活性 |
| STABLE | 门控 LoRA 更新裁剪 | 否 | 阈值调参敏感 |

**关键观察**：序列编辑中的"毒性累积"揭示深层矛盾——当前编辑方法设计为独立操作，但真实知识更新往往是相互关联的网络效应。事件级编辑和逻辑规则编辑正是对此的直接回应。
