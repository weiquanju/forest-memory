# 持续KG嵌入

## 灾难性遗忘问题

知识图谱随真实世界变化持续演化，但 KG 嵌入（KGE）模型在新数据上增量学习时，往往遭遇灾难性遗忘——先前习得的知识被新知识覆盖。

## EWC 用于 KG 持续学习

Jhajj 和 Lin（arXiv:2512.01890）在 FB15k-237 上使用 TransE 嵌入评估 EWC 效果：

- **遗忘缓解**：将灾难性遗忘从 12.62% 降至 6.85%，降幅达 45.7%
- **任务划分影响**：基于关系的划分比随机划分高出 9.8 个百分点的遗忘率
- **局限**：遗忘减半但未消除（6.85% 残留），假设高斯后验

## BAKE：贝叶斯引导的持续 KGE

Li 等人（arXiv:2508.02426）将持续 KG 嵌入形式化为序贯贝叶斯推断问题：

- 利用贝叶斯后验更新原则作为天然的持续学习策略
- 对数据顺序不敏感，提供理论保证
- 引入持续聚类方法维持实体嵌入的紧凑簇结构
- 在多个 CKGE 基准上达到最优
- **优势**：提供理论保证；**局限**：聚类维护开销

## 多模态持续 KG 学习

| 方法 | 贡献 |
|------|------|
| MRCKG（arXiv:2604.02778） | 首次系统研究持续多模态 KG 推理（CMMKGR），提出多模态-结构协同课程调度和跨模态知识保留机制 |
| MSPT（arXiv:2305.08698） | 为持续 MKGC 引入基准，协调知识保留与新数据整合的平衡 |
| KG-GMM（arXiv:2503.18403） | 利用演化 KG 增强类增量学习，在常规和少样本 CIL 设置中均达 SOTA |
| 知情初始化（arXiv:2511.11118） | 利用 KG Schema 和先前嵌入初始化新实体表示，加速知识获取 |

## 关键观察

1. BAKE 和 PRUNE 提供了理论保证，是学术重要进步；但理论保证的充分性在真实世界知识漂移场景下尚待检验
2. KG 持续嵌入（EWC/BAKE）和 LLM 知识编辑（WilKE/PRUNE/STABLE）两类方法目前在各自领域独立发展——将 KG 结构化约束引入 LLM 编辑过程可能是高潜力交叉方向
3. BAKE 的贝叶斯框架能否从理论上扩展至多模态 KG 仍是开放问题
