# 知识冲突检测

## 跨模态知识冲突

Zhu 等人（arXiv:2410.03659）系统定义了跨模态参数化知识冲突问题：

- **发现**：大型视觉-语言模型（LVLM）中视觉和语言组件间存在持续的高冲突率
- **解决方案**：动态对比解码方法缓解冲突
- **性能**：在 ViQuAE 和 InfoSeek 数据集上平均准确率提升 2.24%

## ConflictBank：知识冲突基准

ConflictBank（arXiv:2408.12076, NeurIPS 2024）提供首个系统评估 LLM 中知识冲突影响的基准，涵盖三种冲突类型：

| 冲突类型 | 描述 |
|---------|------|
| 上下文-记忆冲突 | 当前上下文信息与模型记忆中的知识矛盾 |
| 上下文间冲突 | 不同上下文来源提供相互矛盾的信息 |
| 记忆内冲突 | 模型参数化知识内部存在矛盾 |

研究表明，LLM 在面对知识冲突时行为高度复杂，取决于冲突类型、领域和模型能力。

## 事实一致性统一评估

Agarwal（arXiv:2408.04114）统一了四项任务：
- 自然语言推理
- 摘要评估
- 事实性验证
- 事实一致性评估

训练的模型在涵盖 22 个数据集的综合基准上达到 SOTA，实现跨域泛化。

## 开放挑战

1. **三类冲突场景缺乏统一缓解策略**：上下文-记忆冲突、上下文间冲突和记忆内冲突各有不同特征，目前缺乏统一的处理框架
2. **跨领域泛化下降**：从 FEVER 到 Climate-FEVER 跨域时 F1 可从 0.93 下降至 0.78-0.85
3. **人在回路成本**：当前"每条路径审核"的成本过高，需降低到"异常检测 + 抽样审核"

**待解决问题**：如何设计统一的事实一致性评估框架覆盖声明、数值、时态三类事实？
