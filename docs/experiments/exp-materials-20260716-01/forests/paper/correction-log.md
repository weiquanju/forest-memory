# 迭代修正日志

## 设计决策记录

### 决策 #1：森林主题划分
- **日期**: 2026-07-16
- **阶段**: Step 1（森林主题设计）
- **决策**: 采用"what/why → how → evaluate → apply → future"五阶段映射为 5 棵 Tree
  - T1: 记忆基础理论（定义+必要性）
  - T2: 记忆实现架构（来源/形态/操作三维框架）
  - T3: 记忆评估方法（直接+间接）
  - T4: Agent 应用场景（核心交互+垂直领域）
  - T5: 前沿与挑战（参数化记忆+多Agent+类人Agent）
- **理由**: 遵循论文自身的章节组织逻辑（Section 3-4→5→6→7→8），确保层级结构与源材料一致
- **替代方案**: 可合并 T4 到各实现维度（如将应用作为 Source/Form/Operation 的实例），但这会破坏论文的"应用独立成章"的设计

### 决策 #2：Leaf 粒度控制
- **日期**: 2026-07-16
- **阶段**: Step 1（森林主题设计）
- **决策**: 每个 Branch 2-3 个 Leaf，总计 21 个 Leaf 文件
- **理由**: 
  - 单篇论文（39页）的信息量适于此规模
  - 每个 Leaf 保持 100-300 行正文，确保足够深度
  - 避免过度碎片化（如每个模型单独一个 Leaf）或过度粗粒度（如每个 Section 一个 Leaf）

### 决策 #3：跨树引用策略
- **日期**: 2026-07-16
- **阶段**: Step 4（引用关系建立）
- **决策**: 仅建立 Tree 间的概念级映射关系（在 index.md 的跨树关系图中），不在 Leaf 级别交叉引用其他 Tree 的 Leaf
- **理由**: 论文自身是单一来源，各 Tree 间的关系是概念级而非 Leaf 级的具体引用
