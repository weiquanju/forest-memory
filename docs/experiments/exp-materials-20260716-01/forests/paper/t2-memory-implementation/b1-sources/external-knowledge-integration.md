# 外部知识集成

## 定位

LLM-based Agent 的一个关键特征是可以通过自然语言直接获取外部知识。**外部知识源**（如 Wikipedia、数据库、API）为 Agent 提供了远超其内部环境的认知能力。

## 代表性研究

| 模型 | 应用领域 | 外部知识源 | 获取方式 |
|------|---------|-----------|---------|
| ReAct [104] | 通用知识问答 | Wikipedia API | 按需检索，多步推理中动态获取 |
| GITM [93] | Minecraft 探索 | Minecraft Wiki + 合成配方 | API 调用 |
| CodeAgent [114] | Repo-level 代码生成 | 相关文档/依赖 | Web 搜索策略 |
| ChatDoctor [115] | 医疗领域 | Wikipedia + 医学数据库 | Fine-tuned 获取流程 |
| Toolformer [125] | 通用工具使用 | 多种外部 API | 教会 LLM 自主调用工具 |
| ToolLLM [126] | 多工具协调 | RapidAPI (16000+ APIs) | Llama + 多工具使用能力 |

## 关键优势

1. **知识无边扩展**：突破 Agent 内部环境的认知边界
2. **实时性**：通过 API 动态获取，缓解知识过时问题
3. **可验证性**：外部知识有明确来源，可追溯和验证
4. **专业化**：特定领域的深度知识（如医学、金融）无需内化到 Agent 参数中

## 关键挑战

| 挑战 | 描述 | 相关引用 |
|------|------|---------|
| **可靠性** | 外部信息可能存在不准确和偏见 | Qin et al. [18] |
| **语义对齐** | 将外部数据与内部决策过程对齐 | 需要上下文理解能力 |
| **隐私与合规** | API 使用涉及数据安全和隐私问题 | [18] |
| **异构信息** | 检索方法通常处理同构信息，外部异构信息难以直接应用 | Section 5.2.1 |

## 三类来源对比

| 来源 | 动态性 | 范围 | 获取成本 | 可靠性 |
|------|--------|------|---------|--------|
| Inside-trial | 高（实时） | 窄（当前任务） | 低 | 高（直接观测） |
| Cross-trial | 中（累积） | 中（同类任务） | 中（需存储+检索） | 中（经验可能有偏） |
| External | 低-中（按需） | 广（任意领域） | 中-高（API/工具） | 中（依赖来源质量） |
