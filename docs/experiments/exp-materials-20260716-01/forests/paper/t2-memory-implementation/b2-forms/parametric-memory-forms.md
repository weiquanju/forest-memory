# 参数化记忆形态

## 定位

参数化记忆将信息编码进模型参数，不占用 prompt 的上下文长度，因此不受 LLM 长度限制约束。但这一方向仍处于早期研究阶段。

## 两种参数化记忆方法

### 1. Fine-tuning Methods（微调方法）

**机制**：通过监督微调（SFT）将外部知识注入 LLM 参数，使 Agent 获得领域专家级的记忆能力。

**代表工作**：

| 模型 | 领域 | 方法 | 基础模型 |
|------|------|------|---------|
| Character-LLM [105] | 角色扮演 | SFT + 角色相关数据（经验等） | — |
| Huatuo [107] | 生物医学 | SFT + 中文医学知识库 | Llama [127] |
| DoctorGLM [129] | 医疗 | LoRA [131] 高效微调 | ChatGLM [130] |
| Radiology-GPT [132] | 放射学 | SFT + 标注放射学数据集 | — |
| InvestLM [113] | 金融投资 | SFT + 投资数据 | — |

**关键权衡**：
- ✅ 弥合通用Agent与专业Agent之间的差距
- ❌ 过拟合风险 + 灾难性遗忘（更新参数可能丢失原始知识）
- ❌ 计算成本高、耗时长、需要大量数据
- ❌ 主要适用于离线场景，无法应对在线动态交互——反向传播成本无法支持每个 step 都进行微调

### 2. Knowledge Editing Methods（知识编辑方法）

**机制**：精确调整特定事实，而非从数据集中提取模式。确保不相关记忆不受影响。

**与 Fine-tuning 的关键区别**：
- Fine-tuning：从数据集中学习模式 → 可能影响全局知识
- Knowledge Editing：针对特定事实进行调整 → 非目标知识不受影响

**代表工作**：

| 方法 | 机制 | 特点 |
|------|------|------|
| MAC [106] | Meta-learning 替代优化步骤 | 高效的在线记忆适应框架 |
| MEND [134] | Meta-learning 训练轻量模型 | 生成预训练语言模型参数的修改 |
| PersonalityEdit [135] | 基于心理学理论编辑人格 | Big-Five 人格特质调整 |
| KnowledgeEditor [133] | Hyper-network 预测参数修改 | Learning-to-update 问题形式化 |
| APP [136] | 邻居扰动分析 | 研究添加事实对其他事实的影响 |
| Wang et al. [137] | 新优化目标 | 改变中毒知识同时保持通用性能 |

**优势 vs 局限**：

| 维度 | 优势 | 局限 |
|------|------|------|
| 灾难性遗忘 | 非目标知识不受影响 | Meta-training 的计算成本 |
| 更新效率 | 高效、低资源 | 保留无关记忆仍是挑战 |
| 适用场景 | 适合高精度、实时修改 | 小规模调整，不适合大规模知识注入 |
| Agent 应用 | 可作为遗忘机制（编辑不良记忆） | 研究仍处于早期阶段 |
