# 预测性世界模型与RL驱动记忆管理

## 预测性世界模型视角

Ohmae 和 Ohmae（2024）提出：大脑的新皮层和小脑尽管回路结构迥异，却共享一套核心计算原则——**从过去输入预测未来事件**，通过**预测误差学习**持续更新内部的生成式世界模型。

**核心洞见**：
- 世界模型不仅用于理解感知输入（"这是什么"），还被重新部署于生成运动输出（"如何行动"）
- 大脑本质上在持续构建、更新和使用**内部模拟器**来指导行为与决策

**对记忆观的颠覆**：
- 记忆可能不只是静态存储的"数据记录"
- 而是**动态的生成式内部模型**
- 回忆本质上是该模型的"查询与重建"，而非固定痕迹的"读取"

这一视角与 AI 中的世界模型思路呼应：Ha 和 Schmidhuber（2018）展示智能体能在压缩的内部世界模型中学习决策，Ohmae 和 Ohmae（2025）进一步将框架拓展为脑-AI 计算范式趋同——基于世界模型的计算范式可能是生物智能与人工智能共同走向通用智能的核心基础。

## RL 驱动的自适应记忆管理

传统 AI 记忆系统依赖人工设定策略管理记忆。新研究让智能体**自主学会记忆策略**。

**Mem-α 系统**（Wang et al., 2025, arXiv:2509.25911）：通过 RL 训练 LLM 智能体自主决定何时在不同记忆组件（核心/情景/语义）之间存储、更新和检索信息，优化长对话任务中的记忆使用。这体现了**由价值信号驱动的自适应记忆管理**——与大脑通过多巴胺等神经调质强化有用记忆、削弱无用记忆的机制有结构上的可类比性。

## 多智能体共享记忆

**SoHip 框架**（Yi et al., 2026）：借鉴海马体记忆机制，让异构智能体通过共享轻量级"记忆"而非原始数据或模型参数进行协作——经"海马体式"巩固机制转化为长期记忆再融合，在保护隐私的同时相较传统方法最高提升 8.78% 准确率。
