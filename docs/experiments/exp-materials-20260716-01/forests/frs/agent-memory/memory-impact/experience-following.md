# 经验跟随属性与错误累积风险

## 经验跟随属性（Experience-Following）

Hu等人的调查揭示了一个关键现象 [16]：

> 当当前任务与检索到的记忆高度相似时，Agent往往输出与记忆中相似的答案。

## 双重效应

| 效应 | 描述 | 风险 |
|------|------|------|
| **正向复用** | 成功经验的迁移应用 | 提升效率和质量 |
| **负向累积** | 错误记忆被重复使用 | 错误在迭代中放大 |

## 错位经验重放（Misaligned Experience Replay）

更具隐蔽性的是：某些看似正确的记忆在作为示例时可能对当前任务**价值有限甚至具有误导性** [16]。

例如：一个在"天气预报查询"中有效的推理模式在"股票价格预测"中直接复用可能导致错误——尽管记忆内容本身正确，但与当前任务的上下文中不匹配。

## 工程挑战

- 如何区分"可安全复用"和"需要重新判断"的记忆？
- 错误累积的检测和中断机制？
- 记忆的质量评估是否应纳入检索阶段的打分函数？
