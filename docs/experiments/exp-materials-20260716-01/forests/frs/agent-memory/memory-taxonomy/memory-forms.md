# 记忆载体形式分类

## 三级分类

| 级别 | 特征 | 存储形式 | 示例 |
|------|------|---------|------|
| **令牌级 (Token-level)** | 显式且离散 | 文本序列 | 对话历史、上下文窗口内容 |
| **参数级 (Parametric)** | 隐式权重 | 模型参数矩阵 | 模型内部化的知识（事实/语言规则） |
| **潜在级 (Latent)** | 隐状态 | 向量/张量 | RNN的隐状态、Transformer的KV cache |

## 维度分析

- **令牌级**：最直接、可检查，但受上下文窗口长度限制
- **参数级**：容量最大、最持久，但不可直接访问和修改（除非知识编辑）
- **潜在级**：介于两者之间，灵活但难以解释

## 工程启示

三种载体形式对应不同的记忆管理策略：
- 令牌级记忆 → 需要上下文窗口管理和压缩技术
- 参数级记忆 → 需要知识编辑和持续学习技术
- 潜在级记忆 → 需要表示学习和检索增强技术
