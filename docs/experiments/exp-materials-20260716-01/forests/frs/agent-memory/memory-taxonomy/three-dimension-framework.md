# Agent记忆三维统一分类框架

## 框架概述

Hu等人的综合调查提出了统一的记忆分类框架，从**三个正交维度**对Agent记忆进行系统化梳理 [16]：

```
Agent记忆
├── 载体形式 (Forms)：记忆的物理/逻辑载体
├── 功能 (Functions)：记忆服务于什么目的
└── 动态过程 (Dynamics)：记忆如何随时间变化
```

## 三个维度的关系

三维度相互正交——例如，"对话历史"是一个载体形式（令牌级），服务于事实性记忆功能，并经历形成-演化-检索的动态全过程。这种正交性使框架能够系统化地描述和分析任何Agent记忆系统。

## 与其他概念的区别

该框架有助于区分Agent记忆与相关概念：
- **RAG**：检索增强生成，是记忆检索过程的一种实现方式，不等同于记忆本身
- **上下文工程**：管理当前的对话上下文，属于工作记忆范畴但不覆盖长期持久记忆

## Mem0实证价值

Mem0框架证明了结构化持久记忆机制的实际价值——相较OpenAI基线在LLM-as-Judge指标上相对提升**26%**，p95延迟降低**91%**，Token成本节省超过**90%** [16a]。
