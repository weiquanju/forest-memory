# MemVerse 层次化KG多模态记忆框架

## 定位

**MemVerse** 是一种模型无关、即插即用的记忆框架 [17]，将快速参数化回忆与层次化检索记忆桥接。

## 双层记忆架构

| 层级 | 存储内容 | 特点 |
|------|---------|------|
| 短期记忆 | 近期上下文 | 快速访问、容量有限 |
| 长期记忆 | 层次化KG组织的结构化记忆 | 持久存储、多模态 |

## 三大创新

1. **多模态记忆**：可将原始多模态经验（文本+图像+音频）转换为结构化长期记忆
2. **自适应遗忘**：支持有界记忆增长，自动遗忘低价值记忆
3. **周期蒸馏机制**：将长期记忆中的关键知识压缩到参数化模型中，实现快速可微回忆

## 独特地位

MemVerse是唯一同时覆盖**多模态+显式遗忘+知识蒸馏**的框架，概念上最完整，但工程复杂度也最高。
