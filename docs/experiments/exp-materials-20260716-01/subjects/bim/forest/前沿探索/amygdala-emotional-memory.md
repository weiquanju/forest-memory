# 杏仁核-海马体情感记忆调控

## 核心机制

情感唤起事件往往被更生动、更持久地记住——大多数人能清晰回忆极具情感显著性的个人经历。

### 神经基础

情感刺激通过**杏仁核-海马体**交互增强记忆：
1. 情绪刺激激活**杏仁核**（amygdala）
2. 杏仁核释放**去甲肾上腺素**（norepinephrine）等神经调质
3. 去甲肾上腺素直接增强海马体中相关记忆痕迹的**编码和巩固**过程（McGaugh, 2000）

### 算法视角

从算法角度看，这相当于大脑为**高情感显著性的经历赋予了更高的存储优先级**——一种由**价值信号驱动的自适应记忆管理策略**。

这与以下两个方向有天然联系：
- **RL 驱动的记忆管理**（如 Mem-α 系统）：利用奖励信号决定存储/更新/检索策略
- **主动遗忘机制**：情感增强记忆与主动遗忘构成记忆维护的两个相反方向——强化重要的，削弱不重要的

## 未解问题

情感记忆增强是一把双刃剑——在 PTSD（创伤后应激障碍）中，过度的情感记忆巩固导致病理性的创伤记忆闪回。如何选择性削弱情感记忆而保留中立记忆，是临床神经科学的重要挑战。
