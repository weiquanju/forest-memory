# 情景-语义-程序性记忆的模块化分类存储

## 核心机制

人脑记忆系统在内容类型上呈现**模块化特征**，不同类型记忆由不同脑区负责。

### 情景记忆（Episodic Memory）

对特定事件和情景的记忆，包括时间、地点和相关细节。

- **核心脑区**：海马体及邻近内侧颞叶结构
- **编码机制**：海马体绑定情景的各要素，在检索阶段通过模式完成激活分布于新皮层的记忆内容
- **理论基础**：Teyler 和 DiScenna（1986）提出的**海马记忆索引理论**（hippocampal memory indexing theory）——海马体编码"索引"，新皮层存储"内容"，形成索引-存储分离架构
- **最新发展**：Gershman 等人（2025）在其键值记忆框架中将该思想进一步抽象为"海马体编码键、新皮层存储值"的键值分离架构

### 语义记忆（Semantic Memory）

对一般知识和事实的记忆（词汇含义、概念属性等）。

- **核心脑区**：新皮层，尤其是颞叶和额叶的联合皮层
- **特性**：抽象的、去情境化的记忆表征
- **形成过程**：海马体在早期形成中起作用，但随着巩固逐步独立于海马体

### 程序性记忆（Procedural Memory）

对技能和习惯的记忆（骑自行车、弹钢琴等）。

- **核心脑区**：基底神经节和小脑等皮层下结构
- **特性**：不需要意识参与，一旦习得往往终身保留
- **机制差异**：与情景/语义记忆的皮层机制不同，更强调运动学习和模式自动化

### 工作记忆（Working Memory）

临时缓存系统，涉及前额叶皮层对信息的主动维持和操作。非持久存储，容量和持续时间受前额叶网络动态调控。

## 设计类比

这种模块化架构在宏观上类似于：计算机的**缓存-主存-辅存分层存储** + 为不同任务分配**专用处理单元**的设计，提高了整体效率和可靠性。
