# 海马体-新皮层双系统架构

## 核心机制

在海马体-新皮层双系统中，两个脑区在记忆处理上扮演**互补角色**，各自有不同的学习速率和功能定位。

### 海马体：快速学习与细节编码

海马体是大脑的"快速学习"系统，负责快速编码和暂时存储新信息的细节，尤对**情景记忆**（episodic memory）至关重要。

**关键特性**：
- 能够迅速将新经历编码为记忆
- 存储容量有限，记忆痕迹随时间衰退
- 在记忆形成早期阶段活跃
- 短期记忆在此形成后逐渐转移至新皮层

**经典证据**：患者 H.M. 切除海马体后丧失了形成新长期记忆的能力，但保留了手术前的童年记忆——这证明海马体在记忆**编码和转移**中的关键作用（而非最终存储地点）。

### 新皮层：慢速学习与泛化抽象

新皮层是"慢速学习"系统，通过**系统巩固**（systems consolidation）逐步整合海马体传递的信息，形成更持久的记忆表征。这一过程可能需要数周甚至数年。

**关键特性**：
- 擅长泛化和抽象，能从多次经历中提取共性
- 形成对世界的稳定认知模型
- 处理速度慢但容量巨大且持久

**记忆分类存储策略**：具有普遍意义的信息（如每日通勤路线）进入新皮层长期存储并泛化；独特事件细节（如某次聚会的特殊饮料味道）则可能长期保留在海马体中。

## 分层类比

海马体 ↔ 计算机快速缓存（高带宽、低延迟、容量有限）；新皮层 ↔ 硬盘存储（慢处理、大容量、持久）。该分层架构使大脑既能快速适应新信息，又能逐步构建长期知识体系。

## 与 CLS 理论的关系

本双系统架构是**互补学习系统**（Complementary Learning Systems, CLS）理论（McClelland et al., 1995）的核心表述——两个系统以不同的学习速率协作，在特化（记住细节）和泛化（提取规律）之间取得平衡。
