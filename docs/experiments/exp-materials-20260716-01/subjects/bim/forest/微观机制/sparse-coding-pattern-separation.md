# 齿状回稀疏编码与模式分离

## 核心机制

大脑在编码记忆时采用**稀疏分布式编码**（sparse distributed coding）策略：每个记忆事件中仅一小部分神经元被激活，大部分保持静默。

### 两大优势

1. **高容量**：不同记忆的神经表征重叠度极低，可并行存储大量记忆而不冲突
2. **抗干扰**：即使部分神经元受损，分散在少数神经元上的记忆痕迹仍可被检索

### 齿状回（Dentate Gyrus, DG）的关键作用

齿状回颗粒细胞是实现稀疏编码的**核心枢纽**，通过**模式分离**（pattern separation）机制将相似输入映射为差异极大的神经活动模式。

**实验证据**：
- GoodSmith 等人（2017, *Neuron*）与 Diamantaki 等人（2016, *eLife*）：在体电生理和钙成像实验表明，DG 颗粒细胞的发放极其稀疏——任一给定环境中仅约 **9%** 的颗粒细胞处于活跃状态，且不同环境中活跃的是几乎互不重叠的细胞群
- Hainmueller 和 Bartos（2020, *Nature Reviews Neuroscience*）：计算神经科学中为突出模式分离效应，网络模型通常假设更极端的稀疏水平（约 **2-5%** 激活率）

### 算法对应

模式分离在算法上类似于**哈希函数**或**正交编码**：将相近输入映射为差异巨大的输出，在存储时避免冲突。人工神经网络中的稀疏正则化、Sparse Distributed Memory 等模型直接借鉴了该原理。

## 海马体处理流水线

```
EC（内嗅皮层）→ DG（齿状回，模式分离）→ CA3（模式完成）→ CA1（BTSP快速编码）
```

DG 的极端稀疏化使每个记忆在海马体中拥有独特的"指纹"，为下游 CA3 的模式完成提供了干净的去相关输入。
