# 记忆写入策略

## 核心问题

记忆写入（Memory Writing）的核心挑战在于**决定哪些信息值得存储**。原始交互信息通常冗长且含噪，不同环境提供不同形式的反馈，如何提取和表示是关键。

形式化定义：`m^k_t = W({a^k_t, o^k_t})`

## 代表性写入策略

| 模型 | 写入策略 | 信息形式 | 特点 |
|------|---------|---------|------|
| TiM [97] | 实体关系提取 | 结构化数据库（实体→关系） | 相似内容分组存储 |
| SCM [98] | Memory Controller 决策 | Controller 引导写入 | 写入操作自主决策 |
| MemGPT [100] | 完全自主 | Agent 自决策更新 | 无外部写入规则，基于上下文判断 |
| MemoChat [94] | 对话摘要+主题提取 | Key-value：主题→对话片段 | 摘要作为索引键 |
| MemoryBank [6] | 对话→每日摘要 | 高层事件摘要 + 人格洞察 | 持续评估和精炼 |

## 设计维度

### 1. 信息提取粒度

| 粒度 | 代表 | 优势 | 劣势 |
|------|------|------|------|
| 原始存储 | SCM, MemGPT | 信息无损 | 冗余高、检索困难 |
| 结构化提取 | TiM | 检索高效 | 信息可能有损 |
| 摘要化 | MemoryBank, MemoChat | 信息压缩 | 细节可能丢失 |

### 2. 写入自主性

- **规则驱动**：预定义触发器（如达到一定事件数启动 Reflection [83]）
- **LLM 自主**：Agent 基于上下文自动判断（MemGPT [100]）
- **Controller 中介**：独立的 Memory Controller 模块（SCM [98]）

## 关键讨论

- 信息提取策略的设计是"至关重要"的（vital [94]），因为原始信息通常冗长且含噪
- 不同环境提供不同形式的反馈——统一的写入策略可能不适用于所有环境
- 写入操作的**自主性**是一个开放的设计选择：完全自主（MemGPT）、半自主（SCM Controller）还是规则驱动（大多数模型）
