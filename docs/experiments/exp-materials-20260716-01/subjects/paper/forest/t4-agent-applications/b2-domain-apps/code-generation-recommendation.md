# 代码生成与推荐系统中的记忆

## 代码生成（Code Generation）

### 记忆的三种作用

| 作用 | 机制 | 代表 |
|------|------|------|
| 外部知识搜索 | 从记忆/外部检索开发相关信息 | CodeAgent [114] |
| 经验复用 | 保存过往经验解决未来问题 | RTLFixer [142] |
| 上下文维护 | 多 Agent 开发中的对话记忆 | ChatDev [1], MetaGPT [112] |

### 代表性实现

| 模型 | 记忆设计 | 应用场景 |
|------|---------|---------|
| RTLFixer [142] | 外部非参数记忆数据库（编译错误+专家指令） | RTL 语法错误自动修复 |
| GameGPT [144] | 存储个人信息 → 保留上下文和知识 | 游戏开发 |
| ChatDev [1] | 每个角色维护独立记忆（过往对话） | 多 Agent 软件开发 |
| MetaGPT [112] | 检索历史记录应对错误 | 软件开发 |
| CodeAgent [114] | Web 搜索获取相关外部知识 | Repo-level 代码生成 |

### 设计洞察

- **连贯性增强**：整合上下文记忆使 Agent 更好理解开发需求，提升生成代码的连贯性
- **迭代优化**：记忆可识别开发者的历史目标和偏好，是代码迭代优化的关键
- **外部知识**：代码相关知识的检索和存储是增强代码生成能力的重要手段

## 推荐系统（Recommendation）

### 两类应用场景

| 场景 | 记忆功能 | 代表 |
|------|---------|------|
| 用户行为模拟 | 模拟真实用户的偏好和历史行为 | RecAgent [95] |
| 推荐性能提升 | 记忆用户画像、历史交互、领域知识 | RecMind [102], AgentCF [149] |

### 代表性实现

| 模型 | 记忆设计 | 关键机制 |
|------|---------|---------|
| RecAgent [95] | 分层记忆：历史观测 + 洞察 | 模拟推荐系统中的用户行为 |
| InteRecAgent [108] | 长期对话历史 + 最近对话捕获 | Actor-Critic Reflection 提升鲁棒性 |
| AgentCF [149] | Item Agent: 动态记忆（属性+偏好）；User Agent: 自适应更新 | 协同学习 |
| RecMind [102] | 个性化信息（评分/评论）+ Web 搜索获取实时信息 | 多源信息融合 |

### 核心挑战

> "如何将个性化信息和反馈与 LLM 对齐并存入 Agent 记忆，是连接传统推荐模型与 LLM 的重要任务。"

即：推荐系统的结构化数据（评分矩阵、用户画像）如何有效转化为 LLM Agent 可消费的记忆形式，仍是未解决的问题。
