# 认知心理学视角——为什么Agent需要记忆

## 人类记忆的核心地位

认知心理学中，记忆被广泛认为是人类心智过程的核心组件 [84]。它在以下方面发挥基础作用：

| 功能 | 人类表现 | 对 Agent 设计的启示 |
|------|---------|-------------------|
| **知识学习** | 积累重要信息并抽象高层概念 [85] | Agent 需要从交互中提炼可迁移的知识模式 |
| **社会规范形成** | 记忆文化价值和个体经验 [86] | Agent 需要保持行为一致性和角色特征 |
| **合理决策** | 想象行动的潜在正/负后果 [87] | Agent 需要基于历史经验进行推理性决策 |

## 从人类记忆到 Agent 设计

论文提出了一个关键论断：

> LLM-based Agent 的目标是替代人类完成各类任务。让 Agent 像人类一样行动，最自然的方式就是遵循人类的工作机制来设计 Agent [88]。

由于记忆对人类至关重要，为 Agent 设计记忆模块同样具有根本性意义。

## 认知心理学的双重价值

1. **必要性论证**：记忆不是 Agent 的可选组件，而是使其成为真正 Agent 的关键——正是记忆将 Agent 与原始 LLM 区分开来
2. **设计参考**：认知心理学积累了大量有效的人类记忆理论和架构（如 Soar [88]、Duality of Mind [89]），可以为 Agent 的记忆设计提供蓝图

## 学术张力

- **生物启发 vs 工程约束**：人类记忆模型（如 Ebbinghaus 遗忘曲线 [122]、CLS 双系统理论）能否直接映射到 LLM-based Agent？文本记忆的长度限制、参数化记忆的不可解释性都与生物记忆特性存在根本差异
- **模拟 vs 超越**：Agent 记忆是应模拟人类的认知限制（如遗忘、记忆扭曲），还是应追求超人类的完美记忆？Section 8.4 的 Humanoid Agent 方向主张前者，而大多数 Task-oriented Agent 实际追求后者
