# 事件级与逻辑规则感知知识编辑

## 事件级知识编辑 [43]

**问题**：现在编辑方法通常编辑单个三元组（如"CEO(X)=Y"），但真实知识更新涉及**事件**——一次事件改变多个蕴含的知识。

**ELKEN基准**：
- 1,515个事件编辑
- 6,449个事实性问题
- 发现现有方法在事件级编辑上表现**显著不足**

## 逻辑规则感知编辑 [45]

**问题**：即使流行方法（ROME、FT）能准确插入直接断言，在**蕴含知识**上却经常失败。

**关键数据**：直接编辑与蕴含知识评估之间的性能差距高达**24%**。

## CRAFT/KEDAS动态知识编辑 [44]

- **CRAFT**：持续演化的真实世界知识编辑数据集
- **KEDAS**：通过多样化编辑增强和自适应推理的范式
- 评估维度：时态局部性、常识局部性、组合可移植性、别名可移植性

## 深层矛盾

当前编辑方法设计为独立操作，但真实知识更新往往是相互关联的**网络效应**——事件级编辑 [43] 和逻辑规则编辑 [45] 正是对此的直接回应。
