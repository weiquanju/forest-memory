## 3. 关键发现

### 3.1 假设验证：工具差异是否导致显著质量差异？

**结论（中低置信度）：未观察到工具间存在统计显著的森林质量差异。**

- 两工具综合分接近：opencode 6.6 vs CodeBuddy 主评 6.2，差 0.4。
- 在**仅 2 个被测对象 + 同源评审（均 DSV4-Flash）**的条件下，0.4 分差距落在评审者间自然方差（±1）范围内，**不足以断言工具造成质量差异**。
- 差异主要体现在**组织策略**与**规模**上（统一森林+22 叶 vs 按源分森林+64 叶），而非内容质量维度。

### 3.2 异常数据点

1. **D4（批判性分析）两工具均偏低（5 / 5 / 4）**：这是 5 维度中的共同短板，与模型能力（DSV4-Flash, AAI 40）相关，而非工具差异。说明在固定低-中能力模型下，批判性分析的不足是**模型瓶颈**，工具无法弥补。
2. **CodeBuddy 空文件**：2 个 `index.md` 因写入失败为 0 字节，被自评门禁捕获并修复。此属技术噪音，已排除，未影响评审分。
3. **Hy3 重评 D4 更低（4 vs 5）**：Hy3 给 CodeBuddy 的 D4 比 opencode 主评低 1 分，且 D5 高 1 分——反映不同家族模型对"批判性/规范"权重的敏感度不同，属评审者风格差异。

### 3.3 评审偏差影响评估

- **同源偏差**：两个主评审者共用 DSV4-Flash。主观维度（D4/D5）更易受同源风格影响，但两者评分差值仅 ±1，未放大偏差。
- **Hy3 补充重评的作用与局限**：Hy3（不同家族）将 CodeBuddy 综合分从 6.2 拉到 6.5，方向一致，降低了单一同源视角的偏差；但样本仍只有 2 subject，不改变小样本本质。
- **撰写者偏差**：本报告由 Hy3 撰写（见顶部声明），对 CodeBuddy 部分结论存在自利倾向可能，需中立复核。

## 5. 结论与局限

### 5.1 可推广的结论

1. **工具差异 ≠ 质量差异（在本配置下）**：在固定 DSV4-Flash + 相同资料下，opencode 与 CodeBuddy 产出的森林综合质量无显著差异（6.6 vs 6.2，差 0.4，落在评审方差内）。
2. **组织策略是工具带来的主要可观测差异**：opencode 倾向"统一森林"（1 森林/6 树/22 叶），CodeBuddy 倾向"按源分森林"（3 森林/11 树/64 叶）。这是方法论层面的风格差异，不影响 D1-D5 内容质量评分。
3. **模型能力是共同瓶颈**：D4（批判性分析）两工具均 5 分上下，说明在 AAI 40 级别模型下，批判性分析不足是模型上限问题，非工具问题。

### 5.2 局限（诚实声明）

| 局限 | 影响 |
|------|------|
| **样本量极小**（仅 2 subject，opencode 侧仅 1 位评审者） | 无统计显著性，所有差异结论置信度低 |
| **同源评审**（主评审者均 DSV4-Flash） | 系统性同源偏差无法完全排除 |
| **撰写者非中立**（Hy3 为参与者） | 自利偏差风险，报告需中立复核（见顶部） |
| **维度1 基线缺失** | 无法做跨维度对比，假说"工具差异<模型差异"未验证 |
| **数据归集为手动**（脚本不兼容维度2） | 评分提取依赖人工，已记录脚本 bug，待修 |
