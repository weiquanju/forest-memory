# 基于世界模型的内部模拟器

## 架构设计

Ha 和 Schmidhuber（2018）提出：智能体通过 VAE 将高维观测压缩为低维表征，MDN-RNN 学习环境时序动态，再训练小型控制器在该压缩"内部世界"中进行策略搜索。

## 核心意义

智能体拥有了一种**内部记忆模拟器**——它不需要记住每个具体经历，而是记住了环境运行的"生成规则"，在内部重建可能的未来场景来辅助决策。

## 与脑科学的关联

从脑科学角度看，这与大脑在休息和睡眠中通过"回放"（replay）和"预演"（preplay）巩固记忆的机制有深刻的相似性。
