# 意识与记忆的关系

## 核心问题

为什么有些记忆可以被有意识地回忆（陈述性记忆），而有些记忆（程序性技能、条件反射）在意识之外运行？意识参与是记忆检索的必要条件还是仅伴随现象？

## 当前理论倾向

意识可能与**全局工作空间**（global workspace）中信息的全局广播有关：当海马体索引激活了足够广泛的新皮层表征，信息进入"全局可用"状态时，才体验到"记得"的主观感受。

## 定位说明

这一领域目前仍处于理论建构阶段，是连接计算神经科学与认知哲学的最终前沿。
