# 内容寻址与联想记忆

## 联想记忆的本质

一个线索（声音、气味）可以触发对整个事件的回忆——通过内容的一部分检索完整内容，而非通过预先分配的地址。

## CAM的神经基础

海马体 CA3 网络实现内容寻址存储（Content-Addressable Memory）。部分输入激活 CA3 时，网络通过循环连接的能量景观收敛到存储的记忆，等价于 CAM 的匹配和读取操作。

## 键值模型解释

海马体编码"键"（索引线索）而新皮层存储"值"（记忆内容），检索通过键匹配定位后从新皮层提取内容。这与 Transformer 的 QKV 机制（查询×键定位→读取值）形成跨领域对应。
