# 模块化记忆分类

## 四大记忆类型

- **情景记忆**：特定事件和情景（时间、地点、细节），以海马体为核心。海马记忆索引理论（Teyler & DiScenna, 1986）提出海马体编码索引、新皮层存储内容的键值分离架构
- **语义记忆**：一般知识和事实，抽象且去情境化，存储于新皮层联合皮层。早期形成依赖海马体，巩固后独立
- **程序性记忆**：技能和习惯，依赖基底神经节和小脑，无需意识参与
- **工作记忆**：前额叶皮层对信息的主动维持和操作，非持久存储

## 模块化分工价值

海马体擅长快速编码事件细节但不善于长期保存；新皮层善于长期保存和泛化但不善于处理新奇细节。这种分工在宏观上类似于计算机中缓存-主存-辅存的分层存储设计。
