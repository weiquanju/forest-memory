# 稀疏编码与模式分离

## 稀疏编码原理

每个记忆事件中仅一小部分神经元被激活（约 2-9%）。两大优势：并行存储大量记忆而不冲突，以及抗干扰能力（部分神经元受损仍可检索）。

## 齿状回的模式分离

齿状回颗粒细胞将相似但不同的输入映射为差异巨大的神经活动模式。实验证据（GoodSmith et al., 2017, *Neuron*; Diamantaki et al., 2016, *eLife*）表明，给定环境中约 9% 颗粒细胞活跃，不同环境活跃的细胞群几乎互不重叠。

## 算法类比

模式分离 ≈ 哈希函数或正交编码——将相近输入映射为差异巨大的输出，存储时避免冲突。
