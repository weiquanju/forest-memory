# 多智能体共享记忆SoHip

## 核心创新

SoHip（Social Hippocampus Memory Learning, Yi et al., 2026）让异构智能体通过共享轻量级"记忆"而非原始数据或模型参数进行协作。每个智能体从本地表征提取短期记忆，经"海马体式"巩固机制转化为个体长期记忆，再与集体聚合的长期记忆融合。

## 效果

在保护隐私的同时，相比传统方法最高提升 8.78% 准确率。

## 意义

呼应大脑"个体学习-社会共享"的认知模式，为多智能体系统提供了生物学启发的记忆管理范式。
