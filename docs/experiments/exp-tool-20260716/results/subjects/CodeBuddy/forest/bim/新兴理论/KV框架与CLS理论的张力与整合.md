# KV框架与CLS理论的张力与整合

## 两个框架的核心叙事差异

- **CLS（时间梯度转移）**：新记忆依赖海马体，随时间推移通过系统巩固逐渐转移到新皮层，最终旧记忆检索可能不再需要海马体
- **KV（功能并行分工）**：无论记忆新旧，海马体始终作为索引（键），精确情景检索都需要通过海马体的键匹配激活皮层内容

## 张力本质

并非简单的对错之争，而是两个框架回答的问题不同：CLS 聚焦"记忆如何逐步稳定存储"，KV 聚焦"稳定存储后如何高效检索"。

## 当前进展

两个框架的整合是活跃的前沿（Gershman et al., 2025 明确引用 CLS 为思想先驱之一）。如何调和 CLS 的"时间梯度独立性"与 KV 的"永久索引依赖性"有待进一步实验和理论工作。
