# STDP脉冲时序依赖可塑性

## 时序规则

- 突触前在突触后之前几毫秒放电 → LTP（增强）
- 突触前滞后于突触后放电 → LTD（减弱）

## 算法对应

- 对应于时序差分学习算法
- 可用于训练脉冲神经网络（SNN）完成模式识别和序列预测
- 毫秒级精确时序匹配，需要多次重复才能产生稳定变化

## 功能定位

STDP 负责对时序信息的精细调谐（序列学习、因果推理），是多时间尺度可塑性规则分工中的"精细调谐"角色。
