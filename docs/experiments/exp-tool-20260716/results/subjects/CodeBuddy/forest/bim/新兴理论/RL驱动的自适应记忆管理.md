# RL驱动的自适应记忆管理

## 传统局限

传统 AI 记忆系统依赖人工设定策略（固定时间衰减、遗忘阈值等），缺乏自适应能力。

## Mem-α 框架

Wang 等人（2025, arXiv:2509.25911）通过 RL 训练 LLM 智能体自主决定何时在核心记忆、情景记忆和语义记忆组件之间存储、更新和检索信息，在长对话任务中优化记忆使用。

## 生物可类比性

奖励信号驱动记忆管理的设计思路与大脑通过多巴胺等神经调质强化有用记忆、削弱无用记忆的机制有结构上的可类比性——两者都体现了由价值信号驱动的自适应记忆管理策略。
