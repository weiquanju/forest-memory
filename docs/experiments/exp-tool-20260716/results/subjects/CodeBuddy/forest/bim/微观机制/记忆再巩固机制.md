# 记忆再巩固机制

## 核心过程

记忆提取后进入不稳定窗口，此时痕迹可被修改，随后重新稳定。如果在提取时提供新信息，旧记忆会整合新信息而改变。

## 算法对应

在线学习机制——每次查询记忆时，系统对相关记忆进行一次"微调"以适应当前环境和需求。这一机制确保记忆系统具有适应性，而非静态存储。
