# 多模态记忆整合

## 编码阶段的跨模态绑定

多模态信息汇聚到内侧颞叶（海马体）和前额叶皮层。海马体绑定不同感官线索为一个记忆，形成跨模态记忆印记（cross-modal engram）。例如，同时看到图片和听到声音时，海马体会将两者关联。

## 检索阶段的多模态完成

模式完成机制可处理不完整的多模态线索：只有部分感官线索（如闻到咖啡香），海马体仍能找到包含视觉和味觉信息的完整记忆。

## 算法类比

不同模态的特征向量拼接或融合存储在同一个记忆模型中，检索时即使只输入部分模态特征，也能通过部分匹配找到完整记忆。
