# 代码生成Agent记忆

## 核心能力

代码生成 Agent 利用记忆来：
- 记住项目结构和模块依赖关系
- 维持一致的代码风格和命名约定
- 追踪已解决的问题和修复方案
- 实现增量开发，避免重复工作

## 价值

记忆使代码 Agent 能够从大型代码库中理解上下文，生成更一致和符合项目规范的代码，减少需要反复提示的重复工作。
