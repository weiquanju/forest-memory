# 角色扮演Agent与记忆

## 核心需求

角色扮演 Agent 需要长期记忆来维持角色一致性和个性化交互体验。记忆使 Agent 能够记住用户偏好、历史对话和关系演变。

## 关键能力

- **角色一致性**：长期维持角色设定和背景故事
- **用户记忆**：记住用户的偏好、习惯和过往互动
- **关系建模**：追踪用户与角色之间的关系演化
- **情境感知**：理解当前交互在长期对话中的位置
