# Agent记忆评估方法

## 评估维度

- **准确性**：检索命中率、信息正确性
- **效率**：检索延迟、存储开销
- **鲁棒性**：噪声容忍、错误恢复
- **可扩展性**：随交互轮次的性能保持

## 常用指标

- 检索准确率（命中Top-K比率）
- 响应时间（p50/p95/p99延迟）
- 记忆一致性（多轮对话中的事实保持）
- 存储效率（信息密度，存储量÷有效信息）
