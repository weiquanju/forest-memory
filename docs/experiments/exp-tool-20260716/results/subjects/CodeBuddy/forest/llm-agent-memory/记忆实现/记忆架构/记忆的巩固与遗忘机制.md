# 记忆的巩固与遗忘机制

## 巩固策略

- **即时巩固**：每次交互后立即处理
- **定期巩固**：固定间隔汇总
- **事件驱动巩固**：达到特定条件时触发

## 遗忘策略

- **时间衰减**：基于时间戳淘汰
- **容量限制**：达到上限后替换低价值记忆
- **重要性评分**：基于使用频率或价值信号
- **主动遗忘**：识别并移除低质量或过时信息

## 设计挑战

遗忘策略需要在信息保留与存储效率之间取得平衡，过快的遗忘会导致应用退化，过慢的遗忘会影响检索效率。
