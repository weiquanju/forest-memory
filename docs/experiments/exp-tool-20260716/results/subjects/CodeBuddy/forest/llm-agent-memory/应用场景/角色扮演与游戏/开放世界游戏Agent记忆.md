# 开放世界游戏Agent记忆

## 记忆需求

开放世界游戏中的 NPC Agent 需要记忆来跟踪玩家行为、世界状态变化和任务进度，从而提供动态响应和自适应剧情体验。

## 应用场景

- **行为记忆**：NPC 记住玩家之前的互动（帮助/敌对）
- **世界状态**：记忆环境变化和事件影响
- **任务追踪**：跟踪复杂任务链和分支剧情
- **社交记忆**：模拟NPC之间的社交关系和知识传播
