# 为什么Agent需要记忆

## 三个视角

1. **认知心理学视角**：人脑记忆系统可类比指导 Agent 记忆设计，短期/长期记忆分工、巩固和遗忘等机制提供了设计模式
2. **自进化视角**：记忆是 Agent 自进化（self-evolution）的基础——通过存储经验、反思和调整行为策略，Agent 可以随时间改进性能
3. **Agent应用视角**：多轮对话、长期任务、个性化服务都需要记忆来维持上下文一致性和用户偏好
