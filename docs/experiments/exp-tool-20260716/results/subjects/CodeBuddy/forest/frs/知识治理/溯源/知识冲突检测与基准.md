# 知识冲突检测与基准

## 冲突分类

ConflictBank（Su et al., 2024, NeurIPS 2024）定义了三类知识冲突：
1. 上下文-记忆冲突
2. 上下文间冲突
3. 记忆内冲突

## 跨模态冲突

Zhu 等人（2024, arXiv:2410.03659）发现 LVLM 中视觉和语言组件间存在持续高冲突率，提出动态对比解码方法缓解。

## 事实一致性统一框架

Agarwal（2024）统一了自然语言推理、摘要评估、事实性验证和事实一致性评估四项任务，在22个数据集上达到SOTA。
