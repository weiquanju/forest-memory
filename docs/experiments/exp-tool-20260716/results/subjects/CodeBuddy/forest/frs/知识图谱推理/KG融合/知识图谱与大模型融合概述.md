# 知识图谱与大模型融合概述

## 核心动机

LLM 内部知识是隐式的，存在幻觉和知识更新不及时问题。知识图谱（KG）提供结构化事实，增强模型在知识密集型任务中的表现。

## 代表方法

- **PoG**（Paths-over-Graph, arXiv:2410.14211）：三阶段动态多跳路径探索，将 LLM 知识与 KG 事实结合。PoG+GPT-3.5-Turbo 超过 ToG+GPT-4 达 23.9%
- **ToG**（Think-on-Graph, arXiv:2307.07697）：LLM⊗KG 深度整合，通过 beam search 探索 KG 实体和关系，实现知识可追溯性
- **KG-Agent**（arXiv:2402.11163）：10K 样本微调 LLaMA-7B 在 KGQA 上超越更大模型的 SOTA
- **KG-RAR**（arXiv:2503.01642）：过程导向 KG 构建+分层检索+PRP-RM，Math500 和 GSM8K 上 Llama-3B 提升 20.73%
