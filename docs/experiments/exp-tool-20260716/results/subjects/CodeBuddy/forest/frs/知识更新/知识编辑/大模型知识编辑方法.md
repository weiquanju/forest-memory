# 大模型知识编辑方法

## 代表方法

| 方法 | 核心机制 | 表现 |
|------|---------|------|
| **WilKE**[40] | 模式匹配层选择 | GPT2-XL提升46.2%, GPT-J提升67.8% |
| **PRUNE**[41] | 条件数约束 | 保持编辑性能+保留通用能力 |
| **STABLE**[42] | 门控LoRA+预算评估 | 多步顺序编辑 |
| **事件级编辑**[43] | 单事件更新多个三元组 | ELKEN基准 |
| **逻辑规则编辑**[45] | 评估编辑的逻辑后果 | 直接编辑vs蕴含差24% |

## 核心挑战

- **毒性累积**（toxicity buildup）和**毒性爆发**（toxicity flash）——根本原因是模式不匹配
- 单事实编辑与蕴含知识评估之间的性能差距高达24%
- 当前方法设计为独立操作，但真实更新是相互关联的网络效应
