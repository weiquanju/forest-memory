# 记忆对推理与输出质量的影响

## 正面影响

长期记忆使 Agent 能在多轮对话或长时间任务中保持上下文一致性，避免重复错误，逐步积累经验。

## 经验跟随属性（Experience-Following）

当当前任务与检索到的记忆高度相似时，Agent 往往输出与记忆中相似的答案。这有助于复用成功经验，但可能导致错误累积——如果记忆包含错误输出，Agent 在后续任务中可能复制甚至放大这些错误（Hu et al., 2025）。

## 管理要求

记忆不仅需要存储，还需要质量控制和动态更新。错位经验重放（Misaligned Experience Replay）是一个关键挑战。
