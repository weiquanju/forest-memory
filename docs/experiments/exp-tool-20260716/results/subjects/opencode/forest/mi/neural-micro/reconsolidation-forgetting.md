# 再巩固与遗忘机制

记忆处于动态更新状态。当记忆被提取时，进入不稳定窗口，可被修改后重新稳定——再巩固（reconsolidation）。这相当于在线学习机制：每次查询记忆时系统对相关记忆进行一次"微调"。

遗忘并非简单"擦除"，而是多种机制的结果：

**突触资源竞争**：可塑性依赖有限的分子资源（PRPs、代谢能量等）。当某些突触被诱导LTP时，邻近未激活突触可能因资源被抢占而经历异突触LTD，导致旧记忆被削弱。Karbowski（2019）的代谢约束模型表明新学习消耗总突触能量预算的4-11%——资源紧张时仍可挤压旧记忆维持。

**主动遗忘机制**：大脑通过特定分子通路主动降低某些记忆痕迹强度。（1）果蝇中多巴胺→Rac1→Cofilin级联驱动主动遗忘（Shuai et al., 2010; Davis & Zhong, 2017）；（2）海马体中成年神经发生（Akers et al., 2014）——新神经元整合入齿状回回路导致旧记忆痕迹被"稀释"或覆盖。这些主动遗忘机制在算法上类似于权重衰减或剪枝：系统主动降低不常用或低价值连接的权重以优化资源分配。
