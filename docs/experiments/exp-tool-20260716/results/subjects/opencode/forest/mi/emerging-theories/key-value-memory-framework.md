# 键值记忆统一框架

键值记忆（Key-Value Memory）框架（Gershman et al., 2025）统一认知心理学、神经科学和机器学习的记忆理论。核心观点：无论是大脑还是机器学习模型，记忆系统本质上采用键值分离架构——海马体编码"键"（索引），新皮层存储"值"（内容）。

**核心假说——检索失败而非记忆擦除是遗忘的主要原因**：支持证据包括舌尖现象（tip-of-the-tongue）、"知道感"（feeling of knowing）研究，以及实验性遗忘中通过再激活恢复记忆的实验（Ryan et al., 2015, *Science*）。论文模拟实验显示：通过"扩增"旧任务记忆的键值权重，神经网络无需重新训练即可恢复旧任务分类能力。

**与CLS的张力**：CLS聚焦记忆随时间梯度转移（海马体→新皮层），KV聚焦功能并行分工（海马体始终作为索引）。CLS回答"记忆如何稳定存储"，KV回答"存储后如何高效检索"——两者的整合仍是活跃研究前沿。

**注意**：该框架的生物学解释当前仍属推测性假说（"the connections we have highlighted are speculative"），尤其推广到神经退行性疾病须审慎。
