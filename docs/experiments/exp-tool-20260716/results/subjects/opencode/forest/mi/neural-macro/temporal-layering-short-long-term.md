# 记忆的时间分层

短期记忆（工作记忆）与长期记忆是记忆系统最基础的分层划分。短期记忆依赖前额叶皮层等区域的持续神经活动维持信息，容量有限（约7±2个信息块）且持续时间短暂（数秒到数分钟）。这种持续活动模型通过局部回路循环兴奋、突触前馈/反馈以及单细胞双稳态等机制稳定维持。

长期记忆依赖突触结构和功能的持久改变（LTP/LTD），存储容量理论上是巨大的（数十亿神经元×更庞大的突触连接）。长期记忆需要时间和重复来巩固，并非所有短期记忆都能转化为长期记忆，体现了容量与持久性之间的权衡。

两种记忆机制存在互补的资源分配关系：持续神经活动消耗能量但支持灵活操作，突触改变消耗分子资源但支持持久存储。这种权衡在计算机架构中类似于SRAM（高速缓存）与DRAM+SSD（主存+持久存储）的分层设计。
