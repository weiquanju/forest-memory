# 知识编辑与持续学习

LLM知识需要持续更新以保持时效性，核心挑战是在更新知识的同时不破坏已有知识（灾难性遗忘）。

**知识图谱持续学习**：EWC（弹性权重巩固）通过保护重要权重的梯度更新方向来维持旧知识；BAKE（贝叶斯知识编辑）提供概率框架评估编辑对模型的影响边界。这些方法平衡知识更新与记忆保持的trade-off。

**LLM知识编辑**：WilKE通过关键权重定位实现精准编辑，PRUNE利用剪枝策略在移除过时知识的同时保留高频知识。知识编辑需要满足三个关键属性——编辑成功率（修改是否生效）、泛化性（相关上下文是否无矛盾更新）、特异性（不相关上下文是否不被修改）。

**关键挑战**：大规模编辑的副作用控制（连锁影响）、时效性知识的多跳一致性、以及编辑与模型持续训练的协调。终身知识编辑的核心矛盾是模型参数空间的物理局限性和知识持续增长之间的根本张力。
