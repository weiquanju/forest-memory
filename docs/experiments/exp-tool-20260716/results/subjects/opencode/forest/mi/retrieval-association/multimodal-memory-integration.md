# 多模态记忆整合

日常生活记忆往往是多模态的——同时包含视觉、听觉、触觉等信息。大脑通过多感官整合（multisensory integration）机制将不同模态信息绑定为统一记忆表征。

在编码阶段，多模态信息汇聚到内侧颞叶（海马体）和前额叶皮层。海马体绑定不同感官线索到一个记忆中形成跨模态记忆印迹——学习时同时看到图片和听到声音，海马体会将两者关联，日后只需一种线索即可回忆另一部分。

在检索阶段，模式完成机制可处理不完整的多模态线索。只有部分感官线索（如闻到咖啡香）时，海马体仍可通过模式完成找到完整记忆（包括视觉和味觉信息）。在算法上，这类似于将不同模态特征向量拼接或融合后存储在同一个记忆模型中，检索时即使只输入部分模态特征也能通过部分匹配找到完整记忆。
