# 模式分离与模式完成互补算法

## 分工定位

- **模式分离**（编码阶段）：齿状回将相似输入映射为差异很大的输出，防止记忆混淆
- **模式完成**（检索阶段）：CA3 自联想网络通过吸引子网络将部分线索收敛到完整记忆（Hopfield, 1982; Rolls, 2013）

## CA3 的吸引子网络机制

CA3 的 recurrent collateral 突触连接形成一个吸引子网络。输入部分线索时，循环连接将活动模式收敛到存储的完整记忆。在算法上类似于 Hopfield 网络通过能量函数下降收敛到最近的存储模式。

## 互补作用

二者共同确保记忆系统既能区分相似记忆（模式分离），又能重建部分丢失的记忆（模式完成）。
