# 海马体与新皮层互补系统

## 双系统架构

互补学习系统（CLS）理论认为海马体和新皮层扮演互补角色：

- **海马体**："快速学习"系统，快速编码新信息细节，容量有限，负责情景记忆的早期形成
- **新皮层**："慢速学习"系统，逐步整合信息形成长期表征，容量巨大

## 系统巩固过程

海马体通过反复系统巩固（system consolidation）将记忆痕迹转移到皮层网络。经典案例 H.M. 切除海马体后丧失形成新长期记忆的能力但保留童年记忆，证明了海马体在记忆编码和转移中的关键作用。

## 计算类比

海马体 ≈ 快速缓存（即时高带宽、容量有限）；新皮层 ≈ 硬盘存储（速度慢、容量巨大持久）。分层架构使大脑既能快速适应新信息又能构建长期知识体系。
