# 键值记忆框架

## 核心主张

键值记忆（Key-Value Memory）框架提出：大脑和机器学习模型都采用键值分离架构。大脑中，海马体编码"键"（索引），新皮层存储"值"（内容）；Transformer 中通过 QKV 机制实现类似功能。

## 检索失败主导遗忘

核心论点：**检索失败而非记忆擦除是遗忘的主要原因**（Gershman et al., 2025）。证据包括舌尖现象（tip-of-the-tongue）、知道感（feeling of knowing）研究、以及蛋白质合成抑制诱导遗忘可自发恢复的实验（Ryan et al., 2015, *Science*）。

## 局限性

该框架的生物学解释当前属于推测性假说（"the connections we have highlighted are speculative"）。在正常日常遗忘和实验性健忘症场景有较好支持，但推广到神经退行性疾病需审慎。
