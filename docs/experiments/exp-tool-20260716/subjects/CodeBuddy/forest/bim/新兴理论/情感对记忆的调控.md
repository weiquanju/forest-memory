# 情感对记忆的调控

## 神经机制

情感唤起事件被更生动持久地记住，其神经基础在于：情绪刺激激活杏仁核，释放去甲肾上腺素等神经调质，增强海马体中相关记忆痕迹的编码和巩固过程（McGaugh, 2000）。

## 算法意义

大脑为高情感显著性的经历赋予更高"存储优先级"——是一种由价值信号驱动的自适应记忆管理策略。这与 RL 驱动的记忆管理（Mem-α）形成结构上的可类比性，揭示了生物记忆管理策略与 AI 记忆管理策略之间的深层次联系。
