# 主动遗忘机制

## 突触资源竞争

新学习消耗可塑性相关蛋白（PRPs）和代谢能量，邻近未激活突触因资源被"抢占"而经历异突触LTD。Karbowski（2019）代谢约束模型表明，突触可塑性消耗总能量预算的 4-11%。

## 分子层面的主动遗忘

1. **Rac1 通路**：果蝇中多巴胺→Rac1/Cofilin 级联驱动遗忘（Shuai et al., 2010, *Cell*; Davis & Zhong, 2017, *Neuron*），哺乳动物有功能同源物
2. **成年神经发生**：齿状回持续产生新神经元整合入回路，稀释旧记忆突触痕迹（Akers et al., 2014, *Science*）

## 算法类比

主动遗忘 ≈ 权重衰减（weight decay）或剪枝（pruning）——系统主动降低不常用或低价值连接的权重，优化资源分配和模型容量。
