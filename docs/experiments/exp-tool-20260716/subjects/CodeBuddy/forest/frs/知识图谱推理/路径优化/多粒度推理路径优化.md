# 多粒度推理路径优化

## 代表方法比较

| 方法 | 核心机制 | 创新点 |
|------|---------|--------|
| **RRP**[11] | 关系嵌入+重思考模块 | 精炼推理路径后即插即用集成LLM |
| **KARPA**[12] | LLM全局规划+嵌入语义路径 | 避免逐步KG遍历的低效 |
| **ORT**[13] | 本体引导逆向思维 | 从目的反向构建推理路径 |
| **SoG**[14] | observe-think-navigate范式 | 完全利用LLM推理能力 |
| **MemoTime**[15] | 时间树+自演化经验记忆 | 小模型接近GPT-4-Turbo性能 |

## 关键观察

- "无需训练"（ToG/PoG/SoG）是当前主流
- 社区亟需统一KGQA基准上的标准化对比实验
