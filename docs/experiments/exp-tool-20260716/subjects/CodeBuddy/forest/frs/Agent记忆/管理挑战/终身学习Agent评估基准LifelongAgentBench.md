# 终身学习Agent评估基准LifelongAgentBench

## 核心贡献

LifelongAgentBench（Zheng et al., 2025, arXiv:2505.11942）是首个系统评估 LLM Agent 终身学习能力的统一基准。

## 覆盖环境

- 数据库环境（Database）
- 操作系统环境（OS）
- 知识图谱环境（KG）

## 关键发现

传统经验回放对 LLM Agent 效果有限，原因是无关信息和上下文长度约束。
