# 从静态到动态的评估范式转型

## 三大趋势

1. **组合式基准**：通过链式连接复杂化推理链（如Scheherazade）
2. **过程导向评估**：关注推理过程可重用性和可验证性
3. **智能体评估**：多轮交互中的规划、执行和反思

## 结构性挑战

1. **评估成本与可复现性**：Agent基准多轮交互大幅增加API成本
2. **记忆与推理的纠缠**：难以分离"记错了"还是"推理错了"
3. **生态碎片风险**：统一标杆被碎片化专用基准取代
