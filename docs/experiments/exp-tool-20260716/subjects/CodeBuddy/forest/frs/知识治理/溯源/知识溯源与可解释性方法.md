# 知识溯源与可解释性方法

## 主要方法

- **ToG**：推理路径每步可追溯至KG三元组，人类可以检查和纠正
- **RL-based可解释核查**[27]：RL Agent计算证明/反驳路径，可呈现给人
- **Hybrid Pipeline**[28]：KG检索+LLM+Web搜索模块化架构，F1=0.93 on FEVER
- **语义三元组零样本核查**[29]：声明分解为语义三元组，超越监督模型
- **WKGFC**[30]：多源多Agent证据检索，MDP建模自主决策

## 混合管道趋势

KG覆盖不足时自动回退到Web搜索的降级策略——展示了模块化、开源的事实核查架构。
