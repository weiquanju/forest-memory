# 多模态推理的机遇与挑战

## 当前短板

- 局部区域推理和细粒度关系理解不足
- **空间操作任务**（折叠、反射、旋转）遇到明显瓶颈——STARE基准评估显示，MLLM在3D立方体展开折叠和七巧板拼图等多步视觉模拟任务上几乎接近随机猜测水平（Li et al., 2025）

## 前沿方案

Insight-V（Dong et al., 2024, CVPR 2025）通过生成长而稳健的多模态推理链并采用多智能体训练管道，在多个视觉推理基准上取得显著提升。
