# LLM Agent记忆的定义与分类

## 双重定义

**狭义定义**：Agent 中的持久化存储机制，用于在交互过程中存储和检索信息。

**广义定义**：Agent 中所有用于信息存储、处理和检索的组件，包括上下文窗口、模型参数和外部存储。

## 认知心理学视角

Agent 记忆设计从人脑记忆系统获得启发——通过类比人脑的短期/长期记忆分工、情景/语义/程序性记忆分类来指导 Agent 记忆架构设计。
