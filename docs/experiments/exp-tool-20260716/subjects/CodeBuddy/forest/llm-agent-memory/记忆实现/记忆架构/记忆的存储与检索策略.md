# 记忆的存储与检索策略

## 存储结构选择

| 存储类型 | 适用场景 | 优缺点 |
|---------|---------|--------|
| 向量数据库 | 语义相似度检索 | 高效但缺少结构关系 |
| 知识图谱 | 实体关系存储 | 结构清晰但构建复杂 |
| 关系型数据库 | 结构化记录 | 查询灵活但语义弱 |

## 检索策略

- **精确检索**：指定键或ID直接访问
- **模糊检索**：语义相似度匹配
- **层次化检索**：全局→局部逐步细化
- **检索时机**：同步（每次推理前）vs 异步（独立线程更新）
