# 互补学习系统

互补学习系统（CLS）理论由McClelland等人于1995年提出，解释海马体和新皮层在记忆中的互补作用：海马体快速学习并记住事件细节，新皮层慢速学习并记住事件规律。这种分工使大脑在特化和泛化之间取得平衡。

近年来的AI实现：Jun等人（2025）将变分自编码器（VAE，模拟新皮层模式完成与泛化）与现代Hopfield网络（MHN，模拟海马体模式分离与快速编码）结合，构建CLS神经网络模型。在Split-MNIST持续学习基准上达到接近SOTA的约90%准确率，显著减少灾难性遗忘。

这一结果表明：CLS理论不仅是对大脑机制的描述，也可以指导AI模型设计——通过分离快速记忆（模式分离、具体细节）和慢速记忆（模式完成、泛化抽象）的系统分工，实现更稳健的持续学习。
