# 世界模型与预测性记忆

**预测性世界模型**（Ohmae & Ohmae, 2024）：新皮层和小脑共享一套核心计算原则——从过去输入预测未来事件，通过预测误差学习持续更新生成式世界模型。记忆不只是静态存储的"数据记录"，而是动态的生成式内部模型：回忆是对这个模型的"查询与重建"，而非对固定痕迹的"读取"。这与AI中的世界模型（Ha & Schmidhuber, 2018）形成呼应——智能体在压缩的内部世界模型中学习决策。

**RL驱动记忆管理**（Mem-α, Wang et al., 2025）：通过RL训练LLM智能体自主决定何时在核心记忆、情景记忆和语义记忆组件之间存储、更新和检索信息。这体现了由价值信号驱动的自适应记忆管理策略——与大脑通过多巴胺等神经调质强化有用记忆、削弱无用记忆的机制有结构上的可类比性。

**多智能体共享记忆**（SoHip, Yi et al., 2026）：借鉴海马体记忆机制，让异构智能体通过共享轻量级"记忆"而非原始数据或模型参数进行协作。每个智能体提取短期记忆→巩固为个体长期记忆→与集体聚合长期记忆融合，在保护隐私的同时较传统方法最高提升8.78%准确率。
