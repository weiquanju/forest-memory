# 稀疏编码与模式分离

大脑使用稀疏分布式编码策略编码记忆：每个记忆事件中只有一小部分（约2-9%）神经元被激活。这种策略带来两大优势：并行存储大量记忆而不易冲突（表征重叠度低），抗干扰能力强（部分神经元受损仍可检索）。

海马体齿状回（DG）的颗粒细胞是实现稀疏编码的关键区域。DG通过模式分离（pattern separation）机制将相似输入映射为差异很大的神经活动模式——即使相似的记忆项目也会由不同的细胞群编码，防止记忆混淆。

电生理实验表明齿状回颗粒细胞发放极其稀疏：任一给定环境中仅约9%活跃（GoodSmith et al., 2017），不同环境活跃的是几乎互不重叠的细胞群。计算模型通常假设更极端的稀疏水平（约2-5%激活率）以突出模式分离效应。这种机制在算法上类似于哈希函数或正交编码，将相近输入映射为差异巨大的输出以避免存储冲突。
