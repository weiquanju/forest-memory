# 海马体-新皮层双系统

海马体和新皮层构成互补学习系统（CLS）的核心双系统架构，各自扮演互补角色。

海马体是"快速学习"系统，负责快速编码和暂时存储新信息的细节，尤其对情景记忆至关重要。它能够迅速将新经历编码为记忆，但存储容量有限且记忆痕迹会随时间衰退。经典案例患者 H.M. 切除海马体后丧失了形成新长期记忆的能力，但保留了旧记忆。

新皮层是"慢速学习"系统，负责逐步整合和存储海马体传递来的信息，形成长期记忆。新皮层通过系统巩固（system consolidation）过程——涉及睡眠中尖波涟漪（SWR）驱动的海马-皮层对话——将记忆痕迹转移到皮层网络。新皮层擅长泛化和抽象，从多次经历中提取共性形成稳定认知模型。

这种架构类似计算机的缓存-硬盘分层：海马体如同快速缓存（高带宽、有限容量），新皮层类似硬盘（处理慢、容量巨大且持久），使大脑既能快速适应新信息又能逐步构建长期知识体系。
