# 模块化记忆分类

情景记忆（episodic memory）对特定事件和情景的记忆，海马体及其内侧颞叶结构起核心作用。海马记忆索引理论（Teyler & DiScenna, 1986）提出"海马体索引、新皮层存储"的分工——海马体编码索引（键），新皮层存储内容（值）。

语义记忆（semantic memory）对一般知识和事实的记忆，主要存储在新皮层（颞叶和额叶联合皮层），是抽象的、去情境化的。海马体在语义记忆早期形成中也起作用，但随着记忆巩固，语义知识逐渐独立于海马体。

程序性记忆（procedural memory）对技能和习惯的记忆（如骑自行车），依赖基底神经节和小脑等皮层下结构，不需要意识参与且习得后通常终身保留。

工作记忆（working memory）是临时缓存系统，涉及前额叶皮层对信息的主动维持和操作，非持久存储，但受前额叶网络动态调控。

这种模块化架构类似计算机系统的缓存-主存-辅存分层以及为不同任务分配专用处理单元的设计，提高了记忆系统的整体效率和可靠性。
