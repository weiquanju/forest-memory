# 记忆评估方法

Agent记忆评估分为**直接评估**和**间接评估**两大范式：

**直接评估**：直接测试记忆模块的性能指标，包括主观评估（LLM-as-Judge、人工评估——衡量记忆检索的相关性和有用性）和客观评估（记忆精度、召回率、检索延迟、存储效率等可量化指标）。

**间接评估**：通过下游任务表现间接评估记忆质量，包括对话连贯性（长对话中的一致性保持）、多源问答（多信息源的检索准确度）、长上下文应用（长文档处理中的记忆利用效率）。

**MemBench等专用基准**：构建标准化的Agent记忆测试场景，模拟多种交互类型和记忆负载，系统化评估记忆模块的各方面能力。评估范式的演进反映了从静态测试到动态交互评估的趋势——更真实的Agent使用场景需要更复杂的评估协议。
