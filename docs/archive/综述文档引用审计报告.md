## 6. 跨领域审计（人脑记忆 × CS/LLM）

> 本节评估论文中涉及"脑启发"或"记忆机制"类比的严谨性。

### 6.1 编码/表征

论文在 Agent 记忆部分（第三章）提出了**载体形式三维分类**（令牌级/参数级/潜在级），这一分类源自 [16] 的综述工作。
- 令牌级记忆 → 类比海马体对离散事件的快速编码：**合理但论文未做此类比**
- 参数级记忆 → 类比皮层突触可塑性：**合理**
- 潜在级记忆 → 类比工作记忆的神经表征：**论文未做生物学论证，仅为计算抽象**

**评价**：分类本身在计算上是清晰的，但论文**没有试图将其与神经生物学机制对应**，这在"记忆"这一高度生物学化的概念下是一种谨慎做法，避免了肤浅的神经类比。

### 6.2 巩固/记忆形成

第 7.1 节讨论 KG 持续学习时引用 EWC [33]，该方法的灵感直接来自神经科学中的突触巩固理论。论文正确描述了 EWC 如何通过 Fisher 信息矩阵保护重要权重，但**没有讨论 EWC 与生物记忆巩固之间的理论对应关系**（如睡眠期间的突触重放、互补学习系统理论）。

### 6.3 检索/记忆访问

第 3.2 节提出"经验跟随属性"和"错位经验重放"两个关键发现，这两个概念与认知心理学中的**源监控错误（source monitoring error）**和**错误记忆（false memory）**现象有关联。论文未在此处引入心理学文献支撑，但这一发现的计算意义独立成立。

### 6.4 工作记忆 vs 注意力

论文在第三章将"工作记忆"作为 Agent 记忆的一个功能类别处理，定义为"主动上下文管理"。这一用法属于**隐喻性使用**而非计算模型。论文没有声称 Transformer 的注意力机制等同于生物工作记忆，这是一个合理的谨慎立场。
